# Domain modeling: agents as domain professionals (v3.0 direction)

## Context
The v3.0 vision treats each agent role as a professional to model rather than a task processor to extend: what a senior developer, product owner or QA engineer actually does, and what sub-agents, tools and domain knowledge that requires. `docs/research/3.0-domain-modeling.md` lays out the role-analysis approach — role analysis, workflow mapping, architecture design, implementation — and defers concrete retrieval strategies and cross-session learning to the same milestone.

## Trigger to revisit
Pick this up when the retarget session confirms software development is still the target domain — the whole direction assumes it.
