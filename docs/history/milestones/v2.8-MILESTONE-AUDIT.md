### Integration Issues Found

**1. event.routed sequence collision (moderate)**

`emitRoutedEvent()` in `router.ts:62` inserts `agent_events` rows with `sequence: 0` hardcoded. The `agent_events` table has `UNIQUE(conversation_id, sequence)`. When two routing decisions target the same conversation (e.g., trigger_match start then signal_match), the second insert silently fails via try/catch. Dashboard shows only the first routing event per conversation.

- **Impact:** Observability degradation only. Routing functions correctly.
- **Affected:** CORR-06 (event.routed emission)
- **Fix direction:** Use negative sentinel values, max(sequence)+1 query, or per-event synthetic conversation IDs.

**2. work:register and work:query orphaned from agent definitions (low)**

Both tools are registered in `tool-factories.ts:375-377` but zero production agent definition YAML files include them in their `tools:` array. Agents can't call tools not in their definition. The auto-registration path (executor.start() with entityRef from router) works. Agent-initiated registration is unreachable.

- **Impact:** CORR-03/CORR-04 infrastructure complete but agents can't actively use it mid-conversation.
- **Affected:** CORR-03, CORR-04
- **Fix direction:** Add `work:register` and `work:query` to dev-agent and product-agent definition.yaml tools lists.
