| Flow | Steps | Status |
|------|:-----:|--------|

**Flow 1: Full Task Lifecycle** — Agent creates task → MCP call with X-Task-ID → correlation recorded → webhook lookup finds taskId → routeViaTask signals active conversation → task_context injected → agent completes with handoff

**Flow 2: Task Reopening** — Conversation completes → external event → correlation lookup → routeViaTask creates new conversation with taskId → task_context auto-injected → agent consumes handoff via get_task_context

**Flow 3: Conversation Reopen** — Dashboard reopen button → POST /conversations/:id/reopen → world-state injection → agent resumes with artifact verification constraint

**Flow 4: Sub-task Delegation** — Agent creates subtask with parentId → depth ≤ 5, subtasks ≤ 10, no circular delegation enforced → subtask conversation gets parent handoff as context

**Flow 5: Backward Compatibility** — Event without taskId → router guard skips routeViaTask → EventRouter handles via existing fast-path/slow-path → worker loop runs without task_context injection

### Manual E2E Validation (2026-02-08)

E2E flows were initially verified via static code path tracing. Manual runtime testing against live services uncovered 6 issues, all fixed:

| Commit | Fix | Category |
|--------|-----|----------|
| `0a02a55` | Migration journal entries missing for 0004/0005 — `db:migrate` was skipping task tables | Infrastructure |
| `6b9e4c3` | Router had no way to reopen completed conversations — added `reopen_conversation` router tool | Missing capability |
| `694e9e7` | Product-agent completed tasks prematurely — prompt guidance + `complete_task` same-conversation idempotency | Agent behavior |
| `68fb973` | Event content flushed after re-enqueue — `initSequence()` read stale sequence numbers. Moved to atomic buffer flush before re-enqueue | Race condition |
| `c5534d7` | Slack sends both `message.created` and `app_mention.created` for @mentions — top-level messages fell through to slow-path causing duplicate signals. Added `AdapterIgnore` sentinel | Deduplication |
| `5a42f70` | Router classified "unclear" thread replies as ignore for waiting product-agent conversations — router should deliver, not filter conversational intent | Routing logic |

**Key takeaway:** Static code tracing verified structural wiring but missed runtime issues — migration journal gaps, race conditions, Slack event deduplication, and agent behavioral edge cases all required live testing to surface.
