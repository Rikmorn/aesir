# Milestone v2.2: Agentic Architecture

**Status:** SHIPPED 2026-01-31
**Phases:** 28-36
**Total Plans:** 30

## Overview

Replace LangGraph state machine architecture with agentic tool-use loops where LLMs make control flow decisions. Agents reason about what to do, use tools to act, observe results, and adapt -- instead of following predetermined graphs. The journey starts with the core runtime primitive, builds up through database schema, tools, and agents, then validates the full end-to-end flow works better than v2.1's fixed graphs.

## Milestone Summary

**Key Decisions:**
- Replace @langchain/* with @anthropic-ai/sdk for native tool-use
- Agentic tool-use loops replace LangGraph state machine graphs
- Orchestrator + focused sub-agents pattern for dev agent
- Hybrid smart router (deterministic rules + LLM for ambiguous events)
- Semantic context snapshots replace LangGraph checkpoint persistence
- In-process sub-agent spawning (nested function calls, not Temporal activities)
- Non-streaming LLM calls for backend agents in Temporal
- Custom `runAgentLoop()` over SDK's `toolRunner()` for control over tracing/budgets

**Issues Resolved:**
- Context overflow in long conversations (LLM-based compaction)
- XML injection in conversation history (entity escaping)
- Phase tag extraction fragility (fallback inference from execution trace)
- Workflow signal race condition (retry-with-backoff)
- Cancellation detection via hardcoded phrases (removed, agent handles via reasoning)

**Issues Deferred:**
- tool_result trace type not recorded (runAgentLoop lacks onToolResult callback)
- dev-agent/classification/approval.ts dead code not deleted
- Context snapshot JSONB fields have no size limits

**Technical Debt Incurred:**
- TRAC-02 partial: 4 of 5 trace types recorded (tool_result deferred)
- Legacy approval.ts file exists but not imported (dead code)
- No JSONB size constraints on context snapshots
