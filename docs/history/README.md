## Retrieving what was not kept

The GSD planning tree (`.planning/`, ~1,090 files: per-plan PLAN/SUMMARY/VERIFICATION records, per-phase research and context) was deleted from the working tree in the 2026-09 reset. It is intact in git history:

```bash
git show v2.9:.planning/ROADMAP.md                       # any file at the last v2.9 commit
git show v2.9:.planning/phases/84-scheduled-execution/84-01-SUMMARY.md
git ls-tree -r --name-only v2.9 -- .planning | head      # list what existed
git log --all --oneline -- .planning/phases/86-*         # history of a phase
```

The generated files above are the index into it.

Files under `specs/` and `milestones/` are as written and still cite `.planning/...` paths in prose; those resolve to siblings in this folder or to `git show v2.9:<path>`.
