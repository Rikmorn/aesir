## Fixed Issues

### ISS-017: QA agent can't fetch PR — parameter format issue (major, fixed)

QA prompt lacked explicit parameter names for `github:get_pull_request`. Fixed by adding `owner`, `repo`, and `pullNumber` (integer) to the PR diff review guidance in `qa-agent/prompt.md`.

### ISS-018: QA ends without `complete_task` — orphan delegation (critical, fixed)

After tool failures, QA ended with `end_turn` without calling `task:complete_task`. Fixed by adding a hard constraint to QA prompt: must call `task:complete_task` before ending regardless of success/failure. Also updated Communication section to clarify task system is the primary result channel.

### ISS-019: Remove `communication:reply` from QA tool list (major, fixed)

QA is delegation-only with no reply context. `communication:reply` failed because the denormalizer had nowhere to deliver. Removed from `qa-agent/definition.yaml` tools list.

### ISS-020: Timeout signal rejected despite matching expected types (critical, fixed)

Root cause: timeout scheduler created signals with `data: { timeout: true, reason }` but omitted `taskId`. The `signalMatchesPendingWait()` function performs taskId-scoped matching for `wait_for_task` waits, so the signal was rejected. Fixed by threading `metadata` (containing `taskId`) through the timeout scheduling pipeline: `schedule()` now accepts metadata, stores it in the pg-boss job, and the worker merges it into the signal's `data` field.

### ISS-021: Depth always 0 — delegation depth limit unenforced (major, fixed)

`TaskService.create()` lacked a `depth` parameter in its Zod schema and INSERT statement. The workaround of storing depth in metadata was ineffective since `parentTask.depth` always read as 0. Fixed by adding `depth` to `CreateTaskParamsSchema` and the INSERT values, and updating `delegate-task.ts` to pass `depth` directly to `create()`.

### ISS-002: `create_agent_activity` MCP tool not found (critical, fixed)

Missing Express route handler for Linear MCP tools. Fixed by adding imports and switch cases to `packages/integrations/linear/src/api/mcp.ts`.

### ISS-004: Dashboard tasks page date serialization crash (major, fixed)

Raw SQL queries return date strings, not Date objects. Fixed by using `String(row.field)` instead of `(row.field as Date).toISOString()`.

### ISS-010: Dashboard SQL `ANY()` array bind parameter failure (major, fixed)

Drizzle passes JS arrays as scalar bind params. Fixed by replacing `ANY()` with `IN` using `sql.join`.

### ISS-011: `communication_notify` action intent empty parameter (major, fixed)

Denormalizer sent `parameter: ""` for action activities. Fixed by splitting text on first space (verb + rest) with thought fallback.

### ISS-014: Delegation-activated agents shown as "Sub-agent" (minor, fixed)

`getAgentType()` only checked triggers. Fixed by also checking for `task:respond` in tool list.
