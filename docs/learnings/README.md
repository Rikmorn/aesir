# Learnings

One record per closed issue or milestone that clears the bar, linked from the close comment that produced it. Sidekick's docs layout §learnings/ states the bar, the shape, and the status line a record takes once its lesson is promoted. Sidekick's `sk-track` and `sk-milestone` write records in that shape.

Aesir adds one thing. Records written before 2026-09-30, when aesir adopted that shape, keep the shape they were written in.
