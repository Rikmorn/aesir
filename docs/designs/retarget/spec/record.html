Specification

The job record

One durable record per unit of work, stored by the platform in one place, in the shape of A2A's Task, the only foundation-governed job record in the field. Four fields are added that the standard leaves to the client. Nothing else is invented.

Fields

FieldFromMeaning
taskIdA2AServer-minted, unique; the handle every caller holds
contextIdA2AGroups related tasks and messages; the tree of a composite job shares one; parallel work is several tasks in one context
statusA2AThe state set above; terminal tasks cannot restart
history, artifactsA2AMessages exchanged on the task; first-class outputs
push configurationA2AWhere completion is delivered when the caller is remote (transport 2)
stopReasonaddedOn an interrupted state: end_turn, requires_action with the ids waited on, budget_reached, timeout. Every vendor session model converged on a typed pause reason; A2A has the state without the reason
calleraddedWho opened the task, agent or human, with the identity the gateway verified; completion delivery and policy both key on it
originaddedThe originating human request and its tool reference, copied down every hop; the one defence against authorisation drift with a measured effect
completionRecordaddedFinal status and summary written on the row whether or not delivery succeeded; the answer to the case A2A leaves undefined, the push target that is gone

What the record does not carry

  • No negotiation states. No standard has a counter-proposal. A callee that cannot take the work returns REJECTED; one that needs more returns INPUT_REQUIRED to the caller.
  • No group entity. Parallel work is several tasks in one contextId; the join (all, any, majority) is the caller's wait, not a stored object.
  • No human assignee. A human enters as a question on a task, through their tool, never as an owner. Decided.

Verdict on the task concept that exists today

The shape was right and the schema is not worth keeping. Three mechanisms are ahead of the standards and stay: the completion dispatcher with its orphan record, the result written on the row, and the lookup of the caller's current conversation so a completion survives the caller's restart. The rest is replaced: an own status enum, the handshake pause and counter-proposal, groups as entities, a human as assignee, and a depth cap of five. The 2026-09-27 code survey confirmed all three mechanisms exist and found nine implementation defects beside them (a heartbeat that fires only after a model response, no interrupt, stranded signals, the transcript as one rewritten document): keep the shape, rewrite the implementation.
