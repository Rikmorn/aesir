Connector tiers

Added 2026-09-27. Integrations tier by who registers the provider app and who wrote and reviewed the code; whether builder code sees a token is a labelled property of the bundle decided by the credential kind, not a tier. In a self-hosted platform the operator always registers the app, once per provider per installation. The decomposition →

TierPlatform providesBuilder providesPrecedent
0 · bring your ownVault, callback, consent flow, refresh, egress substitution, ingress URLClient code, adapter, its own OAuth client or a static credential; carries a labelClaude "Custom"; Zapier private; Home Assistant custom
1 · reviewedTier 0 plus review, listing, a signed bundleThe same plus tool annotations, tests, a test accountClaude "Verified"; Terraform Partner; Docker-built images
2 · platform-nativeTier 1 plus client code, adapter and provider declaration; the operator registers the appuses: github in the manifestCopilot standard connectors; Managed Agents' vault as the closest credential precedent

Not adopted, and why

CandidateVerdict
Claude Agent SDK as the harnessGives Claude Code's loop, compaction and tools on day one; makes model agnosticism a second harness. Rejected while agnosticism is a principle
Managed AgentsSupplies the harness and the deployment; the loop stays on Anthropic's side, inbound events are your application code, no zero-data-retention. The delta aesir exists for: the loop is yours, inbound is first-class, the unit of distribution is an image
Temporal, Restate, DBOS, InngestDurable execution with clean wait-for-days semantics at the price of one more stateful control plane and a step-shaped loop; DBOS is the cheapest if the claimed loop's limits are hit
Dapr, Rivet, Cloudflare Durable ObjectsThe closest fit to "one addressable process per conversation", with a placement service to run or a platform that is not your cluster
Solace or NATS event mesh between agentsTransport only; even the mesh vendors put an orchestrator on top; no production choreography among LLM agents was found
AGNTCY directory, ANP, NLIPTransport, directory and identity efforts with no job semantics; AGNTCY's signed directory records are worth watching for the registry
An LLM router or front-desk agentAn LLM in the event path is a defect; a front desk costs a hop, a delegation level and a chat product, and degrades past 30 to 40 choices
One Deployment per agentMultiplies scalers, connections, objects and rollouts by the agent count; kagent, the one shipped precedent, replaced it with a worker pool in September 2026. Kept only for a bundle with native dependencies
The Vercel AI SDK as the model portCoverage of the Anthropic surface is near complete; the cost is a major version every six to eight months and per-feature documentation lag. An own port on the shared primitives with a capability declaration per adapter was preferred; revisit if provider breadth on day one outweighs interface stability
LiteLLM or another translation proxy as the portKeeps the levers only on its passthrough route, which swaps nothing; needs Postgres and Redis for its features; shipped a credential stealer on PyPI in March 2026. Passthrough is an egress shape, not the port
A team as a platform objectNo shipped product addresses a team as anything but its lead's session, issue or thread; registered with a condition
First-registration-wins for two subscribersNo platform offers it; every one copies the event per subscription with independent retries
