### Integration Gap

**event.routed dashboard sync (Phase 78 → Phase 77)**

Phase 78 added `event.routed` as the 18th event type in the canonical agents schema and DB CHECK constraint. The dashboard schema was last synced during Phase 77 with 17 types. The 18th type was not propagated back to:
- `packages/dashboard/src/lib/schema.ts` (agentEventTypeValues)
- `packages/dashboard/src/lib/sse-types.ts` (ALL_EVENT_TYPES)
- `packages/dashboard/src/components/conversation-detail/event-icon.tsx` (icon/color mapping)

**Impact:** `event.routed` events are emitted and stored in the DB. They are invisible in the dashboard timeline. Not a critical blocker — routing decisions are logged and queryable, just not rendered in the UI.

**Fix:** 3 files, ~5 lines total. Add `"event.routed"` to the two type arrays and add an icon/color entry.
