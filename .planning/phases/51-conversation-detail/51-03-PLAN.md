  <action>
    **MessagePanel (`message-panel.tsx`):**

    This is a client component ("use client") because it uses Collapsible for system prompt collapse.

    Define local TypeScript interfaces for the Anthropic message format (do NOT import from @anthropic-ai/sdk -- keep dashboard decoupled):

    ```typescript
    interface AnthropicMessage {
      role: "user" | "assistant";
      content: string | ContentBlock[];
    }

    interface ContentBlock {
      type: "text" | "tool_use" | "tool_result";
      text?: string;
      name?: string;
      id?: string;
      input?: Record<string, unknown>;
      content?: string | ContentBlock[];
      is_error?: boolean;
      tool_use_id?: string;
    }
    ```

    **MessagePanel component:**
    - Props: `{ messages: unknown[] }`
    - Cast messages to `AnthropicMessage[]` defensively
    - If messages array is empty, show an "No messages recorded" empty state
    - Detect system prompt: if the first message has `role === "user"` and its content is a single large text block (or specifically check the structure), render it as a "System Prompt" block, collapsed by default using Collapsible
    - For each message, render a MessageBlock

    **MessageBlock (private component):**
    - Differentiate user vs assistant messages visually:
      - Assistant: left-aligned, `bg-muted` background
      - User: left-aligned, `bg-primary/5` background (subtle tint, NOT right-aligned -- this is a debug view, not a chat app)
    - Show role label: "User" or "Assistant" with appropriate styling
    - Handle content as string (wrap in text block) or array of ContentBlock

    **ContentBlockRenderer (private component):**
    - `type: "text"`: Render with `whitespace-pre-wrap` for multiline text
    - `type: "tool_use"`: Render as a styled block with tool name label and JsonPayload for input params. Use a distinct style (e.g., `border-l-2 border-l-purple-500 bg-muted/30 p-3 rounded`)
    - `type: "tool_result"`: Render result content with JsonPayload. If `is_error === true`, apply error styling (`border-l-2 border-l-destructive bg-destructive/5`). Show "(Error)" label for error results.
    - Handle `content` field that can be string or array: `typeof content === "string" ? content : JSON.stringify(content, null, 2)`

    Import JsonPayload from `./json-payload` for rendering tool inputs and results.

    **MetadataSidebar (`metadata-sidebar.tsx`):**

    This is a client component ("use client") because it uses Collapsible for sidebar toggle.

    - Props: `{ conversation: ConversationDetail; children?: ChildConversation[] }` (import types from services/conversations)
    - The entire sidebar content is wrapped in a Collapsible, defaultOpen={true}
    - Header: "Metadata" title with a CollapsibleTrigger button (ChevronDown icon)
    - Collapsing hides the metadata content, keeping only the header visible

    **Metadata fields to display (inside CollapsibleContent):**

    1. **Status** -- Use the existing StatusBadge component (import from @/components/conversations/status-badge)
    2. **Conversation ID** -- Full ID in monospace font, small text
    3. **Agent** -- agentDefinitionId and version (e.g., "dev-agent v1.0")
    4. **Retries** -- retryCount number
    5. **Error** -- errorMessage in red/destructive styling, only if not null
    6. **Parent Conversation** -- If parentConversationId is not null, render as a Next.js Link to `/conversations/${parentConversationId}`. Show truncated ID.
    7. **Child Conversations** -- If children array is non-empty, list each with:
       - Agent definition ID
       - StatusBadge
       - Link to `/conversations/${child.id}`
    8. **Timestamps** -- Created, Updated, Last Event (using formatRelativeTime)
    9. **Artifacts** -- If artifacts object has keys, render each key-value pair. Values that look like URLs should be rendered as links.

    Use Separator between sections. Use consistent label/value pattern: label in `text-sm font-medium text-muted-foreground`, value in `text-sm`.

  <action>
    Create the directory `packages/dashboard/src/app/conversations/[id]/` and the page component.

    **Page component (`page.tsx`):**

    This is an async server component (no "use client").

    ```typescript
    import { notFound } from "next/navigation";
    import Link from "next/link";
    ```

    **Props interface:**
    ```typescript
    interface ConversationDetailPageProps {
      params: Promise<{ id: string }>;
    }
    ```

    CRITICAL: `params` is a Promise in Next.js 15. Must `await params` before accessing `id`.

    **Data fetching:**
    - Await params to get the conversation ID
    - Fetch all data in parallel using Promise.all:
      ```typescript
      const [conversation, events, messages] = await Promise.all([
        getConversationById(id),
        getConversationEvents(id),
        getConversationMessages(id),
      ]);
      ```
    - If conversation is null, call `notFound()` for 404
    - After conversation is confirmed, fetch children (needs the conversation to exist first, but can also be done in parallel if we accept that a non-existent conversation returns empty children):
      ```typescript
      const children = await getChildConversations(id);
      ```
      Or better: include it in the Promise.all since getChildConversations handles missing IDs gracefully (returns empty array).

    **Layout structure:**

    ```
    <main className="container mx-auto py-8 px-4">
      <!-- Breadcrumb / back navigation -->
      <div className="mb-6">
        <Link href="/conversations">← Back to Conversations</Link>
        <h1>{conversation.agentDefinitionId}</h1>
        <p className="text-sm text-muted-foreground font-mono">{conversation.id}</p>
      </div>

      <!-- Three-panel grid -->
      <div className="grid grid-cols-1 lg:grid-cols-[1fr,1fr,300px] gap-6">
        <!-- Left: Event Timeline -->
        <div className="border rounded-lg p-4 overflow-auto" style={{ maxHeight: "80vh" }}>
          <h2>Event Timeline</h2>
          <p className="text-sm text-muted-foreground mb-4">{events.length} events</p>
          <EventTimeline events={events} />
        </div>

        <!-- Center: Messages -->
        <div className="border rounded-lg p-4 overflow-auto" style={{ maxHeight: "80vh" }}>
          <h2>Messages</h2>
          <p className="text-sm text-muted-foreground mb-4">{messages.length} messages</p>
          <MessagePanel messages={messages} />
        </div>

        <!-- Right: Metadata Sidebar -->
        <div className="border rounded-lg p-4 overflow-auto" style={{ maxHeight: "80vh" }}>
          <MetadataSidebar conversation={conversation} children={children} />
        </div>
      </div>
    </main>
    ```

    **Responsive behavior:**
    - On large screens (`lg:`): three-column grid with fixed 300px sidebar
    - On smaller screens: stacks vertically (single column)
    - Each panel has independent scrolling via `overflow-auto` and `maxHeight: 80vh`

    **Imports needed:**
    - `notFound` from "next/navigation"
    - `Link` from "next/link"
    - `getConversationById`, `getConversationEvents`, `getConversationMessages`, `getChildConversations` from "@/services/conversations"
    - `EventTimeline` from "@/components/conversation-detail/event-timeline"
    - `MessagePanel` from "@/components/conversation-detail/message-panel"
    - `MetadataSidebar` from "@/components/conversation-detail/metadata-sidebar"

    **Important notes:**
    - This page is navigated to from the conversations list table (columns.tsx already has `Link href={/conversations/${row.original.id}}`)
    - The `notFound()` call uses Next.js built-in 404 handling
    - All data fetching happens server-side (async server component), no client-side useEffect
    - Do NOT use `children` as a prop name if it conflicts with React's reserved prop -- use `childConversations` instead
