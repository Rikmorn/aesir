    **Component structure:**

    The file exports `EventTimeline` and contains a private `EventItem` component.

    **EventTimeline:**
    - Props: `{ events: ConversationEvent[] }` (import ConversationEvent from services/conversations)
    - Renders a vertical timeline with a left border rail for visual continuity
    - Maps over events and renders an EventItem for each, passing `isSubAgent` prop
    - Determine sub-agent status: `const isSubAgent = event.parentInstanceId !== null`
    - Use `event.id` as the React key
    - If events array is empty, show an "No events recorded" empty state

    **EventItem (private, same file):**
    - Props: `{ event: ConversationEvent; isSubAgent: boolean }`
    - Uses shadcn/ui Collapsible (import from @/components/ui/collapsible)
    - Initialize `isOpen` state: `useState(event.type === "tool.failed")` -- auto-expand failures per spec
    - Failed events get a red/destructive left border or background tint for visual distinction (e.g., `border-l-2 border-l-destructive` or `bg-destructive/5`)

    **Sub-agent event nesting (CONV-07):**
    - When `isSubAgent` is true, apply visual nesting to the event card:
      - Add `ml-6` (left margin) for indentation
      - Add `border-l-2 border-l-muted-foreground/20` (subtle left border) to visually group sub-agent events
      - These styles stack with error styling (a sub-agent tool.failed gets both indentation AND red border)
    - For sub-agent `agent.started` events: show the agent type and task excerpt from `payload.agentType` and `payload.task` as a secondary label below the type label (e.g., "researcher: Explore codebase structure")
    - For sub-agent `agent.completed` events: show `payload.status` and `payload.outputPreview` (truncated) as a secondary label
    - One level of nesting is sufficient for MVP: all events with `parentInstanceId !== null` get the same indentation depth regardless of spawn depth. No recursive nesting.

    **CollapsibleTrigger row (always visible):**
    - Chevron icon (ChevronRight when collapsed, ChevronDown when open)
    - EventIcon for the event type
    - Formatted event type label via formatEventType()
    - For tool.called events: show the tool name from payload (`payload.tool_name` or `payload.name`) after the type label
    - Relative timestamp via formatRelativeTime() on the right side
    - Duration badge if `event.durationMs` is not null (e.g., "142ms")
    - Token count badges if `event.tokenCountInput` or `event.tokenCountOutput` is not null (e.g., "1.2k in / 0.5k out" using formatTokenCount)
    - Use `flex items-center gap-2 w-full` for the trigger layout

    **CollapsibleContent (expanded section):**
    - Render the full payload via `<JsonPayload data={event.payload} />`
    - If event has token counts, show formatted input/output token counts
    - If event has durationMs, show it formatted
    - Add a subtle top border (`border-t mt-2 pt-2`) to separate from trigger

    **Styling approach (Linear/Vercel-inspired):**
    - Each event is a compact row with hover state (`hover:bg-accent/50`)
    - Use `rounded-lg border` for each event card
    - Timeline spacing: `space-y-2` between events
    - Muted color scheme for non-error events, red tints for errors
    - Keep it functional: no animation beyond Collapsible's built-in open/close

    **Important:**
    - Import formatEventType and formatRelativeTime from @/lib/format
    - Import formatTokenCount from @/lib/format for token display
    - Import EventIcon from ./event-icon

    - Import ChevronDown, ChevronRight from lucide-react
