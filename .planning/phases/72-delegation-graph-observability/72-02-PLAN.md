- Return `{ nodes: layoutedNodes, edges }`

**Delegation graph (delegation-graph.tsx):**
"use client" directive. This is the React Flow container.

Import `@xyflow/react/dist/style.css` at the top (CRITICAL: without this, graph has no styling).

Define `nodeTypes` and `edgeTypes` as module-level constants OUTSIDE the component (CRITICAL: referential equality prevents re-mounts):
```typescript
const nodeTypes = { task: TaskNodeComponent };
const edgeTypes = { delegation: DelegationEdgeComponent };
```

Accept props: `nodes: Node[]`, `edges: Edge[]`, `onNodeClick: (nodeId: string) => void`

Transform tree data into React Flow nodes and edges:
- Create a `transformTreeToGraph(treeNodes, events, health)` function
- Each TaskTreeNode becomes a React Flow node with type 'task' and TaskNodeData
- Each parent-child relationship becomes a React Flow edge with type 'delegation' and DelegationEdgeData
- Edge state determined by: child task status + whether orphaned signal exists for this edge
  - child.status === 'created' && no handshake → 'pending'
  - child.status === 'active' → 'active'
  - child.status === 'completed' && not orphaned → 'completed'
  - child.status === 'completed' && orphaned → 'orphaned' (green node + dashed amber edge)
  - child.status === 'cancelled' && rejected → 'rejected'
  - child has timeout event → 'timeout'
  - child.status === 'failed' → 'failed'

Apply dagre layout via `getLayoutedElements()`.

Render `<ReactFlow>` with:
- nodes, edges, nodeTypes, edgeTypes
- `fitView` prop for initial zoom-to-fit
- `onNodeClick` handler
- Controls component (zoom in/out/fit)
- MiniMap component (for context in larger trees)
- Default viewport settings
- `proOptions={{ hideAttribution: true }}` (clean UI, or keep attribution if preferred)

**Live task graph (live-task-graph.tsx):**
"use client" directive. Client wrapper that owns polling state and coordinates graph + future detail panel/timeline.

Accept: taskId, initialTree (serialized nodes/events/health)

State:
- tree (nodes, events, health) -- initialized from props
- selectedNodeId (string | null) -- for detail panel (panel itself added in Plan 03)
- isPolling (boolean) -- starts true if not all terminal, false otherwise

`useEffect` for 30s polling:
- If `!isPolling`, skip (no interval)
- `const interval = setInterval(async () => { ... }, 30_000)`
- Fetch from `/dashboard/api/tasks/${taskId}/tree`
- On success: update tree state, check `isTreeTerminal()` and set `isPolling(false)` if all terminal
- Use `AbortController` in cleanup for in-flight requests on unmount
- Return `() => clearInterval(interval)` cleanup

`isTreeTerminal(nodes)`: every node has status in ['completed', 'failed', 'cancelled']

New events fade-in: Track previous node/event IDs, mark new ones. Apply a brief CSS `animate-fade-in` class (0.5s background highlight) that auto-removes. This is a subtle UX touch -- if complex, just skip and add nodes normally.

Node click handler: `onNodeClick = (nodeId) => setSelectedNodeId(nodeId === selectedNodeId ? null : nodeId)`. Canvas click: `setSelectedNodeId(null)`.
