**Task detail panel (task-detail-panel.tsx):**
"use client" directive. Right-side drawer that opens when a node is clicked.

Accept props:
- node: TaskTreeNode | null (null = panel hidden)
- events: TimelineEvent[] (filtered to this node's task)
- onClose: () => void

Panel layout per user decision (top to bottom):
1. **Header**: Entity name (text-lg font-semibold), status badge (reuse or adapt StatusBadge from conversations -- map task status values), elapsed time (relative from createdAt to now or completedAt)
2. **Full task description**: title + objective in a section with "Description" label. Display objective in a text block if present.
3. **Handshake detail**: Show if task has delegation-related metadata. Display accepted/rejected status, optional estimate (from metadata), timestamp, rejection reason if applicable. Look for handshake info in task metadata or in timeline events with type 'tool.succeeded' and payload matching 'task:respond'.
4. **Result** (terminal states only): If task status is 'completed' or 'failed' and completion_result exists, render it. For completion: show summary and artifacts keys. For failure: show reason and partial results. Use a code-like block or key-value display for the JSON content. Skip this section entirely for non-terminal tasks.
5. **Signals**: Compact list of signals sent/received for this task. Filter timeline events to signal.received and signal.orphaned types. Each signal row: timestamp + signal type + brief payload. If no signals, show "No signals" in muted text.
6. **"View conversation" link**: If node has conversationId, render a Link to `/conversations/${conversationId}`. Use lucide ExternalLink icon. If no conversationId, show "No conversation" in muted text.

Panel positioning:
- Absolutely positioned on the right side of the graph container
- Width ~320px, full height, bg-card border-l shadow-lg
- Slide-in animation (translate-x transition)
- Close button (X icon) in the top-right corner
- Scrollable content area (overflow-y-auto)

**Orphan-specific rendering per user decision:**
When the node's parent edge is orphaned (check events for signal.orphaned referencing this task):
- Show banner: "Orphaned -- result available but undelivered" in amber
- Display completion_result payload inline
- If available in events, show reason why callback failed (from signal.orphaned event payload)

**Delegation timeline (delegation-timeline.tsx):**
"use client" directive. Collapsible panel below the graph.

Accept props:
- events: TimelineEvent[]
- selectedNodeId: string | null (for highlighting)
- onEventClick: (taskId: string) => void (for bidirectional linking)

State:
- isExpanded: boolean (default false per user decision)

Collapsible bar:
- Collapsed: just a clickable bar "Timeline ({N} events)" with ChevronDown icon
- Expanded: event list below the bar

Layout when expanded:
- The parent container should adjust: graph area ~60% height, timeline ~40% height
- Timeline has its own scroll (overflow-y-auto, max-height based on container)

Event list:
- Render each event as a `<TimelineEventRow>` component
- Events already filtered by service layer to delegation lifecycle types
- When selectedNodeId is set, highlight events belonging to that node's task (background accent)
- Assign a ref/id to each event row for scroll-to functionality

Event type mapping to human-readable descriptions:
- agent.started → "{entityName} started working"
- agent.completed → "{entityName} completed"
- agent.paused → "{entityName} paused (waiting)"
- agent.resumed → "{entityName} resumed"
- signal.received → "Signal received: {payload.signalType}"
- signal.orphaned → "Signal orphaned (delivery failed)"
- tool.called with task:delegate → "{entityName} delegated to {targetEntity}"
- tool.called with task:respond → "{entityName} responded: {accepted/rejected}"
- tool.called with task:complete → "{entityName} completed task"
- tool.called with wait_for_task → "{entityName} waiting for delegated task"

Color coding per event type (same palette as edges per user decision):
- Started/resumed: blue
- Completed: green
- Failed: red
- Paused/waiting: amber
- Signal received: blue
- Signal orphaned: amber
- Delegation: blue
- Rejection: gray

- Description: one-line text from the event type mapping above
