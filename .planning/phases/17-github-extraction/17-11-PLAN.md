       # GitHub Integration

       This is the `@aesir/integration-github` package - an independent GitHub integration.

       ## Package Structure

       ```
       packages/integrations/github/
       ├── src/
       │   ├── api/           # HTTP routes (webhooks, oauth, routes)
       │   ├── client/        # Octokit client factory and types
       │   ├── db/            # Database schema (github.*), credential store
       │   ├── oauth/         # Token management, flow utilities
       │   ├── operations/    # Branch, commit, PR operations
       │   ├── webhooks/      # Signature verification, payload parsing
       │   ├── types/         # Config, errors
       │   └── main.ts        # Service entry point
       ├── Dockerfile
       └── package.json
       ```

       ## Key Patterns

       ### Webhook Signature Verification
       Uses `@octokit/webhooks-methods` for timing-safe verification:
       ```typescript
       import { verify } from "@octokit/webhooks-methods";
       const valid = await verify(secret, rawBody, signature);
       ```
       GitHub uses `X-Hub-Signature-256` header with `sha256=` prefix.

       ### Credential Storage
       - Database schema: `github.*` (separate from Linear's `linear.*`)
       - Credentials keyed by `owner` (org/user), not workspace_id
       - Optional `installation_id` for future GitHub Apps support

       ### Error Handling
       ```typescript
       import { GitHubError } from "@aesir/integration-github";
       throw new GitHubError("INT_GITHUB_API", "Failed to create branch", { cause: err });
       ```

       ## Running Locally

       ```bash
       # Set env vars
       export GITHUB_CLIENT_ID=xxx
       export GITHUB_CLIENT_SECRET=xxx
       export GITHUB_WEBHOOK_SECRET=xxx

       # Run migration
       pnpm --filter @aesir/integration-github migrate

       # Start service
       pnpm --filter @aesir/integration-github build
       node packages/integrations/github/dist/main.js
       ```

       ## Testing

       ```bash
       pnpm --filter @aesir/integration-github test
       ```

       ## Don't

       - Don't use timingSafeEqual directly - use @octokit/webhooks-methods
       - Don't parse JSON before signature verification
       - Don't import from `packages/integrations/src/github/` (use package import)
       ```
