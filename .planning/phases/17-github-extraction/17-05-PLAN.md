  <files>

  <action>
    1. Create packages/integrations/github/src/oauth/token-store.ts:
       - Import createPinoLogger from @aesir/common
       - Import GitHubCredentialStore from ../db/credential-store.js
       - Import GitHubError from ../types/errors.js

       - Define GitHubTokens interface:
         - accessToken: string (required)
         - refreshToken?: string (optional - GitHub OAuth apps may not have this)
         - tokenType?: string
         - scope?: string
         - expiresAt?: Date

       - Create loadGitHubTokens function:
         ```typescript
         export async function loadGitHubTokens(
           credentialStore: GitHubCredentialStore,
           owner: string,
         ): Promise<GitHubTokens | null>
         ```
         - Use credentialStore.getByOwner(owner)
         - Unwrap ResultAsync with match()
         - Return null if not found, throw on error
         - Log at debug level

       - Create saveGitHubTokens function:
         ```typescript
         export async function saveGitHubTokens(
           credentialStore: GitHubCredentialStore,
           owner: string,
           tokens: GitHubTokens,
         ): Promise<string>
         ```
         - Use credentialStore.store()
         - Unwrap ResultAsync with match()
         - Return credential ID
         - Log at info level

       - Export DEFAULT_OWNER constant:
         ```typescript
         export const DEFAULT_OWNER = "default";
         ```
         - For single-tenant deployments where owner isn't specified
  </action>
  <verify>
    pnpm --filter @aesir/integration-github typecheck
  </verify>
  <done>Token store functions for loading and saving GitHub tokens</done>

       - Import GitHubCredentialStore from ../db/credential-store.js
       - Import loadGitHubTokens, DEFAULT_OWNER from ./token-store.js
       - Import GitHubError from ../types/errors.js

       - Create createGitHubClientFromDatabase function:
         ```typescript
         export async function createGitHubClientFromDatabase(
           credentialStore: GitHubCredentialStore,
           owner: string = DEFAULT_OWNER,
         ): Promise<Octokit>
         ```
         - Load tokens using loadGitHubTokens
         - Throw GitHubError("INT_GITHUB_TOKEN", "No credentials found") if null
         - Create client with createGitHubClient({ token: tokens.accessToken })
         - Return configured Octokit instance
         - Log at debug level

       - Create generateOAuthState function:
         ```typescript
         export function generateOAuthState(): string
         ```
         - Generate 32-byte random hex string using crypto.randomBytes
         - Used for CSRF protection in OAuth flow

       - Create buildAuthorizationUrl function:
         ```typescript
         export function buildAuthorizationUrl(options: {
           clientId: string;
           redirectUri: string;
           scope?: string;
           state: string;
         }): string
         ```
         - Build URL: https://github.com/login/oauth/authorize
         - Include client_id, redirect_uri, scope, state as query params
         - Default scope: "repo,read:org"
