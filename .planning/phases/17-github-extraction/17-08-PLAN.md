       ```dockerfile
       FROM node:22-slim AS builder

       # Install pnpm
       RUN corepack enable && corepack prepare pnpm@9.15.0 --activate

       WORKDIR /app

       # Copy workspace root files
       COPY pnpm-workspace.yaml package.json pnpm-lock.yaml tsconfig.base.json ./

       # Copy package files for all required packages
       COPY packages/common/package.json packages/common/
       COPY packages/integrations/github/package.json packages/integrations/github/

       # Install dependencies
       RUN pnpm install --frozen-lockfile

       # Copy source files
       COPY packages/common packages/common
       COPY packages/integrations/github packages/integrations/github

       # Build
       RUN pnpm --filter @aesir/common build && \
           pnpm --filter @aesir/integration-github build
       ```

       Stage 2 - Runtime:
       ```dockerfile
       FROM node:22-slim AS runtime

       # Install pnpm
       RUN corepack enable && corepack prepare pnpm@9.15.0 --activate

       # Create non-root user
       RUN groupadd -g 1001 aesir && \
           useradd -u 1001 -g aesir -s /bin/bash -m aesir

       WORKDIR /app

       # Copy workspace config
       COPY pnpm-workspace.yaml package.json pnpm-lock.yaml ./

       # Copy built packages
       COPY --from=builder /app/packages/common/package.json packages/common/
       COPY --from=builder /app/packages/common/dist packages/common/dist
       COPY --from=builder /app/packages/integrations/github/package.json packages/integrations/github/
       COPY --from=builder /app/packages/integrations/github/dist packages/integrations/github/dist

       # Install production dependencies only
       RUN pnpm install --prod --frozen-lockfile

       # Switch to non-root user
       USER aesir

       WORKDIR /app/packages/integrations/github

       EXPOSE 3002

       CMD ["node", "dist/main.js"]
       ```

       # @aesir/integration-github

       GitHub integration package for the Aesir platform. Provides OAuth authentication,
       webhook handling, and GitHub API operations (branches, commits, pull requests).

       ## Installation

       This package is part of the Aesir monorepo. Install from workspace root:

       ```bash
       pnpm install
       ```

       ## Usage

       ### As a Standalone Service

       Run the GitHub integration as an independent HTTP service:

       ```bash
       # Set environment variables (see .env.example)
       export GITHUB_CLIENT_ID=your_client_id
       export GITHUB_CLIENT_SECRET=your_client_secret
       export GITHUB_WEBHOOK_SECRET=your_webhook_secret

       # Run database migration
       pnpm --filter @aesir/integration-github migrate

       # Start the service
       pnpm --filter @aesir/integration-github build
       node packages/integrations/github/dist/main.js
       ```

       Or with Docker:

       ```bash
       docker build -f packages/integrations/github/Dockerfile -t aesir-github .
       docker run -p 3002:3002 --env-file .env aesir-github
       ```

       ### As a Library

       Import GitHub operations into other packages:

       ```typescript
       import {
         createGitHubClient,
         createBranch,
         createCommit,
         createPullRequest,
       } from "@aesir/integration-github";

       // Create client
       const octokit = createGitHubClient({ token: process.env.GITHUB_TOKEN });

       // Create a branch
       const branch = await createBranch(octokit, {
         owner: "org",
         repo: "repo",
         branchName: "feature/new-feature",
         baseBranch: "main",
       });

       // Create a commit
       const commit = await createCommit(octokit, {
         owner: "org",
         repo: "repo",
         branch: "feature/new-feature",
         message: "Add new feature",
         files: [{ path: "src/feature.ts", content: "export const x = 1;" }],
       });

       // Create a pull request
       const pr = await createPullRequest(octokit, {
         owner: "org",
         repo: "repo",
         title: "Add new feature",
         body: "This PR adds a new feature",
         head: "feature/new-feature",
         base: "main",
       });
       ```

       ## API Endpoints

       When running as a service:

       | Endpoint | Method | Description |
       |----------|--------|-------------|
       | `/health` | GET | Health check |
       | `/webhooks/github` | POST | GitHub webhook receiver |
       | `/oauth/github/authorize` | GET | Start OAuth flow |
       | `/oauth/github/callback` | GET | OAuth callback |

       ## Environment Variables

       See `.env.example` for all configuration options.

       ### Required

       - `GITHUB_CLIENT_ID` - GitHub OAuth App client ID
       - `GITHUB_CLIENT_SECRET` - GitHub OAuth App client secret
       - `GITHUB_WEBHOOK_SECRET` - Secret for webhook signature verification

       ### Optional

       - `PORT` - HTTP port (default: 3002)
       - `NODE_ENV` - Environment (default: development)
       - `LOG_LEVEL` - Logging level (default: info)
       - `OAUTH_CALLBACK_URL` - OAuth callback URL
       - `DB_*` - Database connection settings
       - `CREDENTIAL_ENCRYPTION_KEY` - 64-char hex key for token encryption

       ## Database

       This package uses the `github.*` PostgreSQL schema namespace:

       - `github.credentials` - OAuth token storage
       - `github.webhook_deliveries` - Webhook idempotency tracking

       Run migrations:

       ```bash
       pnpm --filter @aesir/integration-github migrate
       ```

       ## Development

       ```bash
       # Build
       pnpm --filter @aesir/integration-github build

       # Type check
       pnpm --filter @aesir/integration-github typecheck

       # Run tests
       pnpm --filter @aesir/integration-github test

       # Lint
       pnpm --filter @aesir/integration-github lint
       ```
       ```
