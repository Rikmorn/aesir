       - Import Router from express
       - Import createPinoLogger, createChildLogger, generateCorrelationId from @aesir/common
       - Import verifySignature, verifyWebhookRequest from ../webhooks/signature.js
       - Import parsePRReviewPayload from ../webhooks/parser.js
       - Import config from ../types/config.js
       - Import GitHubError from ../types/errors.js
       - Import WebhookDeliveryStore from ../db/webhook-delivery-store.js

       - Define WebhookRouterDeps interface:
         - deliveryStore: WebhookDeliveryStore
         - onPRReview?: (payload: PRReviewPayload, deliveryId: string) => Promise<void>

       - Create createWebhookRouter function:
         ```typescript
         export function createWebhookRouter(deps: WebhookRouterDeps): Router
         ```
         - Create router with express.raw({ type: "application/json" }) middleware
         - POST / handler:
           1. Generate correlation ID
           2. Extract headers (x-hub-signature-256, x-github-delivery, x-github-event)
           3. Verify signature using verifySignature
           4. Return 401 if invalid signature
           5. **IDEMPOTENCY CHECK**: Check if delivery already processed:
              ```typescript
              const alreadyProcessed = await deps.deliveryStore.isDeliveryProcessed(deliveryId);
              if (alreadyProcessed.isOk() && alreadyProcessed.value) {
                logger.info({ deliveryId }, "Duplicate webhook delivery, skipping");
                return res.status(200).json({ received: true, deliveryId, duplicate: true });
              }
              ```
           6. Parse payload based on event type
           7. For pull_request_review: validate with parsePRReviewPayload, call onPRReview
           8. **RECORD DELIVERY**: After successful processing:
              ```typescript
              await deps.deliveryStore.recordDelivery({
                deliveryId,
                eventType,
                payloadHash: createHash("sha256").update(body).digest("hex"),
              });
              ```
           9. Return 200 with { received: true, deliveryId }
         - Log at appropriate levels (debug for parsing, info for received, warn for invalid)

       - Create createOAuthRouter function:
         ```typescript
         export function createOAuthRouter(deps: OAuthRouterDeps): Router
         ```
         - GET /authorize:
           1. Generate OAuth state
           2. Store in oauthStates map with timestamp
           3. Optionally accept owner from query param
           4. Build authorization URL
           5. Redirect to GitHub

         - GET /callback:
           1. Extract code and state from query
           2. Validate state exists and not expired (10 min)
           3. Exchange code for token via fetch to https://github.com/login/oauth/access_token
           4. Save tokens using saveGitHubTokens
           5. Return success page or redirect
           6. Clean up state from map
