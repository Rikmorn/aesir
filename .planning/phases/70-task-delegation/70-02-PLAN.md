Output: respond-task.ts tool factory, tool-factories registration, main.ts bootstrap wiring.

  1. **respond-task.ts**: Create the task:respond tool factory. Follow the create-task.ts pattern.

     Input schema (Zod -- per locked decision on handshake behavior):
     - `taskId: z.string().min(1)` -- the delegated task to respond to
     - `response: z.enum(["accept", "reject"])` -- accept or reject the delegation
     - `estimate: z.string().optional()` -- free-text estimate, used with accept (e.g., "~15 minutes")
     - `reason: z.string().optional()` -- rejection reason, used with reject

     Factory signature: `createRespondTaskTool(ctx: ToolContext): ToolDefinition`

     Execute logic:
     a. Check `ctx.delegationDeps` exists, return error if not.
     b. Parse input with safeParse. Return validation errors if invalid.
     c. Get the delegated task via `deps.taskService.get(parsed.taskId)`.
        - If not found: return error "Task not found: {taskId}"
        - If no `parent_id`: return error "This task has no parent -- nothing to respond to. This tool is for responding to delegated tasks."
     d. Find the delegator's active conversation: `deps.executor.findActiveForTask(task.parent_id)`.
        - If null (orphan case): Return non-error message: "Delegator conversation not found (may have timed out or completed). Your handshake response has been recorded. If you accepted, proceed with the work -- completion signaling will handle result delivery."
     e. Build signal (per locked decision -- self-contained payload):
        ```typescript
        const signal: Signal = {
          type: "task_handshake",
          data: {
            taskId: parsed.taskId,
            response: parsed.response,
            ...(parsed.estimate && { estimate: parsed.estimate }),
            ...(parsed.reason && { reason: parsed.reason }),
            respondedBy: ctx.agentId,
          },
          message: parsed.response === "accept"
            ? `Delegation accepted for task ${parsed.taskId}.${parsed.estimate ? ` Estimate: ${parsed.estimate}` : ""}`
            : `Delegation rejected for task ${parsed.taskId}.${parsed.reason ? ` Reason: ${parsed.reason}` : ""}`,
          source: `agent:${ctx.agentId}`,
          deduplicationId: `handshake-${parsed.taskId}`,
        };
        ```
     f. Send signal via `deps.executor.signal(parentConv.id, signal)`.
     g. If accepted, also update the task status to "active":
        ```typescript
        if (parsed.response === "accept") {
          await deps.taskService.update(parsed.taskId, { status: "active" });
        }
        ```
     h. Return success message: "Handshake {response} sent for task {taskId}. Signal delivery: {result.action}." Include estimate or reason in the message for the agent's context.

     Import Signal type from `../../../framework/types.js`. Import TaskService, ToolContext, etc.
