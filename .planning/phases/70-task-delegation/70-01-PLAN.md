  1. **delegate-task.ts**: Create the task:delegate tool factory. Follow the pattern from create-task.ts (Zod input schema, ToolContext, ToolResult return). Implementation:

     Input schema (Zod):
     - `targetEntityId: z.string().min(1)` -- the directory entity to delegate to
     - `description: z.string().min(1)` -- the delegation brief (per locked decision: only two required fields)
     - `parentTaskId: z.string().optional()` -- optional override, defaults to `ctx.taskId` (per Claude's discretion recommendation in research)

     Factory signature: `createDelegateTaskTool(ctx: ToolContext): ToolDefinition`

     Execute logic:
     a. Check `ctx.delegationDeps` exists, return error if not ("Delegation not available -- this agent is not configured for delegation.")
     b. Verify target entity exists and is active via `deps.directoryService.get(targetEntityId)`. Return error if null.
     c. Determine parentId: `parsed.parentTaskId ?? ctx.taskId ?? null`
     d. Check depth: if parentId exists, get parent task via `deps.taskService.get(parentId)`, read its `depth` field (from the DB -- it's now a column). If `parentDepth + 1 >= MAX_DELEGATION_DEPTH`, return error: "Delegation depth limit reached (3). Handle this work directly or report failure to your delegator."
     e. Compute new depth: parentId exists ? (parent task's depth + 1) : 0
     f. Create task via `deps.taskService.create()` with:
        - `parentId` (if exists)
        - `creatorType: "agent"`, `creatorId: ctx.agentId`
        - `assigneeType: entity.type`, `assigneeId: entity.id`
        - `title: parsed.description.slice(0, 100)` (truncated for display)
        - `objective: parsed.description`
        - `status: "created"` (per research recommendation: created until handshake accepted)
        - `metadata: { depth: newDepth, delegatedBy: ctx.agentId }` (delegation-specific in JSONB per Claude's discretion)
     g. Build `<delegation>` XML block:
        ```
        <delegation task_id="TASK_ID" from="AGENT_ID" depth="DEPTH" max_depth="MAX_DELEGATION_DEPTH">
        DESCRIPTION
        </delegation>
        ```
     h. Start target conversation via `deps.executor.start()`:
        - `agentDefinitionId: entity.id`
        - `correlationKey: task.id` (task ID as correlation key for deterministic conversation ID)
        - `initialMessage: delegationBlock`
        - `taskId: task.id`
     i. Return success message with task ID, conversation ID, and guidance to call `wait_for` with type `"task_handshake"` and timeout `"30s"`.

     Export: `createDelegateTaskTool`

     Also create a `buildDelegationBlock` helper function (exported for testing):
     ```typescript
     export function buildDelegationBlock(params: {
       taskId: string; from: string; depth: number; maxDepth: number; description: string;
     }): string
     ```
