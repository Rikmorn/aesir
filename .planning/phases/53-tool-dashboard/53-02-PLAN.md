**permission-matrix.tsx:** Server component showing agent x tool permission grid.

Props:
```typescript
interface PermissionMatrixProps {
  cells: PermissionCell[];
  agents: AgentSummary[];
}
```

Implementation:
- Extract unique tool refs from cells (sorted by namespace, then name)
- Extract unique agent IDs from cells (sorted alphabetically)
- Only show MCP-namespaced tools (linear, github, slack) -- codebase and coordination tools don't have MCP permissions
- Render a Table with:
  - Header row: first cell empty, then one column per agent
  - Body rows: one per tool ref, first cell shows the tool ref (e.g., "linear:get_issue"), then cells for each agent
  - Each cell shows permission status:
    - Both YAML and MCP: green checkmark icon or "Allowed" badge
    - YAML-only mismatch: amber/yellow warning with Tooltip explaining "Defined in YAML but no MCP permission"
    - MCP-only mismatch: amber/yellow warning with Tooltip explaining "MCP permission exists but not in agent YAML"
    - Neither: empty cell or dash
  - Use color coding: green background for "both", amber/yellow background for mismatches, no background for "neither"
- If no cells (no MCP tools configured), show empty state: "No MCP tool permissions configured"
- Add a summary row or note at top showing total mismatch count if > 0
- Use Tooltip (from shadcn) for hover details on mismatch cells

Color approach for cells:
- `none` (both match): `bg-emerald-50 text-emerald-700` (light mode)
- `yaml-only`: `bg-amber-50 text-amber-700` with warning icon
- `mcp-only`: `bg-amber-50 text-amber-700` with warning icon
- No relationship: empty cell
