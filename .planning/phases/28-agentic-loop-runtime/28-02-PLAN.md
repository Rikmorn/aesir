Create `packages/agents/src/shared/agent-loop/run-agent-loop.ts` implementing the core agent loop.

**Architecture:**

The function signature:
```typescript
export async function runAgentLoop(options: AgentLoopOptions): Promise<AgentLoopResult>
```

**Internal helper: `toAnthropicTool()`**
Convert a `ToolDefinition` to the Anthropic API format using `betaZodTool()`:
```typescript
import { betaZodTool } from "@anthropic-ai/sdk/helpers/beta/zod";
```
Use `betaZodTool({ name, description, inputSchema, run: async () => "" })` to get the converted schema. Extract `name`, `description`, and `input_schema` from the result. The dummy `run` is required by the SDK but unused -- we execute tools manually. Return an `Anthropic.Tool` object.

**Internal helper: `mapStopReasonToStatus()`**
Map Anthropic `stop_reason` values to `AgentLoopStatus` (LOOP-09):
- `"end_turn"` -> `"completed"`
- `"tool_use"` -> `"completed"` (should not reach this in the mapping, but handle gracefully)
- `"max_tokens"` -> `"max_tokens"`
- `"model_context_window_exceeded"` -> `"max_tokens"`
- `"stop_sequence"` -> `"completed"`
- `"refusal"` -> `"error"`
- `"pause_turn"` -> `"completed"` (server-tool only, unused)
- `null` or unknown -> `"completed"` with warning log
Log a warning via `options.logger` for unknown stop_reason values.

**Main loop implementation (LOOP-01):**

1. Create Anthropic client: `const client = new Anthropic()` (reads ANTHROPIC_API_KEY from env)
2. Convert tools: `const anthropicTools = options.tools.map(toAnthropicTool)`
3. Initialize conversation messages array with the initial message (combine `options.context` and `options.initialMessage` into a single user message if context provided)
4. Initialize counters: `iterationCount = 0`, `totalInputTokens = 0`, `totalOutputTokens = 0`, `toolCallCount = 0`
5. Initialize trace array: `const trace: TraceStep[] = []`
6. Apply defaults: `maxIterations = options.maxIterations ?? 50`, `model = options.model ?? "claude-sonnet-4-20250514"`, `maxTokensPerResponse = options.maxTokensPerResponse ?? 16384`

**Loop body (each iteration):**

a. **Check abort signal** (LOOP-06): If `options.abortSignal?.aborted`, return result with status `"aborted"`.

b. **Check token budget** (LOOP-05): If `options.tokenBudget?.isExhausted()`, return result with status `"max_tokens"`.

c. **Check iteration limit** (LOOP-04): The while condition `iterationCount < maxIterations` handles this. If the loop exits naturally, return status `"max_iterations"`.

d. **Call LLM** (LOOP-02): Use `client.messages.create()` with:
   - `model`
   - `max_tokens: maxTokensPerResponse`
   - `system: options.systemPrompt`
   - `tools: anthropicTools` (only include if tools array is non-empty)
   - `messages: conversationMessages`
   Pass `{ signal: options.abortSignal }` as the second argument for abort support.

   Wrap in try/catch:
   - If error is `Anthropic.APIError`, log and return status `"error"` with error message as output.
   - If error is `AbortError` (from AbortSignal), return status `"aborted"`.
   - For other errors, return status `"error"`.

e. **Track tokens**: Add `response.usage.input_tokens` and `response.usage.output_tokens` to totals. Call `options.tokenBudget?.deduct(response.usage.input_tokens, response.usage.output_tokens)`.

f. **Record LLM response trace step**: Push a `TraceStep` of type `"llm_response"` with timestamp, tokenCount, stopReason, and durationMs (measure the `messages.create` call duration).

g. **Fire onResponse callback** (LOOP-07): Call `options.onResponse?.(response)`.

h. **Handle stop_reason** (LOOP-09):
   - If `response.stop_reason !== "tool_use"`: The agent is done. Extract text content from `response.content` blocks of type `"text"`. Join them. Try to parse as JSON for `structuredOutput` (wrap in try/catch, set to undefined if not valid JSON). Return `AgentLoopResult` with mapped status, output, toolCallCount, tokenCount, trace.
   - If `response.stop_reason === "tool_use"`: Continue to tool execution below.

i. **Extract tool_use blocks**: Filter `response.content` for blocks where `type === "tool_use"`.

j. **Add assistant message to conversation**: Push `{ role: "assistant", content: response.content }`.

k. **Execute tools and collect results** (LOOP-01, LOOP-03):
   For each `tool_use` block:
   1. Check abort signal before each tool execution.
   2. Fire `options.onToolCall?.({ name: toolUse.name, input: toolUse.input, id: toolUse.id })` (LOOP-07).
   3. Record `TraceStep` of type `"tool_call"` with toolName, toolCallId, input, timestamp.
   4. Find the matching tool from `options.tools` by name.
   5. Execute: if found, `await tool.execute(toolUse.input)`. If not found, return `{ content: "Unknown tool: ${name}", isError: true }`.
   6. Wrap execute in try/catch -- on error, return `{ content: "Tool execution error: ${error.message}", isError: true }`. This ensures tool errors go back to the LLM for reasoning (LOOP-07/requirement context from TOOL-07).
   7. Record `TraceStep` of type `"tool_result"` with toolName, toolCallId, output, durationMs, timestamp.
   8. Build `Anthropic.ToolResultBlockParam`: `{ type: "tool_result", tool_use_id: toolUse.id, content: result.content, is_error: result.isError ?? false }`.
   Increment `toolCallCount` by the number of tool_use blocks in this response (counting parallel calls).

l. **Add tool results to conversation**: Push `{ role: "user", content: toolResults }` as a SINGLE user message containing ALL tool_result blocks.
   **CRITICAL**: Do NOT add any text blocks to this message. Tool results only. Text blocks alongside tool_result blocks cause empty LLM responses (see research pitfall #1).

m. **Increment iteration counter**: `iterationCount++`.

**After loop exits** (max iterations reached):
Return `AgentLoopResult` with status `"max_iterations"`, the last text output (if any), toolCallCount, tokenCount, trace.

**Update barrel export:**
Add `export { runAgentLoop } from "./run-agent-loop.js"` to `index.ts` (alongside existing exports from Plan 01).

**Implementation notes:**
- Use `performance.now()` or `Date.now()` for duration measurement.
- `structuredOutput` parsing: Only attempt JSON parse on the final text output. Use a try/catch -- if it's not valid JSON, just leave it undefined.
- The Anthropic client reads `ANTHROPIC_API_KEY` from `process.env` automatically.
- Do NOT import anything from `@langchain/*`. This file should only import from `@anthropic-ai/sdk`, `zod`, local types, and pino.
- Use `import type` where possible to minimize runtime imports.
