  <action>
Create the `packages/agents/src/shared/agent-loop/` directory with four files.

**types.ts** -- All type definitions for the agent loop runtime:

1. `ToolResult` interface:
   - `content: string` -- text content fed back to the LLM
   - `isError?: boolean` -- if true, LLM sees this as an error to reason about

2. `ToolDefinition` interface:
   - `name: string` -- tool name (must match regex `^[a-zA-Z0-9_-]{1,64}$`)
   - `description: string` -- detailed description of what the tool does
   - `inputSchema: z.ZodType` -- Zod schema for input validation
   - `execute: (input: unknown) => Promise<ToolResult>` -- execute function

3. `AgentLoopStatus` type union:
   - `"completed"` -- LLM responded with text only (end_turn, stop_sequence)
   - `"max_iterations"` -- hit iteration limit (LOOP-04)
   - `"max_tokens"` -- token budget exhausted (LOOP-05) or LLM hit max_tokens/model_context_window_exceeded
   - `"aborted"` -- AbortSignal fired (LOOP-06)
   - `"error"` -- unrecoverable error (refusal or exception)

4. `TraceStep` interface (LOOP-07, LOOP-08):
   - `type: "tool_call" | "tool_result" | "llm_response"`
   - `timestamp: string` (ISO 8601)
   - `toolName?: string`
   - `toolCallId?: string`
   - `input?: unknown`
   - `output?: unknown`
   - `tokenCount?: { input: number; output: number }`
   - `durationMs?: number`
   - `stopReason?: string`

5. `ToolCallInfo` interface (for onToolCall callback):
   - `name: string`
   - `input: unknown`
   - `id: string`

6. `ResponseInfo` -- use `import type Anthropic from "@anthropic-ai/sdk"` and alias `Anthropic.Message` for the onResponse callback parameter type. Export as `type LLMResponse = Anthropic.Message`.

7. `AgentLoopOptions` interface (LOOP-01 through LOOP-07):
   - `systemPrompt: string` -- system prompt defining agent behavior
   - `tools: ToolDefinition[]` -- available tools
   - `initialMessage: string` -- the initial task/message
   - `context?: string` -- additional context prepended to initial message
   - `model?: string` -- model to use (default handled in loop: `"claude-sonnet-4-20250514"`)
   - `maxIterations?: number` -- max loop iterations (default handled in loop: 50)
   - `maxTokensPerResponse?: number` -- max_tokens per LLM call (default handled in loop: 16384)
   - `tokenBudget?: TokenBudget` -- shared mutable token budget (import from token-budget.ts)
   - `onToolCall?: (call: ToolCallInfo) => void` -- called on every tool call
   - `onResponse?: (response: LLMResponse) => void` -- called on every LLM response
   - `abortSignal?: AbortSignal` -- for clean cancellation
   - `logger?: PinoLogger` -- optional pino logger for warnings (import type from pino)

8. `AgentLoopResult` interface (LOOP-08):
   - `status: AgentLoopStatus`
   - `output: string` -- final text output from LLM
   - `structuredOutput?: unknown` -- parsed JSON if final message contains it
   - `toolCallCount: number` -- total tool call iterations
   - `tokenCount: { input: number; output: number }` -- cumulative token usage
   - `trace: TraceStep[]` -- full execution trace

Import `z` from `zod` for `ToolDefinition.inputSchema` type. Use `import type` for Anthropic SDK types to avoid runtime dependency in the types file where possible.

**token-budget.ts** -- Mutable token budget counter (LOOP-05):

1. `TokenBudget` interface:
   - `total: number` -- total budget for the task
   - `remaining: number` -- remaining tokens (mutated by each agent loop iteration)
   - `isExhausted(): boolean` -- check if budget is exhausted
   - `deduct(input: number, output: number): void` -- deduct tokens used

2. `createTokenBudget(total: number): TokenBudget` factory function:
   - Creates a mutable budget object
   - `isExhausted()` returns `this.remaining <= 0`
   - `deduct()` subtracts `(input + output)` from remaining
   - This object is passed by reference to orchestrator and all sub-agents, so mutations are shared

Export the interface AND the factory function.

**errors.ts** -- Error classes for loop failure modes:

1. `AgentLoopError extends Error`:
   - `constructor(message: string, public readonly status: AgentLoopStatus, public readonly cause?: Error)`
   - Base class for all agent loop errors

2. `MaxIterationsError extends AgentLoopError`:
   - `constructor(iterations: number)`
   - Message: `"Agent loop hit maximum iterations limit (${iterations})"`
   - Status: `"max_iterations"`

3. `TokenBudgetExhaustedError extends AgentLoopError`:
   - `constructor(total: number, used: number)`
   - Message: `"Token budget exhausted: used ${used} of ${total} tokens"`
   - Status: `"max_tokens"`

4. `AgentAbortedError extends AgentLoopError`:
   - `constructor()`
   - Message: `"Agent loop aborted via AbortSignal"`
   - Status: `"aborted"`

**index.ts** -- Barrel export:
- `export * from "./types.js"`
- `export * from "./token-budget.js"`
- `export * from "./errors.js"`
