    **Step 2: Create `packages/agents/src/shared/tools/coordination/spawn-agent.ts`**

    Exports: `SpawnAgentDeps`, `AgentTypeConfig`, `createSpawnAgentTool`

    ```typescript
    import { z } from "zod";
    import { createId } from "@aesir/types";
    import type { PinoLogger } from "@aesir/platform";
    import { runAgentLoop } from "../../agent-loop/run-agent-loop.js";
    import type { TokenBudget } from "../../agent-loop/token-budget.js";
    import type { ToolDefinition, ToolResult } from "../../agent-loop/types.js";
    import type { TraceRecorderCallbacks } from "../../db/trace-recorder.js";
    ```

    **Interfaces:**
    ```typescript
    export interface AgentTypeConfig {
      systemPrompt: string;
      tools: ToolDefinition[];
      maxIterations: number;
      model?: string;
    }

    export interface SpawnAgentDeps {
      agentTypes: Record<string, AgentTypeConfig>;
      tokenBudget: TokenBudget;
      abortSignal?: AbortSignal;
      traceRecorder: TraceRecorderCallbacks;
      logger: PinoLogger;
    }
    ```

    **Factory function:**
    - Name: `spawn_agent`
    - Input schema: `{ agentType: z.enum(["researcher", "coder", "tester"]), task: z.string(), context?: z.string() }`
    - Description: 3-4 sentences explaining available agent types and what each does
    - Execute logic:
      1. safeParse input
      2. Look up AgentTypeConfig from `deps.agentTypes[agentType]`
      3. If not found, return isError with "Unknown agent type"
      4. Generate childInstanceId via `createId.agentInstance()`
      5. Call `deps.traceRecorder.onAgentSpawn(childInstanceId, agentType, { task, context })`
      6. Log spawn at info level
      7. Call `runAgentLoop()` with:
         - `systemPrompt`: config.systemPrompt
         - `tools`: config.tools
         - `initialMessage`: task
         - `context`: context (only set if provided, for exactOptionalPropertyTypes)
         - `maxIterations`: config.maxIterations
         - `model`: config.model (only set if provided)
         - `tokenBudget`: deps.tokenBudget (SHARED reference)
         - `abortSignal`: deps.abortSignal (only set if provided)
         - `logger`: deps.logger.child({ agentType, agentInstanceId: childInstanceId })
      8. After completion, call `deps.traceRecorder.onAgentComplete({ agentType, childInstanceId, status: result.status, toolCallCount: result.toolCallCount, tokenCount: result.tokenCount })`
      9. Log completion at info level
      10. If result.status === "error": return `{ content: "Sub-agent error: {result.output}", isError: true }`
      11. Otherwise: return `{ content: result.output }`
    - Catch all errors: return isError with "Sub-agent {agentType} failed: {message}"

    **IMPORTANT:** When building the AgentLoopOptions object for runAgentLoop(), use the mutable-then-conditional-set pattern for optional fields:
    ```typescript
    const loopOptions: AgentLoopOptions = {
      systemPrompt: config.systemPrompt,
      tools: config.tools,
      initialMessage: task,
      maxIterations: config.maxIterations,
      tokenBudget: deps.tokenBudget,
      logger: deps.logger.child({ agentType, agentInstanceId: childInstanceId }),
    };
    if (context !== undefined) { loopOptions.context = context; }
    if (config.model !== undefined) { loopOptions.model = config.model; }
    if (deps.abortSignal !== undefined) { loopOptions.abortSignal = deps.abortSignal; }
    ```
