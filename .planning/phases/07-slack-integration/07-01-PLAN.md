<task type="auto">
  <name>Task 3: Create notification functions and module exports</name>
  <files>src/integrations/slack/notifications.ts, src/integrations/slack/notifications.test.ts, src/integrations/slack/index.ts</files>
  <action>
    1. Create `src/integrations/slack/notifications.ts`:
       - Import WebClient from @slack/web-api
       - Import createLogger from ../../logging/logger.js
       - Import notification types from ./types.js
       - Create module logger

       **formatApprovalMessage(notification: ApprovalNotification): Block[]**
       - Return Block Kit blocks array:
         - Section block with mrkdwn: "*PR Ready for Review*\n{title}"
         - Section block with mrkdwn: "{summary}"
         - Section block with mrkdwn: "<{prUrl}|View Pull Request>"
         - Context block: "Task: {taskId} | Requested by: dev-agent"
       - Keep it simple — don't over-engineer Block Kit

       **formatStatusMessage(notification: StatusNotification): Block[]**
       - Return Block Kit blocks array:
         - Section block with emoji prefix based on status:
           - started: ":arrow_forward: Task Started"
           - completed: ":white_check_mark: Task Completed"
           - failed: ":x: Task Failed"
         - If details provided, context block with details

       **postNotification(client: WebClient, notification: Notification, channel: string): Promise<NotificationResult>**
       - Determine format function based on notification.type
       - Get text fallback from notification (for push notifications)
       - Call client.chat.postMessage with channel, text, blocks
       - Log info on success with timestamp
       - Return { success: true, timestamp: result.ts }
       - On error: log error, return { success: false, error: message }

       **sendApprovalRequest(client: WebClient, notification: ApprovalNotification, channel: string): Promise<NotificationResult>**
       - Thin wrapper calling postNotification
       - Exists for semantic clarity in calling code

       **sendStatusUpdate(client: WebClient, notification: StatusNotification, channel: string): Promise<NotificationResult>**
       - Thin wrapper calling postNotification

       **openDmChannel(client: WebClient, userId: string): Promise<string>**
       - Call client.conversations.open({ users: userId })
       - Return channel ID from response
       - Enables sending DMs by resolving user ID to DM channel

    2. Create `src/integrations/slack/notifications.test.ts`:
       - Mock @slack/web-api WebClient
       - Test formatApprovalMessage returns valid blocks
       - Test formatStatusMessage returns valid blocks for each status
       - Test postNotification calls chat.postMessage with correct params
       - Test postNotification returns success result
       - Test postNotification handles errors gracefully
       - Test openDmChannel calls conversations.open

    3. Create `src/integrations/slack/index.ts`:
       - Export all types from ./types.js
       - Export createSlackClient, getSlackClient from ./client.js
       - Export postNotification, sendApprovalRequest, sendStatusUpdate, openDmChannel from ./notifications.js

    Keep messages concise and actionable per CONTEXT.md requirements.
