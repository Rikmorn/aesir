## Must-Haves

### Truths (invariants)
- Temporal requires PostgreSQL for persistence (official recommendation)
- `temporalio/auto-setup` handles schema creation automatically
- Port 7233 is Temporal gRPC frontend, 8080 is Temporal UI
- Dev Agent pattern must match Product Agent for consistency
- Agents run on host for easier debugging; infrastructure in Docker

### Artifacts
- `docker-compose.yml` — Temporal infrastructure
- `temporal-config/dynamic_config.yml` — Temporal dynamic config
- `src/scripts/start-dev-agent.ts` — Dev Agent entry point

### Key Links
- Research: `9.1-RESEARCH.md` → Docker Compose example, Dev Agent pattern
- Pattern: `src/scripts/start-product-agent.ts` → entry point script pattern
- Existing: `src/agents/dev-agent/` → Dev Agent implementation

## Tasks

<task id="1" name="Create Docker Compose for Temporal">
<description>
Create `docker-compose.yml` with Temporal server, PostgreSQL backend, and Temporal UI.
</description>

<files>
- CREATE: docker-compose.yml
- CREATE: temporal-config/dynamic_config.yml
</files>

<acceptance_criteria>
- PostgreSQL service with health check
- Temporal auto-setup service depends on healthy PostgreSQL
- Temporal UI service accessible at port 8080
- Port 7233 exposed for gRPC
- Named volume for PostgreSQL data persistence
- All services start with `docker-compose up`
</acceptance_criteria>

<implementation_hints>
Use official images:
- `postgres:15-alpine` for PostgreSQL
- `temporalio/auto-setup:1.24.2` for Temporal server
- `temporalio/ui:2.26.2` for Temporal UI

Dynamic config file is required by Temporal - can be minimal for local dev.
</implementation_hints>
</task>

<task id="2" name="Create Dev Agent entry point script">
<description>
Create `src/scripts/start-dev-agent.ts` following the Product Agent pattern.

Dev Agent entry point should:
1. Load environment variables
2. Validate required config
3. Initialize Linear client, GitHub client
4. Start Temporal worker for dev-agent workflows
5. Listen for Linear webhooks (or manual invocation for MVP)
</description>

<files>
- CREATE: src/scripts/start-dev-agent.ts
</files>

<acceptance_criteria>
- Script follows `start-product-agent.ts` pattern
- Validates required env vars: LINEAR_ACCESS_TOKEN, GITHUB_TOKEN, GITHUB_REPO, ANTHROPIC_API_KEY
- Initializes Temporal worker with dev-agent task queue
- Graceful shutdown on SIGINT/SIGTERM
- Clear startup message with next steps
</acceptance_criteria>

<implementation_hints>
Dev Agent workflow is triggered by Linear webhooks (issue assignment).
For MVP, the entry point starts the worker which processes workflows.

Required imports from existing code:
- `src/temporal/worker.ts` for worker creation
- `src/integrations/linear/` for Linear client
- `src/integrations/github/` for GitHub client
</implementation_hints>
</task>
