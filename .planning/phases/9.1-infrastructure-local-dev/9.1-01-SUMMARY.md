## Decisions Made

2. **actor=app in OAuth URL** - Critical for ensuring actions appear as app identity, not authorizing user
3. **5-minute timeout** - Prevents server from hanging indefinitely if user abandons flow
4. **Custom error classes** - TokenFileNotFoundError includes helpful message pointing to `npm run linear-oauth`

## User Setup Required

**External services require manual configuration:**

1. Create a Linear OAuth application at https://linear.app/settings/api
2. Add credentials to `.env.local`:
   ```
   LINEAR_CLIENT_ID=your-client-id
   LINEAR_CLIENT_SECRET=your-client-secret
   ```
3. Run `npm run linear-oauth` to authorize
4. Complete browser authorization flow
5. Tokens saved to `.linear-tokens.json`
