    **2. EventStreamStore (`lib/event-stream-store.ts`):**

    Build a plain TypeScript class (NOT a React component) that manages:
    - EventSource connection lifecycle (connect, disconnect)
    - 500ms batched event buffering (collect events in array, flush on interval timer)
    - `subscribe` and `getSnapshot` methods for `useSyncExternalStore` compatibility
    - Cached state reference (only create new reference on actual state change -- critical to prevent infinite re-renders)
    - Named event listeners for all SSE event types (the server sends `event: tool.called`, `event: agent.started`, etc. -- these are named events, NOT `onmessage`)
    - Also listen for the special `gap` event type -- when received, set a `hasGap` flag on the state so consumers can trigger a refetch
    - lastEventId tracking from SSE event IDs
    - Max event cap: Accept an optional `maxEvents` parameter (default 1000). When the events array exceeds this, drop the oldest events.

    The store must be importable from both client and server safely (no browser globals at module level). Guard `EventSource` usage inside `connect()`.

    Key implementation details:
    - `subscribe(listener)`: Add listener to a Set, return unsubscribe function
    - `getSnapshot()`: Return `this.state` (same reference unless state changed)
    - `connect()`: Create EventSource, register named event listeners for ALL_EVENT_TYPES plus `gap`, start flush interval
    - `disconnect()`: Close EventSource, clear interval, update status to disconnected
    - `flush()`: If buffer is non-empty, splice buffer, create new events array (prepending existing), update state, notify listeners
    - `clearEvents()`: Reset events array to empty (used by consumers on navigation)

    Status tracking:
    - `onopen` -> "connected"
    - `onerror` with `readyState === CONNECTING` -> "error" (reconnecting)
    - `onerror` with `readyState === CLOSED` -> "disconnected"

    - Returns `useSyncExternalStore(store.subscribe, store.getSnapshot, serverSnapshot)` where `serverSnapshot` returns `{ events: [], status: "disconnected", lastEventId: null, hasGap: false }`
    - Export the hook as a named export

    Important: The hook must NOT create a new EventStreamStore on every render. The `useMemo` dependency array must be `[sseUrl, batchIntervalMs, maxEvents]`.
