**Testing strategy for Temporal workflows:**

Temporal workflow testing requires special handling because workflow code runs in a sandboxed environment. There are two approaches:

A) **Temporal Test Environment** (official approach): Use `@temporalio/testing` which provides `TestWorkflowEnvironment` with time skipping. This is the most accurate but requires more setup.

B) **Direct unit testing** (simpler approach): Mock `@temporalio/workflow` module and test the workflow function directly. This is what the existing `product-agent-workflow.test.ts` does.

Check the existing `product-agent-workflow.test.ts` to see which approach is used. Follow the same pattern.

const signalHandlers = new Map<string, Function>();
const queryHandlers = new Map<string, Function>();
let conditionCallbacks: Array<{ check: () => boolean; timeout?: string; resolve: (value: boolean) => void }> = [];

vi.mock("@temporalio/workflow", () => {
  return {
    defineSignal: vi.fn((name: string) => name),

**Helper to simulate signals:**
```typescript
function simulateSignal(name: string, payload?: unknown): void {
  const handler = signalHandlers.get(name);
  if (handler) {
    handler(payload);
    // Resolve any pending conditions
    for (const cb of conditionCallbacks) {
      if (cb.check()) {
        cb.resolve(true);
      }
    }
    conditionCallbacks = conditionCallbacks.filter(cb => !cb.check());
  }
}

function simulateTimeout(): void {
  // Resolve the oldest pending condition as false (timeout)
  if (conditionCallbacks.length > 0) {
    const cb = conditionCallbacks.shift()!;
    cb.resolve(false);
  }
}
```
