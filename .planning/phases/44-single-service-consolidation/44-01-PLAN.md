Create `packages/agents/src/service/main.ts` -- the single entry point replacing dev-agent/main.ts, product-agent/main.ts, and router/main.ts.

**CRITICAL: This file is pure wiring. No new business logic. Every component is created via existing factory functions from the framework module.**

**Bootstrap sequence (follow this exact order):**

1. **Env validation** -- import `../shared/env/config.js` to trigger Zod validation, extract `env` and `config`.

2. **Logger** -- create pino logger via `createPinoLogger` from `@aesir/platform` with `{ component: "agent-service" }`.

3. **Database Pool** -- create `Pool` from `pg` explicitly (NOT from shared/db/client.ts singleton). Pass `config.database.host`, `config.database.port`, `config.database.user`, `config.database.password`, `config.database.name`, `max: 20`, `idleTimeoutMillis: 30000`, `connectionTimeoutMillis: 5000`. Then create Drizzle instance: `drizzle(pool, { schema })` importing `* as schema from "../shared/db/schema.js"`.

4. **AgentRegistry** -- `createAgentRegistry({ definitionsDir: path.resolve(__dirname, "../../definitions"), logger })`. Use `path` from `node:path`. The `__dirname` in compiled JS will be `dist/service/`, so `../../definitions` resolves to the `definitions/` directory at package root.

5. **ToolRegistry** -- `createToolRegistry({ logger })`, then `registerAllTools({ registry: toolRegistry, agentRegistry, logger })`.

6. **EventLog** -- `createEventLog({ db, logger })`.

7. **SessionProjection** -- `createSessionProjection({ db, logger, eventLog, artifactConfig })`. Define `artifactConfig` as a `Map<string, ArtifactExtractor>` with these entries:
   ```typescript
   const artifactConfig: ArtifactExtractionConfig = new Map([
     ["github:create_pull_request", { artifactKey: "pr_url", payloadPath: "result.url" }],
     ["github:create_branch", { artifactKey: "branch_name", payloadPath: "result.branch" }],
   ]);
   ```
   Import `ArtifactExtractionConfig` from the framework types.

8. **TimeoutScheduler** -- `createTimeoutScheduler({ pool, logger })`.

9. **ConversationExecutor** -- `createConversationExecutor({ db, eventLog, sessionProjection, agentRegistry, toolRegistry, logger, timeoutScheduler, pollIntervalMs: config.service.workerPollIntervalMs, concurrencyLimit: config.service.maxConcurrentConversations, anthropicApiKey: config.anthropic.apiKey })`.

10. **EventRouter** -- `createEventRouter({ agentRegistry, logger })`, then `await eventRouter.loadStartRules()`.

11. **Express app** -- create Express app with `express.json({ limit: "1mb" })` middleware. Define 4 routes:

    **GET /health** -- return `{ status: "ok", service: "agent-service" }` with 200.

    **POST /events** -- parse body with `NormalizedEventSchema.safeParse(req.body)`. On failure return 400 with `{ error: "Validation failed", issues: parsed.error.issues }`. On success call `routeEvent(parsed.data, routeEventDeps)` where `routeEventDeps: RouteEventDeps = { executor, eventRouter, logger, alertsChannel: config.router.alertsChannel, linearTeamId: config.linear.teamId }`. Return result as JSON. Wrap in try/catch -- on error log and return 500 `{ error: "Internal server error" }`. Import `NormalizedEventSchema` from `@aesir/types` and `routeEvent` from `../router/router.js`. Import `RouteEventDeps` from `../router/types.js`.

    **GET /conversations/:id** -- call `executor.get(req.params.id)`. If null, return 404 `{ error: "Conversation not found" }`. Otherwise return conversation info as JSON. Wrap in try/catch.

    **POST /conversations/:id/cancel** -- call `executor.cancel(req.params.id)`. If false (already terminal), return 409 `{ error: "Conversation already in terminal state" }`. If true, return 200 `{ cancelled: true }`. Wrap in try/catch.

12. **Start server** -- `const server = app.listen(config.service.port, () => { logger.info({ port: config.service.port }, "Agent service listening") })`.

13. **Start worker** -- `executor.startWorker()`. Call AFTER server.listen to ensure HTTP is ready.

14. **Graceful shutdown** -- implement shutdown handler:
    ```typescript
    let isShuttingDown = false;

    const shutdown = async (signal: string): Promise<void> => {
      if (isShuttingDown) return;
      isShuttingDown = true;
      logger.info({ signal }, "Graceful shutdown initiated");

      // 1. Stop accepting HTTP connections
      server.close();

      // 2. Stop worker + drain conversations + flush event log + stop pg-boss
      await executor.stopWorker();

      // 3. Final event log flush (belt + suspenders)
      await eventLog.close();

      // 4. Close session projection subscriptions
      sessionProjection.close();

      // 5. Close database pool
      await pool.end();

      logger.info("Graceful shutdown complete");
      process.exit(0);
    };

    process.on("SIGINT", () => void shutdown("SIGINT"));
    process.on("SIGTERM", () => void shutdown("SIGTERM"));

    // Force exit after grace period
    const forceTimeout = setTimeout(() => {
      if (isShuttingDown) {
        logger.error("Forced shutdown after timeout");
        process.exit(1);
      }
    }, config.service.forceShutdownTimeoutMs);
    forceTimeout.unref();
    ```
