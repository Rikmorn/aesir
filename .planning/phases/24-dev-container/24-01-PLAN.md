<task type="auto">
  <name>Task 1: Create dev environment Dockerfile</name>
  <files>docker/dev-env/Dockerfile</files>
  <action>
Create `docker/dev-env/Dockerfile` with:

1. Base image: `node:20-slim`
2. Enable corepack and prepare pnpm:
   ```dockerfile
   RUN corepack enable && corepack prepare pnpm@latest --activate
   ```
3. Install system packages:
   - git (version control)
   - ripgrep (fast code search - apt package is `ripgrep`, binary is `rg`)
   - fd-find (fast file finder - apt package is `fd-find`, binary is `fdfind`, symlink to `fd`)
   - jq (JSON processing)
   - curl (HTTP requests)
   - ca-certificates (HTTPS support)
4. Install GitHub CLI (gh):
   - Add GitHub CLI apt repository
   - Install gh package
   - Clean up apt lists to reduce image size
5. Create symlink for fd-find (`ln -s $(which fdfind) /usr/local/bin/fd`)
6. Set working directory to `/workspace`
7. Set CMD to `["sleep", "infinity"]` to keep container running

Important patterns from RESEARCH.md:
- Use `apt-get update && apt-get install -y ... && rm -rf /var/lib/apt/lists/*` for smaller image
- No TTY mode needed (Tty: false for exec)
- AutoRemove: false will be set at container creation time

Do NOT set ENTRYPOINT - just CMD. Do NOT add USER directive (runs as root for Docker socket access when needed).
  </action>
  <verify>
