<task type="auto">
  <name>Task 1: Create TraceStore with task ID indexing</name>
  <files>src/logging/trace-store.ts</files>
  <action>
Create TraceStore class that:
1. Uses `Map<string, LogEntry[]>` to store entries indexed by taskId
2. Implements:
   - `append(entry: LogEntry): void` - adds entry to taskId bucket (no-op if taskId missing)
   - `getByTaskId(taskId: string): LogEntry[]` - returns all entries for taskId (empty array if not found)
   - `getByWorkflowId(workflowId: string): LogEntry[]` - returns entries matching workflowId in context
   - `clear(taskId?: string): void` - clears specific taskId or all if omitted
   - `size(): number` - returns total entry count
3. Export `createTraceStore()` factory function

Key implementation notes:
- Import LogEntry type from ./logger.js
- Check for `entry.context.taskId` before indexing (defensive)
- getByWorkflowId filters all entries where context.workflowId matches
- Thread-safe not required (single-threaded JS runtime)
  </action>
  <verify>TypeScript compiles: npx tsc --noEmit</verify>
  <done>TraceStore class with Map storage, append, query methods, and factory function exported</done>
</task>
