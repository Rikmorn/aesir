  <name>Task 1: Create LangGraphTracer callback handler</name>
  <files>src/agents/tracing/langgraph-tracer.ts, src/agents/tracing/index.ts</files>
  <action>
Create LangGraphTracer extending BaseCallbackHandler:

1. Import BaseCallbackHandler from @langchain/core/callbacks/base
2. Import Logger and TraceStore from ../logging/index.js

3. Implement LangGraphTracer class:
   - Constructor takes Logger and TraceStore
   - Set `name = "LangGraphTracer"` (required by BaseCallbackHandler)

4. Override callback methods (wrap each in try/catch to prevent tracing errors from crashing workflow):

   handleChainStart(chain, inputs, runId, parentRunId, tags, metadata):
   - Log "chain_start" at info level
   - Include: runId, chainType (constructor name), parentRunId
   - Append to store

   handleChainEnd(outputs, runId):
   - Log "chain_end" at info level
   - Include: runId, outcome: "success"
   - Append to store

   handleChainError(error, runId):
   - Log "chain_error" at error level
   - Include: runId, outcome: "failure", error message
   - Append to store

   handleLLMStart(llm, prompts, runId, parentRunId):
   - Log "llm_start" at debug level (prompts can be large)
   - Include: runId, model name if available, promptCount
   - Append to store

   handleLLMEnd(output, runId):
   - Log "llm_end" at debug level
   - Include: runId, tokenUsage from output.llmOutput if available
   - Append to store

   handleToolStart(tool, input, runId):
   - Log "tool_start" at info level
   - Include: runId, tool.name, inputLength (not full input)
   - Append to store

   handleToolEnd(output, runId):
   - Log "tool_end" at info level
   - Include: runId, outputLength
   - Append to store

5. Export createLangGraphTracer(logger, store) factory

6. Create src/agents/tracing/index.ts:
   - Export LangGraphTracer, createLangGraphTracer

Critical: ALL handler methods must wrap in try/catch - callback exceptions should never propagate to workflow.
  </action>
  <verify>TypeScript compiles: npx tsc --noEmit</verify>
  <done>LangGraphTracer class with all callback methods, error-safe, factory exported</done>
</task>
