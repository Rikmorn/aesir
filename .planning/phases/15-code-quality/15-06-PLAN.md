```json
      "ignore": ["**/*.test.ts", "**/testing/**"]

      "entry": ["src/index.ts"],
      "project": ["src/**/*.ts"],

    "packages/integrations": {
      "entry": ["src/index.ts"],
      "project": ["src/**/*.ts"],
      "ignore": ["**/*.test.ts", "**/testing/**"]
    },
    "packages/observability": {
      "entry": ["src/index.ts"],
      "project": ["src/**/*.ts"],
      "ignore": ["**/*.test.ts", "**/testing/**"]
    },
    "packages/agents": {
      "entry": [
        "src/index.ts",
        "src/scripts/*.ts",
        "src/dev-agent.ts",
        "src/product-agent.ts"
      ],
      "project": ["src/**/*.ts"],
      "ignore": ["**/*.test.ts", "**/testing/**"]
    }
  },
  "ignore": [
    "**/*.test.ts",
    "**/testing/**",
    "**/_legacy/**",
    "**/dist/**",

    "@types/*"
  ]
}
```

Key configuration decisions:
1. **Entry points**: Package index.ts plus agent scripts (entry points for execution)
2. **Ignore test files**: *.test.ts and testing/ directories
3. **Ignore _legacy/**: Already tracked for future review
4. **Ignore @types/***: Dev dependencies that don't show usage

Run `pnpm exec knip` to verify configuration works.

<task type="auto">
  <name>Task 2: Analyze and remove dead code</name>
  <files>
    - (Files identified by knip)
  </files>
  <action>
Run knip to identify dead code, then systematically remove it.

**Step 1: Run analysis**
```bash
pnpm exec knip
```

**Step 2: Categorize findings**

knip reports several categories:
- **Unused exports**: Functions/types exported but never imported
- **Unused files**: Files not imported anywhere
- **Unused dependencies**: npm packages in package.json but not imported

For each finding, evaluate:
1. Is it truly dead code? (not used at runtime, tests, or scripts)
2. Is it @deprecated but still referenced? (keep)
3. Is it for future use? (remove - YAGNI, git history preserves it)

**Step 3: Remove dead code**

For unused exports:
- If the entire file is unused, delete the file
- If only some exports are unused, remove those exports

For unused dependencies:
- Remove from package.json
- Run `pnpm install` to update lockfile

For unused files:
- Delete the file
- If it's in _legacy/, leave it (separate cleanup task)

**Step 4: Verify removal**
```bash
pnpm exec knip  # Should report fewer/no issues
pnpm build      # Ensure nothing is broken
pnpm test       # Tests still pass
```

**Expected categories of dead code:**
- Old utility functions superseded by new patterns
- Unused type definitions from refactors
- Exports added "just in case" but never used
- Duplicate implementations (consolidate to one)

Document significant removals in SUMMARY for future reference.

Note: If knip shows false positives (code used dynamically), add to ignore patterns. Document why in knip.json comments.
  </action>
  <verify>
    - `pnpm exec knip` reports clean or only expected issues
    - `pnpm build` succeeds
    - `pnpm test` passes
    - Removed code documented in SUMMARY
    - No runtime errors from missing code
  </verify>
  <done>

  </done>
