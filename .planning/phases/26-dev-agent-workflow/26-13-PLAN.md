## E2E Verification Checklist

### Prerequisites
1. Docker Compose running: `docker compose up -d`
2. Check all services healthy: `docker compose ps`
3. Check Temporal UI: http://localhost:8080

### Test Flow

**Step 1: Create Linear Issue**
1. Go to Linear workspace
2. Create issue with title: "[Test] Dev agent E2E verification"
3. Add description with clear requirements
4. Add label: "agent-ready"
5. Note the issue identifier (e.g., ABC-123)

**Step 2: Verify Workflow Started**
1. Check dev-agent logs: `docker compose logs -f dev-agent`
2. Confirm "Starting dev-agent workflow" appears
3. Check Temporal UI for workflow: dev-agent-{issue-id}
4. Verify phase: "awaiting_approval"

**Step 3: Verify Dual-Channel Approval Request**
1. Check Linear issue for plan comment
2. Check Slack channel for approval request message
3. Confirm plan includes: steps, files, confidence level

**Step 4: Approve Plan**
Option A: Reply "approved" on Linear issue comment
Option B: Click "Approve" button in Slack

**Step 5: Verify Execution**
1. Check Temporal UI shows workflow continuing
2. Check dev-agent-worker logs for execution progress
3. Verify container created: `docker ps | grep dev-container`

**Step 6: Verify PR Created**
1. Check GitHub for new PR
2. Verify PR title matches plan
3. Verify PR links to Linear issue
4. Verify tests pass in PR

**Step 7: Verify Notifications**
1. Check Slack for PR notification
2. Check Linear issue status updated to "In Review"

### Error Path Testing (Optional)
1. Create issue that will fail (e.g., impossible requirement)
2. Verify escalation notification in Slack and Linear
3. Verify workflow waiting for resolution signal
