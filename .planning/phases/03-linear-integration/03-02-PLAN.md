<task type="auto">
  <name>Task 1: Create webhook signature verification and payload parsing</name>
  <files>src/integrations/linear/webhooks.ts, src/integrations/linear/webhooks.test.ts</files>
  <action>
    1. Create webhooks.ts with:

       - verifyWebhookSignature(signature: string, rawBody: string, secret: string): boolean
         - Uses node:crypto createHmac with 'sha256'
         - Computes HMAC of rawBody with secret
         - Uses timingSafeEqual to compare (security requirement)
         - Returns boolean

       - validateWebhookTimestamp(timestamp: number, toleranceMs?: number): boolean
         - Default tolerance: 60000ms (60 seconds)
         - Returns true if timestamp within tolerance of Date.now()
         - Prevents replay attacks

       - parseWebhookPayload&lt;T&gt;(rawBody: string): T
         - JSON.parse with type assertion
         - Called AFTER signature verification (raw body preserved)

       - isAgentSessionEvent(payload: WebhookPayload): payload is AgentSessionPayload
         - Type guard checking payload.type === 'AgentSession'

       - isIssueEvent(payload: WebhookPayload): boolean
         - Returns payload.type === 'Issue'

    2. Create webhooks.test.ts with:
       - Test verifyWebhookSignature with known secret/body/signature
       - Test verifyWebhookSignature rejects wrong signature
       - Test verifyWebhookSignature rejects tampered body
       - Test validateWebhookTimestamp accepts recent timestamps
       - Test validateWebhookTimestamp rejects old timestamps
       - Test type guards work correctly

    CRITICAL: Use raw body string for signature verification, NOT parsed JSON. JSON.parse then JSON.stringify changes whitespace and breaks verification.

    AVOID: Don't import LinearClient here - webhooks.ts should be pure functions for verification only.
  </action>
  <verify>npm test -- src/integrations/linear/webhooks passes</verify>
  <done>Webhook signature verification working with tests</done>
</task>
