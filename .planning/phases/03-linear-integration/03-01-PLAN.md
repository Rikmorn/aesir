<task type="auto">
  <name>Task 2: Create LinearClient factory with OAuth token management</name>
  <files>src/integrations/linear/client.ts</files>
  <action>
    1. Create createLinearClient function that:
       - Takes LinearConfig (accessToken, refreshToken, expiresAt)
       - Checks if token needs refresh (within 60s of expiresAt)
       - If refresh needed, calls refreshOAuthToken helper
       - Returns LinearClient instance with valid accessToken

    2. Create refreshOAuthToken helper that:
       - POSTs to https://api.linear.app/oauth/token
       - Uses grant_type: refresh_token
       - Returns new accessToken, refreshToken, expiresIn
       - Throws descriptive error on failure

    3. Create getLinearClient convenience function for when token management not needed (testing)

    Use logger from src/logging for token refresh events.

    AVOID: Don't store tokens in memory globally - accept config as parameter for testability. Don't catch errors silently - let them propagate with context.
  </action>
  <verify>TypeScript compiles, function signatures match expected usage</verify>
  <done>LinearClient factory created with token refresh logic</done>
</task>
