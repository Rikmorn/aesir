  <name>Task 1: Create Slack interactions router</name>
  <files>packages/integrations/slack/src/api/interactions.ts</files>
  <action>
Create handler for Slack interactive component payloads (button clicks).

Create packages/integrations/slack/src/api/interactions.ts with:

1. Interface for dependencies:
   - logger: PinoLogger
   - dispatchUrl: string (dev-agent URL for forwarding)

2. createInteractionsRouter function:
   - Returns Express Router
   - POST /interactions endpoint

3. Endpoint implementation:
   IMPORTANT: Slack sends interactive payloads as application/x-www-form-urlencoded
   with a "payload" field containing a JSON string.

   a. Parse the payload:
      ```typescript
      const payload = JSON.parse(req.body.payload);
      ```

   b. Validate payload type is "block_actions"

   c. Extract action details:
      - action_id from payload.actions[0].action_id (e.g., "approve_plan_ABC-123_pr")
      - value from payload.actions[0].value (the task identifier)
      - user.id from payload.user.id

   d. Normalize to event format compatible with dev-agent /events:
      ```typescript
      const normalizedEvent = {
        id: createId.event(),
        type: isApproval ? "slack.block_actions.approved" : "slack.block_actions.rejected",
        source: "slack",
        timestamp: new Date().toISOString(),
        correlationId: deliveryId or event id,
        payload: {
          taskIdentifier,  // e.g., "ABC-123"
          userId,
          actionId,
          isApproval,
          messageTs: payload.message.ts,
          channel: payload.channel.id,
        }
      };
      ```

   e. Dispatch to dev-agent (fire-and-forget):
      ```typescript
      fetch(dispatchUrl, {
        method: "POST",
        headers: { "Content-Type": "application/json" },
        body: JSON.stringify(normalizedEvent),
      }).catch(err => logger.error({ err }, "Failed to dispatch"));
      ```

   f. Acknowledge immediately (Slack 3-second rule):
      ```typescript
      res.status(200).json({ received: true });
      ```

4. Add express.urlencoded middleware note in comments

Export createInteractionsRouter.

   - Create and mount the interactions router at /slack/interactions
   - Use DEV_AGENT_URL env var or default "http://dev-agent:3004/events"

Example registration:
```typescript
import { createInteractionsRouter } from "./api/interactions.js";

// In createApp or server setup:
app.use(express.urlencoded({ extended: true }));

const interactionsRouter = createInteractionsRouter({
  logger: logger.child({ component: "interactions" }),
  dispatchUrl: process.env.DEV_AGENT_URL || "http://dev-agent:3004/events",
});

app.use("/slack", interactionsRouter);
```
