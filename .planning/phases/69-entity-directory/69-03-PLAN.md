**1. Create `packages/agents/scripts/seed-directory.ts`:**

Follow the seed-permissions.ts pattern from `packages/integrations/linear/scripts/`. The script:

```typescript
#!/usr/bin/env tsx
```

**Setup:**
- Import `loadEnvFromRoot` from `@aesir/platform` and call it first (before any env access)
- Import `drizzle` from `drizzle-orm/postgres-js`, `postgres` from `postgres`
- Import `entityDirectory` from `../src/shared/db/schema.js`
- Import `createEmbeddingService` from `../src/shared/embedding/index.js`
- Import `createAgentRegistry` from `../src/framework/agent-registry.ts` (to load definitions from disk)
- Import `createPinoLogger` from `@aesir/platform`
- Import `eq`, `and`, `notInArray`, `sql` from `drizzle-orm`
- Import `readdir`, `stat` from `node:fs/promises` and `join`, `resolve`, `dirname` from `node:path`
- Import `fileURLToPath` from `node:url`

**Main function:**
1. Create logger, DB connection (postgres client + drizzle), and EmbeddingService from env config.

   For the EmbeddingService config, read from process.env matching the pattern in `packages/agents/src/shared/env/config.ts`:
   ```typescript
   const embeddingConfig = {
     provider: (process.env.EMBEDDING_PROVIDER || "ollama") as "ollama" | "voyage",
     dimensions: Number(process.env.EMBEDDING_DIMENSIONS || "768"),
     ollama: {
       url: process.env.OLLAMA_URL || "http://localhost:11434",
       model: process.env.OLLAMA_MODEL || "nomic-embed-text",
     },
     voyage: {
       apiKey: process.env.VOYAGE_API_KEY as string | undefined,
       model: process.env.VOYAGE_MODEL || "voyage-3",
     },
   };
   ```

2. Resolve definitions directory relative to script location (same pattern as main.ts):
   ```typescript
   const DEFINITIONS_DIR = resolve(dirname(fileURLToPath(import.meta.url)), "../definitions");
   ```

3. Create AgentRegistry and call `list()` to get all definitions.

4. Filter to definitions that have capabilities (presence of `capabilities` field is the opt-in signal):
   ```typescript
   const withCaps = definitions.filter(d => d.capabilities && d.capabilities.length > 0);
   ```

5. For each definition with capabilities:
   a. Check if entry already exists in DB: `SELECT capabilities FROM agents.entity_directory WHERE id = def.id`
   b. Compare capabilities arrays (sort both before comparison to handle ordering):
      ```typescript
      const sortedCaps = (caps: string[]) => [...caps].sort();
      const capsChanged = !existing ||
        JSON.stringify(sortedCaps(existing.capabilities as string[])) !==
        JSON.stringify(sortedCaps(def.capabilities!));
      ```
   c. If capabilities changed, generate embedding:
      ```typescript
      const capsText = def.capabilities!.join(". ");
      const embedding = await embeddingService.embed(capsText);
      if (!embedding) {
        console.error(`FATAL: Could not generate embedding for ${def.id}. Is the embedding service running?`);
        process.exit(1);  // Hard fail -- seeding must succeed completely
      }
      ```
   d. Upsert using ON CONFLICT DO UPDATE:
      ```typescript
      await db.insert(entityDirectory).values({
        id: def.id,  // Use agent definition ID directly (natural key)
        type: "agent",
        name: def.name,
        description: def.description,
        capabilities: def.capabilities!,
        capabilities_embedding: capsChanged ? embedding! : undefined,
        status: "active",
        metadata: {},
        last_seeded_at: new Date(),
      }).onConflictDoUpdate({
        target: entityDirectory.id,
        set: {
          name: def.name,
          description: def.description,
          capabilities: def.capabilities!,
          ...(capsChanged && embedding ? { capabilities_embedding: embedding } : {}),
          status: "active",
          last_seeded_at: new Date(),
          updated_at: new Date(),
        },
      });
      ```
   e. Log: `console.log(\`  ${capsChanged ? "UPDATED" : "UNCHANGED"}: ${def.id} (${def.capabilities!.length} capabilities)\`)`

6. Deactivate stale entries: UPDATE agents.entity_directory SET status = 'inactive', updated_at = now() WHERE type = 'agent' AND status = 'active' AND id NOT IN (list of IDs from withCaps). Log count of deactivated entries.

7. Print summary and close DB connection:
   ```typescript
   console.log(`\nSeeded ${withCaps.length} entities, deactivated ${deactivatedCount} stale entries`);
   await client.end();
   ```

**Error handling:** Wrap main function in try/catch, log error and exit(1) on failure.
