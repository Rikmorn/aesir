Create `packages/agents/src/shared/services/directory-service.ts` following the KnowledgeService pattern exactly.

**Interface:**
```typescript
export interface DirectoryEntry {
  id: string;
  name: string;
  type: "agent" | "human";
  description: string;
  capabilities: string[];
}

export interface DirectoryEntryFull extends DirectoryEntry {
  reachVia: Record<string, unknown> | null;
  metadata: Record<string, unknown>;
}

export interface UpsertDirectoryEntry {
  id: string;
  type: "agent" | "human";
  name: string;
  description: string;
  capabilities: string[];
  capabilitiesEmbedding: number[] | null;
  reachVia?: Record<string, unknown> | null;
  metadata?: Record<string, unknown>;
}

export interface DirectoryService {
  find(query: string, excludeAgentId: string): Promise<DirectoryEntry[]>;
  get(entityId: string): Promise<DirectoryEntryFull | null>;
  upsert(entry: UpsertDirectoryEntry): Promise<void>;
  deactivateStale(activeIds: string[]): Promise<number>;
  health(): Promise<{ healthy: boolean; latencyMs: number }>;
  close(): Promise<void>;
}
```

**Factory: `createDirectoryService(options)`**

Options: `{ db, embeddingService, logger }` (same shape as KnowledgeService options -- `db: NodePgDatabase<typeof agentsSchemaModule>`, `embeddingService: EmbeddingService`, `logger: PinoLogger`).

Fail-fast validation: throw if db, embeddingService, or logger is missing.

**`find(query, excludeAgentId)` implementation:**
1. Generate query embedding via `embeddingService.embed(query)`. If null (embedding failure), log warning and return [] (DIR-06 graceful degradation).
2. Build similarity expression: `sql<number>\`1 - (\${cosineDistance(entityDirectory.capabilities_embedding, queryEmbedding)})\``
3. Query: SELECT id, name, type, description, capabilities FROM agents.entity_directory WHERE status = 'active' AND id != excludeAgentId AND capabilities_embedding IS NOT NULL AND similarity > SIMILARITY_THRESHOLD ORDER BY similarity DESC.
4. Use `SIMILARITY_THRESHOLD = 0.3` (matching knowledge service, per research recommendation).
5. Map rows to DirectoryEntry[] and return.

**`get(entityId)` implementation:**
1. SELECT all columns FROM agents.entity_directory WHERE id = entityId.
2. If no row, return null.
3. If row exists but status = 'inactive', return null (per user decision: "Returns not-found for inactive entities"). Log at debug level: `"Entity '{name}' is inactive"`.
4. Map to DirectoryEntryFull and return.

**`upsert(entry)` implementation:**
1. Insert with ON CONFLICT (id) DO UPDATE: name, description, capabilities, status='active', updated_at=now(), last_seeded_at=now(). Only update capabilities_embedding if capabilitiesEmbedding is not null.
2. This is used by the seed script (Plan 03).

**`deactivateStale(activeIds)` implementation:**
1. UPDATE agents.entity_directory SET status = 'inactive', updated_at = now() WHERE type = 'agent' AND status = 'active' AND id NOT IN (activeIds).
2. Return count of deactivated rows. Scoped to type='agent' only per user decision.

**`health()` implementation:**
1. Run `SELECT 1 FROM agents.entity_directory LIMIT 1` with timing.
2. Return `{ healthy: true, latencyMs }` or `{ healthy: false, latencyMs }` on error.

**`close()` implementation:**
1. No-op (no resources to release, matching KnowledgeService pattern).

Import `cosineDistance`, `desc`, `gt`, `eq`, `and`, `sql`, `isNull`, `notInArray` from drizzle-orm. Import `entityDirectory` from `../db/schema.js`. Import `EmbeddingService` from `../embedding/types.js`.
