**Step 2: Create packages/agents/src/shared/db/schema.ts**

Follow the exact pattern from `packages/observability/src/db/schema.ts`. Use `pgSchema("agents")` for namespace isolation.

Define three tables:

1. **contextSnapshots** (`agents.context_snapshots`):
   - `id`: text PK with `createId.contextSnapshot()` default
   - `task_id`: text, notNull
   - `workflow_id`: text, notNull
   - `agent_type`: text, notNull (e.g., "dev-orchestrator", "product")
   - `stage`: text, notNull (e.g., "post-research", "post-approval", "post-execution")
   - `summary`: text, notNull
   - `completed_actions`: jsonb, typed as `string[]`, default `[]`
   - `pending_intent`: text (nullable)
   - `known_issues`: jsonb, typed as `string[]`, default `[]`
   - `project_context`: jsonb, typed as `Record<string, unknown>`, default `{}`
   - `key_files`: jsonb, typed as `string[]`, default `[]`
   - `research_findings`: jsonb (nullable, typed as `unknown`)
   - `plan`: jsonb (nullable, typed as `unknown`)
   - `tool_call_count`: integer, notNull, default 0
   - `token_count`: jsonb, typed as `{ input: number; output: number }`, default `{ input: 0, output: 0 }`
   - `created_at`: timestamp with timezone, defaultNow, notNull
   - `updated_at`: timestamp with timezone, defaultNow, notNull
   - Indexes: `context_snapshots_task_idx` on task_id, `context_snapshots_workflow_idx` on workflow_id

2. **tasks** (`agents.tasks`):
   - `id`: text PK with `createId.agentTask()` default
   - `task_id`: text, notNull, unique (external task ID, e.g., Linear issue UUID)
   - `issue_id`: text (nullable)
   - `issue_identifier`: text (nullable, e.g., "AES-42")
   - `agent_type`: text, notNull ("dev" or "product")
   - `workflow_id`: text (nullable)
   - `status`: text with type `"pending" | "researching" | "planning" | "approved" | "executing" | "complete" | "failed"`, notNull, default "pending"
   - `container_id`: text (nullable)
   - `branch_name`: text (nullable)
   - `pr_number`: integer (nullable)
   - `pr_url`: text (nullable)
   - `approval_status`: text with type `"pending" | "approved" | "rejected"`, default "pending"
   - `approval_feedback`: text (nullable)
   - `error`: text (nullable)
   - `escalation_reason`: text (nullable)
   - `slack_channel`: text (nullable)
   - `slack_message_ts`: text (nullable)
   - `created_at`: timestamp with timezone, defaultNow, notNull
   - `updated_at`: timestamp with timezone, defaultNow, notNull
   - Indexes: `tasks_workflow_idx` on workflow_id, `tasks_status_idx` on status

3. **executionTraces** (`agents.execution_traces`):
   - `id`: text PK with `createId.executionTrace()` default
   - `task_id`: text, notNull
   - `workflow_id`: text, notNull
   - `agent_type`: text, notNull (e.g., "dev-orchestrator", "researcher", "coder")
   - `agent_instance_id`: text, notNull (unique per agent invocation)
   - `parent_agent_instance_id`: text (nullable -- null for orchestrator, set for sub-agents)
   - `step_number`: integer, notNull
   - `type`: text with type `"tool_call" | "tool_result" | "llm_response" | "agent_spawn" | "agent_complete"`, notNull
   - `tool_name`: text (nullable)
   - `input`: jsonb (nullable)
   - `output`: jsonb (nullable)
   - `token_count_input`: integer (nullable)
   - `token_count_output`: integer (nullable)
   - `duration_ms`: integer (nullable)
   - `created_at`: timestamp with timezone, defaultNow, notNull
   - Indexes: `execution_traces_task_idx` on task_id, `execution_traces_instance_idx` on agent_instance_id, `execution_traces_parent_idx` on parent_agent_instance_id, `execution_traces_workflow_idx` on workflow_id

Export TypeScript types using Drizzle's `$inferSelect` and `$inferInsert` patterns:
```typescript
export type ContextSnapshot = typeof contextSnapshots.$inferSelect;
export type NewContextSnapshot = typeof contextSnapshots.$inferInsert;
export type AgentTask = typeof tasks.$inferSelect;
export type NewAgentTask = typeof tasks.$inferInsert;
export type ExecutionTrace = typeof executionTraces.$inferSelect;
export type NewExecutionTrace = typeof executionTraces.$inferInsert;
```
