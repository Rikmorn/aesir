Create conversation state schema using LangGraph Annotation pattern (like existing agent-state.ts):

1. Define `ProductAgentState` with fields:
   - messages: BaseMessage[] with add_messages reducer (conversation history)
   - requirements: object with what/why/who/acceptanceCriteria/constraints (gathered info)

   - createdTasks: Array<{ id, identifier, title }> for tracking output

2. Use LangGraph's `Annotation.Root` pattern:

   - requirements should merge partial updates

   - ProductAgentStateSchema for full state validation

Follow existing state patterns from src/state/agent-state.ts for consistency.

Tests should verify:
- State creation with defaults
