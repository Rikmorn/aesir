Create three adapter files. Each adapter is a pure function: `(event: NormalizedEvent) => IncomingEvent | null`. Returns null for unrecognized events (sends them to slow-path).

**CRITICAL DISTINCTION from RESEARCH.md:** Start events preserve their original dotted type (e.g., `slack.app_mention.created`) because agent definition triggers match on those types. Signal events use domain-language types (e.g., `"approval"`, `"pr_merged"`) because agents' wait_for calls match on those types.

**Slack adapter** (`slack.ts`) -- export `adaptSlackEvent`:
- `slack.block_actions.approved` -> type: `"approval"`, data: `{ approved: true, source: "slack" }`, correlationKey: `payload.taskIdentifier`
- `slack.block_actions.rejected` -> type: `"approval"`, data: `{ approved: false, feedback: "Rejected via Slack button", source: "slack" }`, correlationKey: `payload.taskIdentifier`
- `slack.block_actions.escalation_retry` -> type: `"escalation_resolved"`, data: `{ action: "retry" }`, correlationKey: `payload.taskIdentifier`
- `slack.block_actions.escalation_abort` -> type: `"escalation_resolved"`, data: `{ action: "abort" }`, correlationKey: `payload.taskIdentifier`
- `slack.app_mention.created` -> type: `"slack.app_mention.created"` (ORIGINAL type for start-rule matching), data: `{ threadTs, channelId, initialMessage, userId, slackTeamId }`, correlationKey: `threadTs || ts`
- `slack.message.created` and any other -> return `null` (slow-path per CONTEXT.md)
- All cases: source = `"slack:webhook"`, deduplicationId = `event.correlationId`

**GitHub adapter** (`github.ts`) -- export `adaptGitHubEvent`:
- `github.pull_request.merged` -> type: `"pr_merged"`, data: `{ merged: true, prNumber }`, correlationKey: extracted from `branchName` via `BRANCH_TASK_REGEX` (`/feature\/([A-Z]+-\d+)/i`). If regex doesn't match, return `null` (can't extract task ID, falls through).
- `github.pull_request.closed` -> type: `"pr_closed"`, data: `{ merged: false, prNumber }`, correlationKey: same extraction.
- `github.pull_request.review_submitted` and any other -> return `null` (slow-path per CONTEXT.md)
- source = `"github:webhook"`, deduplicationId = `event.correlationId`

**Linear adapter** (`linear.ts`) -- export `adaptLinearEvent`:
- `linear.agent_session.created` -> type: `"linear.agent_session.created"` (ORIGINAL type for start-rule matching), data: `{ issueId }`, correlationKey: `issueId`
- `linear.issue.created` -> type: `"linear.issue.created"`, data: `payload`, source: `"linear:webhook"` -- no correlationKey (ignore event, but still adapted so EventRouter can match IGNORE_EVENT_TYPES)
- `linear.issue.updated` -> type: `"linear.issue.updated"`, data: `payload`, source: `"linear:webhook"` -- no correlationKey (ignore event)
- `linear.comment.created` and any other -> return `null` (slow-path per CONTEXT.md)
- source = `"linear:webhook"`, deduplicationId = `event.correlationId`
