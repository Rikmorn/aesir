    1. Create packages/integrations/linear/src/oauth/token-store.ts:
       - Import createPinoLogger from @aesir/common
       - Import createLinearCredentialStore, type DecryptedCredential from ../db/index.js
       - Import db from ../db/client.js
       - Import LinearConfig from ../client/types.js
       - Import LinearError from ../types/errors.js

       - Define DEFAULT_WORKSPACE_ID = "ws_default"

       - Create CredentialNotFoundError class extending LinearError:
         - constructor(workspaceId: string)
         - Error code: INT_LINEAR_TOKEN
         - Message: Clear instructions to run OAuth flow

       - Create loadLinearTokens function:
         - Parameters: workspaceId = DEFAULT_WORKSPACE_ID
         - Creates credential store with db and logger
         - Calls store.getByWorkspace(workspaceId)
         - If credential is null or error, throw CredentialNotFoundError
         - Convert DecryptedCredential to LinearConfig
         - Return LinearConfig

       - Create saveLinearTokens function:
         - Parameters: config: LinearConfig, workspaceId = DEFAULT_WORKSPACE_ID
         - Creates credential store with db and logger
         - Calls store.store({ workspaceId, accessToken, refreshToken?, expiresAt? })
         - Returns credential ID
         - Logs success

       - Helper: credentialToConfig(credential: DecryptedCredential): LinearConfig
         - Maps database credential to LinearConfig
         - Handles optional fields correctly
  </action>
