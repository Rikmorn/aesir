<task type="auto">
  <name>Task 2: Create credential migration script</name>
  <files>
    scripts/migrate-linear-credentials.ts
  </files>
  <action>
    1. Create scripts/migrate-linear-credentials.ts:
       - Shebang: #!/usr/bin/env npx tsx
       - Doc comment explaining the migration purpose

       - Import pg Pool directly (avoid config validation, similar to existing migrate-tokens.ts)
       - Import dotenv-flow for env loading

       - Load env vars: DB_HOST, DB_PORT, DB_USER, DB_PASSWORD, DB_NAME

       - Create async main function:

         a. Connect to database

         b. Check if linear schema exists, if not run migration:
            - Execute 0000_create_linear_schema.sql

         c. Query existing Linear credentials:
            - SELECT * FROM integrations.credentials
              WHERE provider = 'linear' AND deleted_at IS NULL
            - Filter by provider='linear' (Pitfall 5 from RESEARCH.md)

         d. For each credential:
            - Check if already exists in linear.credentials by workspace_id
            - If exists, skip (idempotent)
            - If not, INSERT into linear.credentials:
              - Generate new ID (or reuse existing)
              - Copy all fields except provider (not needed in linear-specific table)

         e. Log migration summary:
            - Total found
            - Migrated count
            - Skipped count (already exist)

         f. Close database connection

       - Call main with error handling

       - Important: Script is idempotent - can be run multiple times safely
  </action>
