       - Import Router from express
       - Import type PinoLogger from @aesir/common
       - Import config from ../types/config.js
       - Import saveLinearTokens from ../oauth/token-store.js

       - Define OAuthRouterDeps interface:
         - logger: PinoLogger

       - Create createOAuthRouter function (returns Router):
         - Store state parameter in memory (Map<string, { created: number }>)

         - GET /oauth/authorize:
           - Generate random state
           - Store state with timestamp
           - Redirect to Linear OAuth authorize URL with params:
             - client_id, redirect_uri, response_type=code, state, scope, actor=app

         - GET /oauth/callback:
           - Extract code, state, error from query params
           - Validate state matches stored state (CSRF protection)
           - Exchange code for tokens via fetch to Linear OAuth endpoint
           - Save tokens via saveLinearTokens
           - Render success HTML page

       - Export createOAuthRouter
