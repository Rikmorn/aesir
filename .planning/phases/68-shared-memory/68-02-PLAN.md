**types.ts** -- Define the embedding interface and config:

```typescript
import type { PinoLogger } from "@aesir/platform";

export interface EmbeddingService {
  /** Embed a single text. Returns null on any failure (graceful degradation). */
  embed(text: string): Promise<number[] | null>;
  /** Embed multiple texts. Returns null for each failed embedding. */
  embedBatch(texts: string[]): Promise<(number[] | null)[]>;
}

export interface EmbeddingConfig {
  provider: "ollama" | "voyage";
  dimensions: number;
  ollama: {
    url: string;
    model: string;
  };
  voyage: {
    apiKey?: string;
    model: string;
  };
}

export interface EmbeddingServiceOptions {
  config: EmbeddingConfig;
  logger: PinoLogger;
}
```

**ollama.ts** -- Ollama provider using REST API:

Create `createOllamaEmbedding(options: EmbeddingServiceOptions): EmbeddingService`:
- `embed(text)`: POST to `{config.ollama.url}/api/embed` with `{ model: config.ollama.model, input: text }`. Use `AbortSignal.timeout(5000)` for 5s timeout. Parse `response.embeddings[0]`. Return null on any error (network, timeout, parse). Log warning on failure.
- `embedBatch(texts)`: Ollama does NOT support batch embeddings. Process sequentially using `embed()` for each text. Use `Promise.all(texts.map(t => this.embed(t)))` -- failures return null per item, don't abort the batch.
- Note: The endpoint is `/api/embed` (not `/api/embeddings` which is the older endpoint).

**voyage.ts** -- Voyage AI provider using official SDK:

Create `createVoyageEmbedding(options: EmbeddingServiceOptions): EmbeddingService`:
- Fail fast at creation time if `config.voyage.apiKey` is missing: throw `new Error("VOYAGE_API_KEY is required when EMBEDDING_PROVIDER=voyage")`.
- Instantiate `VoyageAIClient` from the `voyageai` package with the API key.
- `embed(text)`: Call `client.embed({ input: text, model: config.voyage.model, inputType: "document" })`. Extract `response.data?.[0]?.embedding`. Return null on VoyageAIError or any other error. Log warning with status code on failure.
- `embedBatch(texts)`: Call `client.embed({ input: texts, model: config.voyage.model, inputType: "document" })`. Map results: `texts.map((_, i) => response.data?.[i]?.embedding ?? null)`. On error, return `texts.map(() => null)`.
- Use `AbortSignal.timeout(10000)` for 10s timeout on Voyage calls if the SDK supports it. If not, rely on SDK's built-in timeout.

**factory.ts** -- Provider selection:

Create `createEmbeddingService(options: EmbeddingServiceOptions): EmbeddingService`:
- Switch on `options.config.provider`:
  - `"ollama"` -> return `createOllamaEmbedding(options)`
  - `"voyage"` -> return `createVoyageEmbedding(options)`
  - default -> throw `new Error(\`Unknown embedding provider: ${options.config.provider}\`)`
- Log at info level which provider was selected.
