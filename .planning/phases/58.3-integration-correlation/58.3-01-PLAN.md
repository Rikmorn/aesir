<objective>
Wire the X-Task-ID header from agent conversations through the MCP call chain, create task_correlations tables in all three integration schemas, and extend the IncomingEvent type with an optional taskId field.

Purpose: This is the shared infrastructure that Plans 02-04 build on. Without the header, integrations cannot know which task initiated a tool call. Without the tables, correlations have nowhere to be stored. Without the IncomingEvent field, correlation lookups have no way to attach task references to events.

Output: MCP header propagation chain complete, three migration files, three Drizzle schema updates, IncomingEvent extended.
</objective>
