## Decisions Made
- RouteEventDeps uses optional fields (taskService?, db?) with explicit guard for backward compatibility -- existing code continues to work without any changes
- Advisory lock uses `pg_advisory_xact_lock(hashtext(taskId))` -- hashtext is a PG built-in that converts arbitrary strings to int4, transaction-scoped so auto-released on commit/rollback
- Fall-through strips taskId from event before passing to EventRouter -- orphaned taskId from deleted tasks or non-agent assignees would be misleading downstream
- Non-null assertions avoided in favor of `as` casts with guard-guarantee comments to satisfy biome's noNonNullAssertion lint rule
