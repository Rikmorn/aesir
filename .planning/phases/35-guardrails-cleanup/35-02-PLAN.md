1. **orchestrator-activities.ts** -- Wire the `onHeartbeat` callback in all three orchestrator activity functions (`runOrchestratorPreApproval`, `runOrchestratorPostApproval`, `handleOrchestratorFeedback`).

   At the top of each activity function, import Temporal's `Context` from `@temporalio/activity`:
   ```typescript
   import { Context } from "@temporalio/activity";
   ```

   IMPORTANT: This import is activity-only (not available in workflow or test context). Use a try/catch or conditional import pattern to avoid breaking tests. The recommended approach per the research:

   Create a helper at the top of the file:
   ```typescript
   function getHeartbeatFn(): (() => void) | undefined {
     try {
       const ctx = Context.current();
       return () => ctx.heartbeat();
     } catch {
       // Not running inside a Temporal activity (e.g., in tests)
       return undefined;
     }
   }
   ```

   Then in each activity's `runAgentLoop()` call, add `onHeartbeat: getHeartbeatFn()` to the options.
