  <action>
1. **token-budget.ts** -- Add three new capabilities to the `TokenBudget` interface and `createTokenBudget()`:
   - `isWarning(): boolean` -- returns true when `remaining <= total * 0.20` (20% threshold)
   - `isReserveOnly(): boolean` -- returns true when `remaining <= RESERVE_BUFFER` (5000 tokens)
   - `warningFired: boolean` -- mutable flag, starts `false`, set externally after first warning callback

   Add constants: `WARNING_THRESHOLD_RATIO = 0.20`, `RESERVE_BUFFER = 5_000`. Export the constants for testing.

2. **types.ts** -- Add to `AgentLoopOptions`:
   - `onBudgetWarning?: (info: { total: number; remaining: number; usedPercent: number }) => void` -- callback fired once when budget drops below warning threshold
   - `onHeartbeat?: () => void` -- callback fired after each LLM response (for Temporal heartbeats, wired in Plan 02)

3. **run-agent-loop.ts** -- Three changes:
   a. **maxRetries: 0** -- Change `new Anthropic()` to `new Anthropic({ maxRetries: 0 })` to disable SDK built-in retries (let Temporal handle retries).
   b. **Warning callback** -- After `tokenBudget?.deduct(...)`, check `tokenBudget?.isWarning() && !tokenBudget.warningFired`. If true, set `tokenBudget.warningFired = true` and fire `options.onBudgetWarning?.({ total: tokenBudget.total, remaining: tokenBudget.remaining, usedPercent: Math.round(((tokenBudget.total - tokenBudget.remaining) / tokenBudget.total) * 100) })`.
   c. **Graceful exhaustion** -- Replace the existing `isExhausted()` check at top of loop with `isReserveOnly()` check. When `isReserveOnly()` returns true AND there are pending tool results (i.e., after at least one iteration), return with `status: "max_tokens"`. The existing `isExhausted()` check remains as a hard stop. The reserve allows one final LLM call with a wrap-up instruction appended to the conversation: add a user message like `"[SYSTEM] Token budget nearly exhausted. Provide a brief summary of progress so far and what remains to be done, so work can be resumed later."` before the final LLM call, then return with status "max_tokens".
   d. **Heartbeat callback** -- After the `onResponse?.(response)` call, add `options.onHeartbeat?.()` to fire heartbeat on each iteration.

4. **token-budget.test.ts** -- Add tests:
   - `isWarning()` returns false above 20%, true at/below 20%
   - `isReserveOnly()` returns false above 5000, true at/below 5000
   - `warningFired` starts false, can be set to true
   - Edge cases: budget of 0, budget exactly at thresholds

5. **run-agent-loop.test.ts** -- Add tests:
   - Warning callback fires exactly once when budget crosses threshold
   - Graceful exhaustion returns "max_tokens" with summary opportunity
   - `onHeartbeat` fires after each LLM response
   - `maxRetries: 0` is passed to Anthropic constructor (spy on constructor)
