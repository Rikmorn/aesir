Export `routeEvent(event: NormalizedEvent, deps: RouterDeps): Promise<RouteResult>`:

```typescript
export async function routeEvent(
  event: NormalizedEvent,
  deps: RouterDeps,
): Promise<RouteResult> {
  const eventLogger = deps.logger.child({
    eventId: event.id,
    eventType: event.type,
    source: event.source,
  });

  eventLogger.info("Routing event");

  // 1. Try fast path first (zero LLM latency)
  const fastAction = matchFastPath(event);

  if (fastAction) {
    eventLogger.info({ rule: "fast-path", actionType: fastAction.type }, "Fast-path match");
    try {
      const result = await executeFastPath(fastAction, deps);
      eventLogger.info({ result }, "Fast-path routing complete");
      return result;
    } catch (error) {
      eventLogger.error({ err: error }, "Fast-path execution failed");
      // Fall through to error handling below
      return handleRoutingFailure(event, deps, error);
    }
  }

  // 2. Slow path: LLM reasoning for ambiguous events
  eventLogger.info("No fast-path match, routing via agentic loop");
  try {
    const result = await routeViaAgentLoop(event, deps);
    eventLogger.info({ result }, "Slow-path routing complete");

    // ROUT-06: If routing failed, alert
    if (result.status === "failed") {
      await sendRoutingAlert(event, deps, result.error || "Unknown failure");
    }

    return result;
  } catch (error) {
    eventLogger.error({ err: error }, "Slow-path routing failed");
    return handleRoutingFailure(event, deps, error);
  }
}
```

Define `handleRoutingFailure(event, deps, error): Promise<RouteResult>`:
- Log error at error level with full event context
- Call `sendRoutingAlert` (best-effort)
- Return `{ status: "failed", error: message }`

Define `sendRoutingAlert(event, deps, reason): Promise<void>`:
- If `deps.alertsChannel` is configured:
  - Use `callMcpTool` to send Slack message to alerts channel
  - Message format: `Router failed to route event: {event.type} ({event.id}) - {reason}`
  - Catch errors from the alert itself (best-effort, don't throw)
- Always log the failure at error level regardless of alert channel config

HTTP server (same node:http pattern as dev-agent/main.ts):
- `GET /health` -> `{ status: "ok", service: "router" }`
- `POST /events` -> Route the event:

  2. Parse JSON
  3. Validate with `NormalizedEventSchema.safeParse(body)`
  4. If validation fails: 400 with error details
  5. Determine if fast-path or slow-path:
     - Import `matchFastPath` from `./fast-path.js`
     - Check `matchFastPath(event)` -- if truthy, process synchronously:
       - Call `routeEvent(event, routerDeps)`
       - Return 200 with result
     - If no fast-path match, acknowledge immediately and process async:
       - Respond 202 Accepted immediately: `{ received: true, eventId: event.id, processing: "async" }`
       - Process in background: `routeEvent(event, routerDeps).catch(err => logger.error(...))`
  6. On unhandled error: 500
