  <files>src/integrations/github/commits.ts, src/integrations/github/commits.test.ts</files>
  <action>
    1. Create src/integrations/github/commits.ts:
       - Import Octokit, createLogger, types
       - Import getBranch from ./branches.js (to get current SHA)

       - createCommit(octokit: Octokit, options: CreateCommitOptions): Promise<CommitInfo>
         This creates a commit with file changes using Git Data API:

         a. Get current commit SHA from branch:
            const branchInfo = await getBranch(octokit, owner, repo, branch)
            const parentSha = branchInfo.sha

         b. Get base tree SHA:
            const { data: parentCommit } = await octokit.rest.git.getCommit({
              owner, repo, commit_sha: parentSha
            })
            const baseTreeSha = parentCommit.tree.sha

         c. Create tree with file changes:
            const treeItems = files.map(f => ({
              path: f.path,
              mode: f.mode || '100644' as const,
              type: 'blob' as const,
              content: f.content
            }))
            const { data: tree } = await octokit.rest.git.createTree({
              owner, repo, base_tree: baseTreeSha, tree: treeItems
            })

         d. Create commit:
            const { data: commit } = await octokit.rest.git.createCommit({
              owner, repo, message, tree: tree.sha, parents: [parentSha]
            })

         e. Update branch reference:
            await octokit.rest.git.updateRef({
              owner, repo, ref: `heads/${branch}`, sha: commit.sha
            })

         f. Return CommitInfo:
            { sha: commit.sha, message, author: { name, email, date } }

         Log at info level with outcome.

    2. Create src/integrations/github/commits.test.ts:
       - Mock Octokit git methods (getCommit, createTree, createCommit, updateRef)
       - Mock getBranch to return known SHA
       - Test createCommit:
         - Calls getBranch to get current SHA
         - Calls getCommit to get base tree
         - Calls createTree with file changes
         - Calls createCommit with tree SHA and parent
         - Calls updateRef to advance branch
         - Returns correct CommitInfo

    Note: The Git Data API is the correct way to create commits programmatically.
    It avoids needing a working directory or git clone.
  </action>
