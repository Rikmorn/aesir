## Tasks

### Task 1: Agent Definition

**What:** Create the ReAct agent that orchestrates code generation using createReactAgent prebuilt.

**File to create:** `src/agents/dev-agent.ts`

**Agent structure:**
```typescript
import { createReactAgent } from "@langchain/langgraph/prebuilt";
import { ChatAnthropic } from "@langchain/anthropic";
import { SqliteSaver } from "@langchain/langgraph-checkpoint-sqlite";
import { codeGenTool } from "../tools";
import { logger } from "../logging";

// LLM configuration
const llm = new ChatAnthropic({
  model: "claude-3-5-sonnet-20241022",
  temperature: 0,
});

// Checkpointer for state persistence
const checkpointer = SqliteSaver.fromConnString(":memory:");
// Note: Use file path for persistence across restarts in dev
// const checkpointer = SqliteSaver.fromConnString("./data/checkpoints.db");

// Agent definition
export const devAgent = createReactAgent({
  llm,
  tools: [codeGenTool],
  checkpointSaver: checkpointer,
});

// Export compiled graph for use with langgraph.json
export const agent = devAgent;
```

**Files to create:**
- `src/agents/dev-agent.ts` - Agent definition
- `src/agents/index.ts` - Public exports

**Verification:**
- Agent compiles without errors
- Agent can be imported and has invoke method

### Task 2: Agent Configuration

**What:** Define agent configuration in code/config files satisfying CORE-05.

```json
  "env": ".env",

```

**src/config/agent-config.ts:**
```typescript
import { z } from "zod";

// Agent configuration schema
export const AgentConfigSchema = z.object({
  // Agent identity
  name: z.string(),
  description: z.string(),

  // Execution limits
  maxIterations: z.number().default(10),
  recursionLimit: z.number().default(25),
  timeoutMs: z.number().default(300000), // 5 minutes

  // LLM settings
  model: z.string().default("claude-3-5-sonnet-20241022"),
  temperature: z.number().min(0).max(1).default(0),

  // Tools
  enabledTools: z.array(z.string()).default(["generate_code"]),
});

export type AgentConfig = z.infer<typeof AgentConfigSchema>;

// Default dev agent configuration
export const devAgentConfig: AgentConfig = {
  name: "dev-agent",
  description: "Development agent for code generation tasks",
  maxIterations: 10,
  recursionLimit: 25,
  timeoutMs: 300000,
  model: "claude-3-5-sonnet-20241022",
  temperature: 0,
  enabledTools: ["generate_code"],
};
```

**Files to create:**
- `langgraph.json` - LangGraph configuration
- `src/config/agent-config.ts` - Agent configuration schema
- `src/config/index.ts` - Public exports

### Task 3: Basic Agent Invocation

**What:** Create a simple runner that invokes the agent with a task description.

**File to create:** `src/index.ts`

**Runner structure:**
```typescript
import "dotenv/config";
import { devAgent } from "./agents";
import { devAgentConfig } from "./config";
import { logger } from "./logging";

export async function runAgent(taskDescription: string, threadId: string) {
  logger.log({
    action: "agent_start",
    context: { threadId, taskDescription },
    outcome: "pending",
  });

  const result = await devAgent.invoke(
    {
      messages: [{ role: "user", content: taskDescription }],
    },
    {
      configurable: { thread_id: threadId },
      recursionLimit: devAgentConfig.recursionLimit,
    }
  );

  logger.log({
    action: "agent_complete",
    context: { threadId },
    outcome: "success",
  });

  return result;
}
```

**Verification:**
- Runner compiles
- Runner can be called (will fail without API key, but should fail cleanly)
