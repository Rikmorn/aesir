### Task 2: Structured Logging Utility

**What:** Create a logging utility that captures agent activity in a structured format suitable for querying.

**File to create:** `src/logging/logger.ts`

**Logger interface:**
```typescript
interface LogEntry {
  timestamp: string;      // ISO 8601
  level: 'info' | 'warn' | 'error' | 'debug';
  action: string;         // What happened (e.g., "tool_call", "llm_request")
  context: {
    threadId?: string;    // Agent thread/session
    taskId?: string;      // External task reference
    agentId?: string;     // Which agent
    [key: string]: unknown;
  };
  outcome?: 'success' | 'failure' | 'pending';
  message?: string;       // Human-readable description
  durationMs?: number;    // For timed operations
}
```

**Requirements:**
- JSON output format (one JSON object per line)
- Console output in development
- Supports correlation IDs for tracing
- Timer utility for measuring operation duration

**Files to create:**
- `src/logging/logger.ts` - Main logger implementation
- `src/logging/index.ts` - Public exports
- `src/logging/logger.test.ts` - Unit tests

**Verification:**
- Logger outputs valid JSON
- Timestamp format is ISO 8601
- All required fields present in log entries
- Timer correctly measures elapsed time
- Tests pass: `npm test`
