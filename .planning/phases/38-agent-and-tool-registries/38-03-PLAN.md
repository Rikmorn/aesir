**Step 2: Create `packages/agents/src/framework/agent-registry.ts`.**

Import dependencies:
- `readdir`, `readFile`, `stat` from "node:fs/promises"
- `join` from "node:path"
- `parse` from "yaml" (the yaml package's parse function)
- `PinoLogger` from "@aesir/platform"
- `AgentDefinitionYamlSchema`, `AgentDefinition`, `AgentRegistry` from "./types.js"

Define `AgentRegistryOptions` interface:
- `definitionsDir: string` -- absolute path to definitions directory
- `logger: PinoLogger`

Define internal `CacheEntry` interface:
- `definition: AgentDefinition`
- `mtime: number` -- ms since epoch from fs.stat

Implement `createAgentRegistry(options: AgentRegistryOptions): AgentRegistry`:

Internal state:
- `cache = new Map<string, CacheEntry>()`
- Destructure `{ definitionsDir, logger }` from options

Internal `loadDefinition(id: string)` async function:
1. Build paths: `defDir = join(definitionsDir, id)`, `yamlPath = join(defDir, "definition.yaml")`, `promptPath = join(defDir, "prompt.md")`
2. Try `stat(yamlPath)` and `stat(promptPath)`. If either throws (ENOENT), return null (agent not found). Catch errors with code check: `if ((error as NodeJS.ErrnoException).code === 'ENOENT') return null; throw error;`
3. Get mtime: `const mtime = Math.max(yamlStat.mtimeMs, promptStat.mtimeMs)`
4. Check cache: `const cached = cache.get(id); if (cached && cached.mtime >= mtime) return cached.definition;`
5. Read files: `const yamlContent = await readFile(yamlPath, "utf-8"); const promptContent = await readFile(promptPath, "utf-8");`
6. Parse YAML: `const parsed = parse(yamlContent);` (from yaml package)
7. Validate with Zod: `const config = AgentDefinitionYamlSchema.parse(parsed);` -- let ZodError propagate (fail fast on invalid definitions per DEF-02)
8. Verify id matches directory name: `if (config.id !== id) throw new Error("Agent definition id '${config.id}' does not match directory name '${id}'")`
9. Build AgentDefinition: Use mutable-then-conditional-set pattern for exactOptionalPropertyTypes:
   ```typescript
   const definition: AgentDefinition = {
     id: config.id,
     name: config.name,
     description: config.description,
     version: config.version,
     model: config.model,
     tools: config.tools,
     maxIterations: config.maxIterations,
     tokenBudget: config.tokenBudget,
     history: config.history,
     systemPrompt: promptContent,
   };
   if (config.temperature !== undefined) {
     (definition as { temperature?: number }).temperature = config.temperature;
   }
   if (config.subAgents !== undefined) {
     (definition as { subAgents?: Record<string, string> }).subAgents = config.subAgents;
   }
   if (config.triggers !== undefined) {
     (definition as { triggers?: Array<{ event: string }> }).triggers = config.triggers;
   }
   ```
10. Cache: `cache.set(id, { definition, mtime })`
11. Log: `logger.debug({ agentId: id, version: config.version }, "Agent definition loaded")`
12. Return definition

Return object implementing AgentRegistry:
- `get(id, version?)`:
  - Call loadDefinition(id)
  - If result is null, return null
  - If version provided and result.version !== version: `logger.warn({ agentId: id, requestedVersion: version, cachedVersion: result.version }, "Agent definition version mismatch -- returning cached version")`
  - Return result
- `list()`:
  - Read definitionsDir with readdir: `const entries = await readdir(definitionsDir, { withFileTypes: true })`
  - Filter to directories only: `entries.filter(e => e.isDirectory())`
  - Map each to loadDefinition, await Promise.all
  - Filter out nulls
  - Return AgentDefinition[]
