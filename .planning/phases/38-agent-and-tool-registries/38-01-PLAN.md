  <files>packages/agents/src/framework/tool-registry.ts, packages/agents/src/framework/index.ts</files>
  <action>
Create `packages/agents/src/framework/tool-registry.ts`:

1. Import types from `./types.js`: `ToolFactory`, `ToolContext`, `ToolRegistry`.
2. Import `PinoLogger` from `@aesir/platform`.

3. Define `ToolRegistryOptions` interface:
   - `logger: PinoLogger`

4. Implement `createToolRegistry(options: ToolRegistryOptions): ToolRegistry`:
   - Internal `factories` Map<string, ToolFactory>
   - `register(ref, factory)`:
     - Validate ref matches `/^[a-z]+:[a-z_]+$/` -- throw Error with clear message if not
     - Throw if ref already registered (no silent overwrites)
     - Store in factories map
     - Log debug: `{ toolRef: ref }, "Tool factory registered"`
   - `resolve(toolRefs, context)`:
     - Map each ref to its factory, call factory(context) to get ToolDefinition
     - If any ref not found, throw Error listing all missing refs (not just the first)
     - Return ToolDefinition[]
   - `has(ref)`: return factories.has(ref)
   - `listRegistered()`: return Array.from(factories.keys()).sort()

5. Update `packages/agents/src/framework/index.ts`:
   - Add: `export { createToolRegistry } from "./tool-registry.js";`
   - Existing exports remain unchanged
