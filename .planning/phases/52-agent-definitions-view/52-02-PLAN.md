    **1. Create `components/agents/agent-type-badge.tsx`:**

    Server component (no "use client"). Renders a Badge that visually distinguishes orchestrator agents from sub-agents.

    Detection logic: An agent is an orchestrator if it has `triggers` (non-empty array). An agent without triggers is a sub-agent. This matches the current agent definitions:
    - Orchestrators: dev-agent (trigger: `linear.agent_session.created`), product-agent (trigger: `slack.app_mention.created`)
    - Sub-agents: coder, researcher, tester (no triggers)

    Props: `{ type: "orchestrator" | "sub-agent" }`

    Visual treatment:
    - Orchestrator: Badge with a distinct color (e.g., indigo/purple tones) and label "Orchestrator"
    - Sub-agent: Badge with a muted color (e.g., slate/gray tones) and label "Sub-agent"

    Use the same Badge + cn pattern as StatusBadge in `components/conversations/status-badge.tsx`. Keep it a server component for reuse in both server and client contexts.

    Export a helper function `getAgentType(triggers?: Array<{ event: string }>): "orchestrator" | "sub-agent"` that components can use to determine agent type from the triggers field.

    **2. Create `components/agents/agent-card.tsx`:**

    Server component (no "use client"). Renders a single agent as a card in the list view.

    Props: Accept an `AgentSummary` type (imported from `@/lib/agent-service`).

    Card layout using shadcn Card component. Follow modern dashboard conventions (Linear/Vercel style):

    **Card header area:**
    - Agent name (prominent, e.g., `text-base font-semibold`)
    - Agent type badge (orchestrator/sub-agent) inline with name
    - Agent ID in muted mono text below name (e.g., `font-mono text-xs text-muted-foreground`)

    **Card body:**
    - Description text (1-2 lines, text-sm text-muted-foreground, truncate with line-clamp-2)
    - Metadata grid showing:
      - Model (e.g., "claude-sonnet-4-20250514")
      - Tools count (e.g., "12 tools")
      - Sub-agents (if any, show count like "3 sub-agents", otherwise omit)
      - Trigger events (if orchestrator, show event name like "linear.agent_session.created", otherwise omit)
      - Version (e.g., "v1.0")

    Use lucide-react icons for metadata items:
    - `Brain` or `Cpu` for model
    - `Wrench` for tools
    - `Users` or `GitBranch` for sub-agents
    - `Zap` for triggers
    - `Tag` for version

    The entire card should be wrapped in a Next.js `Link` to `/agents/${agent.id}` so clicking anywhere navigates to the detail page. Use hover state on the card (e.g., `hover:border-foreground/20 transition-colors`).

    Layout:
