<task type="auto">
  <name>Task 2: Install and configure Biome</name>
  <files>package.json, biome.json</files>
  <action>
    1. Install Biome as dev dependency with exact version:
       `npm install --save-dev --exact @biomejs/biome`

    2. Create biome.json at project root with practical-strict configuration:
       - Enable VCS integration (git, useIgnoreFile)
       - Include: src/**/*.ts, src/**/*.tsx, *.json
       - Formatter: 2 spaces, 80 char line width, LF line endings
       - Linter rules (per CONTEXT.md decisions):
         - recommended: true
         - noExplicitAny: error (ban any)
         - noConsoleLog: error (production code only)
         - complexity rules: warn only
         - useNamingConvention: camelCase vars, PascalCase types, CONSTANT_CASE for consts
       - Override for test files: allow console.log
       - organizeImports: enabled

    3. Add npm scripts to package.json:
       - "lint": "biome check ."
       - "lint:fix": "biome check --write ."
       - "format": "biome format --write ."

    Use Biome 2.x configuration schema. Reference 10-RESEARCH.md Pattern 2 for exact config structure.
  </action>
  <verify>
    - `npx biome --version` shows installed version
    - `npm run lint` executes Biome (will report violations in existing code - expected)
    - biome.json passes schema validation (no Biome config errors)
  </verify>
  <done>
    Biome installed and configured, npm run lint uses Biome, config matches practical-strict philosophy
  </done>
</task>
