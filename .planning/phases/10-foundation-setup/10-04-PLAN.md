  <name>Task 2: Create .cursor rules directory and files</name>
  <files>.cursor/rules/typescript.mdc, .cursor/rules/architecture.mdc</files>
  <action>
    1. Create .cursor/rules/ directory

    2. Create .cursor/rules/typescript.mdc:
       ```markdown
       ---
       description: "TypeScript coding standards for Aesir project"
       globs: ["src/**/*.ts"]
       alwaysApply: true
       ---

       # TypeScript Standards

       - Use explicit return types for public functions
       - Prefer `unknown` over `any` - Biome enforces noExplicitAny
       - Use Zod for runtime validation at all external boundaries
       - No console.log in production code (use logger from src/logging/)

       # Error Handling

       - Wrap external API calls in try/catch
       - Use typed error classes for domain errors (AppError base class in v2.0)
       - Log errors with context using pino logger

       # Formatting

       - Biome handles formatting - don't manually adjust
       - 2 spaces indent, 80 char line width
       - Run `npm run lint:fix` to auto-fix issues

       # Naming Conventions

       - camelCase for variables and functions
       - PascalCase for classes, types, interfaces
       - CONSTANT_CASE for module-level constants
       ```

    3. Create .cursor/rules/architecture.mdc:
       ```markdown
       ---
       description: "Architecture patterns for Aesir project"
       globs: ["src/**/*.ts"]
       alwaysApply: true
       ---

       # 3-Layer Architecture

       - Platform (config, logging, state): No external dependencies
       - Integrations (Linear, GitHub, Slack): Uses Platform, not Agents
       - Agents (dev-agent, product-agent): Uses both Platform and Integrations

       # Dependency Direction

       Agents -> Integrations -> Platform (never reverse)

       # Key Frameworks

       - LangGraph: Agent state machines with checkpoint persistence
       - Temporal: Approval workflows requiring human input
       - Zod: Schema validation for configs and API inputs

       # State Management

       - Agent state in PostgreSQL via LangGraph checkpointer
       - Config from environment (src/config/env.ts)
       - OAuth tokens in .tokens/ (migrating to database)

       # Common Patterns

       - Factory functions over global singletons (v2.0 DI pattern)
       - Explicit dependency injection in constructors
       - Return Result types at service boundaries (neverthrow in v2.0)
       ```

    Per CONTEXT.md: ".cursor files: Mirror .claude - same content, compatible format"
    Note: .cursor/rules uses .mdc files with frontmatter, not .cursorrules (deprecated).
