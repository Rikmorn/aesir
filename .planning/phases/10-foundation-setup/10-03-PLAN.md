<task type="auto">
  <name>Task 1: Install and configure Husky</name>
  <files>package.json, .husky/pre-commit</files>
  <action>
    1. Install Husky:
       `npm install --save-dev husky`

    2. Initialize Husky:
       `npx husky init`
       This creates .husky/ directory and adds "prepare": "husky" to package.json

    3. Create .husky/pre-commit with the following content:

       ```bash
       #!/usr/bin/env sh
       . "$(dirname -- "$0")/_/husky.sh"

       # Biome lint and format on staged files (native --staged support)
       # --write auto-fixes, --files-ignore-unknown skips non-supported files
       npx @biomejs/biome check --staged --write --files-ignore-unknown=true --no-errors-on-unmatched

       # Re-stage any auto-fixed files
       git update-index --again

       # TypeScript type-check (must be full project - staged-only is fundamentally broken)
       # See 10-RESEARCH.md "Anti-Patterns to Avoid" for rationale
       npx tsc --noEmit
       ```

    4. Make pre-commit executable:
       `chmod +x .husky/pre-commit`

    Per CONTEXT.md decisions:
    - "Check scope: Lint + format + TypeScript type check (~10-15 seconds)"
    - "File scope: Staged files only" (for Biome)
    - "Auto-fix: Auto-fix and stage"
    - "Bypass: Allow --no-verify"
  </action>
  <verify>
    - .husky/pre-commit exists and is executable
    - `git status` shows .husky/ directory
    - package.json contains "prepare": "husky" script
  </verify>
  <done>
    Husky installed with pre-commit hook running Biome + tsc
  </done>
</task>
