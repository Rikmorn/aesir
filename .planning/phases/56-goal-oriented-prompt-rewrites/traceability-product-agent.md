## Categories

- **Framework contract -> Keep as constraint**: Rule that breaks the executor if violated. Keep as a hard constraint.
- **Behavioral -> Constraint**: Procedural rule replaced by a constitutional negative constraint.
- **Behavioral -> Example**: Procedural rule replaced by a few-shot example that teaches the same judgment.
- **Behavioral -> Constraint + Example**: Covered by both a constraint and an example.
- **Domain knowledge -> Keep**: Non-procedural reference material. Kept in domain knowledge section.
- **Context-reading -> Move to tools**: Slack context usage instructions moved to tools section.
- **Behavioral -> Drop (model-native)**: Rule encoding something the model does natively. Drop per PROMPT_GUIDE.md Rule 7.
