Generate and apply platform schema migrations:

   - CREATE TABLE platform.configurations

4. Apply platform migrations:
   ```bash
   pnpm db:migrate
   ```

5. Verify schema exists:
   ```bash
   docker compose exec postgresql psql -U temporal -d temporal -c "\dn"
   # Should show 'platform' schema
   docker compose exec postgresql psql -U temporal -d temporal -c "\dt platform.*"
   # Should show workspaces, configurations tables
   ```

6. Create updated_at trigger (add to migration or run manually):
   The trigger function should be created once and applied to tables:
   ```sql
   -- Run in psql or add to a custom migration
   CREATE OR REPLACE FUNCTION platform.update_updated_at_column()
   RETURNS TRIGGER AS $$
   BEGIN
     NEW.updated_at = CURRENT_TIMESTAMP;
     RETURN NEW;
   END;
   $$ LANGUAGE plpgsql;

   CREATE TRIGGER update_workspaces_updated_at
     BEFORE UPDATE ON platform.workspaces
     FOR EACH ROW
     EXECUTE FUNCTION platform.update_updated_at_column();

   CREATE TRIGGER update_configurations_updated_at
     BEFORE UPDATE ON platform.configurations
     FOR EACH ROW
     EXECUTE FUNCTION platform.update_updated_at_column();
   ```

   If drizzle-kit doesn't generate this, create a manual SQL file in migrations/ with timestamp prefix.
  </action>

<task type="auto">
  <name>Task 3: Create default workspace for single-tenant operation</name>
  <files>packages/platform/src/db/seeds/default-workspace.ts</files>
  <action>
Create a seed script for the default workspace (per CONTEXT.md: "single workspace used initially"):

1. Create packages/platform/src/db/seeds/default-workspace.ts:
   ```typescript
   /**
    * Default Workspace Seed
    *
    * Creates the default workspace for single-tenant operation.
    * Run with: npx tsx packages/platform/src/db/seeds/default-workspace.ts
    */
   import { db } from "../client.js";
   import { workspaces } from "../schema.js";
   import { eq } from "drizzle-orm";

   const DEFAULT_WORKSPACE = {
     id: "ws_default",
     name: "Default Workspace",
     slug: "default",
   };

   async function seed() {
     console.log("Seeding default workspace...");

     // Check if exists
     const existing = await db
       .select()
       .from(workspaces)
       .where(eq(workspaces.slug, "default"))
       .limit(1);

     if (existing.length > 0) {
       console.log("Default workspace already exists:", existing[0].id);
       return;
     }

     // Insert
     const [workspace] = await db
       .insert(workspaces)
       .values(DEFAULT_WORKSPACE)
       .returning();

     console.log("Created default workspace:", workspace.id);
   }

   seed()
     .then(() => process.exit(0))
     .catch((err) => {
       console.error("Seed failed:", err);
       process.exit(1);
     });
   ```

2. Add seed script to packages/platform/package.json:
   ```json
   "scripts": {
     // ... existing ...
     "db:seed": "tsx src/db/seeds/default-workspace.ts"
   }
   ```

3. Run the seed:
   ```bash
   pnpm --filter @aesir/platform db:seed
   ```

4. Verify workspace exists:
   ```bash
   docker compose exec postgresql psql -U temporal -d temporal -c "SELECT * FROM platform.workspaces;"
   ```
  </action>
  <verify>
Query shows default workspace with id 'ws_default', slug 'default'.
Running seed again does not create duplicate (idempotent).
  </verify>

  </done>
