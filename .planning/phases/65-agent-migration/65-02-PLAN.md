<objective>
Add defaultNotifyTarget injection to agent context enrichment and remove the obsolete `<slack_context>` block. This gives agents a Slack channel address for proactive notifications (notify() tool) without needing a signal's replyContext.

Purpose: Agents using communication:notify need a target channel, but notify() doesn't come from a signal -- it's for proactive updates (status, escalations). The framework must inject this target into the agent's context. The `<slack_context>` block was product-agent-specific Slack wiring that is now replaced by the channel-agnostic `<reply_context>` (Phase 61) and `<default_notify_target>`.

Output: Updated env config with SLACK_TEAM_ID and per-agent notify channel vars. Updated enrichment.ts that injects `<default_notify_target>` and removes `<slack_context>`. Tests verifying both changes.
</objective>

   Wait — the enrichment function receives deps but doesn't know which agent is being started. Looking at enrichInitialMessage calls in router.ts:
   - Fast-path start: `enrichInitialMessage(routeDecision.event, deps, routeDecision.message)` — the routeDecision has `agentDefinitionId`

   The cleanest approach: add `slackTeamId` and per-agent notify channels to `RouteEventDeps` interface. Then pass a resolved `notifyChannelId` to `enrichInitialMessage` by extending its signature:

   Actually, looking at the architecture more carefully, `enrichInitialMessage` takes `(event, deps, message?)`. We need to add agent-awareness. The simplest approach per the decision "add agentDefinitionId as 4th parameter":

   - Change enrichment signature to: `enrichInitialMessage(event, deps, message?, agentDefinitionId?)`
   - The `deps` carries `slackTeamId` and a notify channel map
   - Inside enrichment, resolve the correct notifyChannelId for the given agentDefinitionId

   Update `EnrichmentDeps`:
   ```typescript
   export interface EnrichmentDeps {

     githubRepo?: string | undefined;
     githubBaseBranch?: string | undefined;

     slackTeamId?: string | undefined;
     notifyChannels?: Record<string, string> | undefined;  // agentId -> channelId
   }
   ```

   And extend enrichInitialMessage signature:
   ```typescript
   export function enrichInitialMessage(
     event: IncomingEvent,
     deps: EnrichmentDeps,

   ```

   Inside, resolve: `const notifyChannelId = agentDefinitionId && deps.notifyChannels?.[agentDefinitionId]`
