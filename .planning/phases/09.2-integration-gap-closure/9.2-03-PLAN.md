2. Update createCheckpointer function:
```typescript
/**
 * Create the checkpointer for state persistence
 *
 * Uses PostgreSQL for persistence across restarts.
 * Requires DATABASE_URL environment variable.
 *
 * @param connectionString - PostgreSQL connection string (defaults to DATABASE_URL env var)
 */
async function createCheckpointer(connectionString?: string) {
  const connStr = connectionString ?? process.env["DATABASE_URL"];
  if (!connStr) {
    throw new Error("DATABASE_URL environment variable is required for checkpointer");
  }
  const saver = PostgresSaver.fromConnString(connStr);
  await saver.setup();
  return saver;
}
```

3. Update the checkpointer creation to be async:

Since PostgresSaver.setup() is async, we need to handle this. The simplest approach is to create the checkpointer lazily or export a factory.

async function getCheckpointer(): Promise<PostgresSaver> {
  if (!_checkpointer) {

  }
  return _checkpointer;
}

// Export for use by workflow
export { getCheckpointer };
