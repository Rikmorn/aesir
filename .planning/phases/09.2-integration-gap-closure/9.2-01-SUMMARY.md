## Changes Summary

### Task 1: prNumber Propagation

**Problem:** The Dev workflow creates PRs but was discarding the PR number before returning. The approval workflow needed the PR number for merge operations but received `undefined`.

**Solution:**
- Added `prNumber: Annotation<number | null>` field to `DevWorkflowState`
- Updated `commitPRNode` to return `prNumber: pr.number` in state update
- Updated `runDevWorkflow` to extract and include `prNumber` in `DevWorkflowResult`
- Used conditional assignment to handle `exactOptionalPropertyTypes`

**Key changes:**
```typescript
// In commit-pr.ts
return {
  status: "complete",
  prNumber: pr.number,  // NEW - was being discarded
};

// In dev-workflow-runner.ts
if (result.prNumber != null) {
  workflowResult.prNumber = result.prNumber;
}
```

### Task 2: Activity Factory Pattern

**Problem:** Temporal activities were defined with client as first parameter, but workflows cannot serialize/pass client instances. The workflow was passing `{}` which would fail at runtime.

**Solution:**
- Created `ActivityDependencies` interface for client types
- Implemented `makeActivities(deps)` factory that returns bound activity functions
- Worker creates activities with `makeActivities(config.dependencies)` at startup
- Exported `BoundActivities` type for workflow typing

**Key changes:**
```typescript
// In activities/index.ts
export function makeActivities(deps: ActivityDependencies) {
  return {
    sendApprovalRequestActivity: (notification, channel) =>
      sendApprovalRequestActivity(deps.slackClient, notification, channel),
    // ... other activities bound similarly
  };
}

// In worker.ts
if (config.dependencies) {
  activities = makeActivities(config.dependencies);
}
```

### Task 3: Workflow Activity Calls

**Problem:** Workflow was using `{} as Parameters<...>[0]` casts to call activities, which was incorrect and would fail at runtime.

**Solution:**
- Updated `proxyActivities<BoundActivities>()` to use new type
- Removed all `{} as Parameters` casts
- Activity calls now use simplified signatures without client param

**Key changes:**
```typescript
// Before
await sendApprovalRequestActivity(
  {} as Parameters<typeof sendApprovalRequestActivity>[0],
  notification,
  channel
);

// After
await sendApprovalRequestActivity(notification, channel);
```
