    **1. Add RetrievalConfigSchema** before AgentDefinitionYamlSchema:

    ```typescript
    /**
     * Zod schema for per-agent retrieval configuration.
     *
     * Strategy objects use .passthrough() to allow strategy-specific fields
     * (e.g., similarity_threshold for vector) without schema errors.
     * The `type` and `weight` fields are validated here; strategy-specific
     * config is validated by each strategy factory at definition load time.
     */
    const RetrievalStrategySchema = z.object({
      /** Strategy type name (must match a registered strategy) */
      type: z.string().min(1),
      /** Relative weight for score fusion (normalized at query time) */
      weight: z.number().positive(),
    }).passthrough();

    const RetrievalConfigSchema = z.object({
      /** Strategy configurations with weights */
      strategies: z.array(RetrievalStrategySchema).min(1),
      /** Maximum results to return after fusion (default: 10) */
      resultLimit: z.number().int().positive().optional(),
    });
    ```

    **2. Add optional `retrieval` field to AgentDefinitionYamlSchema:**

    - This makes it fully optional -- agents without the field load exactly as before (KR-07)

    - This allows agent-registry and pipeline code to reference it

    **4. The `AgentDefinition` interface** extends `AgentDefinitionYaml` which is inferred from the schema -- the `retrieval` field automatically appears as optional on the type. No manual interface changes needed.

    After the parse succeeds and before the directory name check, add:

    ```typescript
    // Validate retrieval strategy names against registered strategies (KR-08)
    if (config.retrieval) {
      const registeredStrategies = getRegisteredStrategyNames();
      for (const strategy of config.retrieval.strategies) {
        if (!registeredStrategies.includes(strategy.type)) {
          throw new Error(
            `Agent "${id}" references unknown retrieval strategy "${strategy.type}". ` +
            `Registered strategies: ${registeredStrategies.join(", ")}`,
          );
        }
      }
    }
    ```

    This validates at definition load time (startup), causing the agent to fail to load if it references an unregistered strategy. Clear error message includes the available strategies.
