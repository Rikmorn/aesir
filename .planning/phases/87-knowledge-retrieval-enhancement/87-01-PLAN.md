  <action>
    **1. Create `retrieval/fusion.ts`** -- pure function, no dependencies:
    - `const RRF_K = 60` (standard constant, NOT configurable per user decision)
    - `reciprocalRankFusion(strategyResults: Array<{ results: ScoredResult[]; weight: number }>): ScoredResult[]`
    - Normalize weights: `totalWeight = sum(weight)`, `normalizedWeight = weight / totalWeight`
    - For each strategy's results, compute contribution per result: `normalizedWeight / (RRF_K + rank + 1)` where rank is 0-indexed position
    - Aggregate by result ID in a Map: `Map<string, { score: number; result: ScoredResult }>`
    - If same ID appears from multiple strategies, sum the contributions
    - Sort by descending fused score, return ScoredResult[] with updated score field
    - Export `RRF_K` for testing
    - Handle edge cases: empty results array, single strategy (passthrough), zero weights (skip)

    **2. Create `retrieval/pipeline.ts`** -- the pipeline factory:
    - **Module-level** `strategies` Map: `const strategies = new Map<string, StrategyFactory>()` -- populated at module load time (NOT inside the factory function) with `"vector"` and `"keyword"` factories. This must be module-level so `getRegisteredStrategyNames()` can be called at agent definition load time (Plan 03) without instantiating a pipeline.
    - Export module-level `getRegisteredStrategyNames()` -- returns `Array.from(strategies.keys())` for validation in agent-registry (Plan 03)
    - `createRetrievalPipeline(options: { db, embeddingService, logger })` returns a pipeline object that reads from the module-level strategies Map
    - Pipeline object has:
      - `search(query: string, scope: RetrievalScope, config: RetrievalConfig): Promise<ScoredResult[]>`
        - For each strategy in `config.strategies`: resolve factory from Map, create instance with db + strategy config, call `search()` via `Promise.allSettled`
        - Log failures from allSettled (graceful degradation per user decision)
        - Collect successful results with their weights
        - If only one strategy succeeded, return its results directly (no fusion needed)
        - If multiple succeeded, call `reciprocalRankFusion(strategyResults)` and limit to `config.resultLimit ?? 10`
    - The pipeline is NOT instantiated when agents have no retrieval config (zero-overhead default path handled by caller in Plan 03)

    **3. Create `retrieval/index.ts`** -- barrel exports:
    - Export types: `RetrievalStrategy`, `ScoredResult`, `RetrievalScope`, `StrategyFactory`, `RetrievalConfig`
    - Export factory: `createRetrievalPipeline`, `getRegisteredStrategyNames`
    - Export fusion: `reciprocalRankFusion` (for testing)
    - Export strategy factories: `createVectorStrategy`, `createKeywordStrategy`
  </action>
