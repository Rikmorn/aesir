**Artifact formatting function:**
```typescript
function formatArtifacts(artifacts: Record<string, string>): string
```
- If empty: return "(no artifacts recorded yet)"
- Otherwise: format as `- **{key}**: {value}` lines, one per entry

**Summary detection:**
```typescript
function containsSummary(messages: Anthropic.MessageParam[]): { hasSummary: boolean; summaryIndex: number }
```
- Scan messages from the START for a user message whose text content contains `<summary>` tags
- Return the index of the summary message if found, -1 otherwise
- Used to detect and merge existing summaries

**Messages serialization for summary prompt:**
```typescript
function serializeMessagesForSummary(messages: Anthropic.MessageParam[]): string
```
- Iterate messages and produce a readable text representation
- For user text messages: `User: {text}`
- For assistant messages: `Assistant: {text}` (text blocks only, skip tool_use blocks)
- For tool_result messages: `Tool Results: [{tool_use_id}: {first 200 chars of content}...]`
- This is fed to the summary model as context -- it does NOT need to be token-efficient, just readable

**Summary generation:**
```typescript
async function generateSummary(
  client: Anthropic,
  messagesToSummarize: Anthropic.MessageParam[],
  artifacts: Record<string, string>,
  summaryModel: string,
): Promise<string>
```
- Build a single user message prompt (see research 39-RESEARCH.md Pattern 5 for the template)
- Call `client.messages.create()` with the summaryModel, max_tokens 4096
- Extract text from response content blocks
- Parse `<summary>...</summary>` tags from the response. If tags not found, use the full response text.
- Return the summary text (without the tags)

**Summary prompt template (within generateSummary):**
```
You are summarizing a conversation to allow efficient continuation.

## Conversation to Summarize
{serialized messages}

## Ground-Truth Artifacts (from event log -- DO NOT paraphrase or modify)
{formatted artifacts}

## Instructions
Create a structured continuation summary including:
1. **Task Overview**: The user's core request and constraints
2. **Completed Work**: What has been accomplished, files modified, key outputs
3. **Key Decisions**: Technical decisions, rationale, errors resolved
4. **Current State**: Where the agent stopped, what was in progress
5. **Next Steps**: Specific actions needed to continue

## Artifacts (from event log)
Include the Ground-Truth Artifacts section verbatim -- these are machine-extracted from actual tool results and must not be paraphrased.

Wrap your summary in <summary></summary> tags.
```

**Pipeline integration (update compact method):**
After Phase 1 pruning, the current code returns with phase "pruned". Add Phase 2 logic:

1. After Phase 1 re-estimation, check if estimatedTokens > config.summaryThreshold
2. If no anthropicClient provided in options: log warning, return pruned result (phase "pruned")
3. Determine summary boundary: everything BEFORE the protected messages zone
4. Check if existing summary exists (containsSummary). If yes:
   - Include the existing summary content in the messages to summarize (the summary model sees the old summary + new messages since)
   - The new summary REPLACES the old summary message (at summaryIndex)
5. If no existing summary: summarize all unprotected messages
6. Call generateSummary with the messages to summarize, artifacts from options, and config.summaryModel
7. Build replacement: a single user message with role "user" and content wrapping the summary in `<summary>` tags:
   ```
   <summary>
   {summary text}
   </summary>
   ```
8. Replace the summarized messages with the single summary message
9. Preserve all protected messages after the summary message
10. Re-estimate final token count
11. Return with phase "summarized"

**Error handling:**
- If summary LLM call fails (API error, timeout): log error, return the Phase 1 pruned result (phase "pruned") as best-effort fallback. The History Manager is an optimization, not a safety mechanism.
- If summary is somehow larger than the messages it replaces (shouldn't happen but protect against it): log warning, return pruned result.
