   ```typescript
   // Communication context: last-received channel address for reply routing (v2.6)
   reply_context: jsonb("reply_context").$type<Record<string, unknown> | null>(),
   ```
   Nullable, no default. Existing rows get null. The `$type` uses `Record<string, unknown> | null` because the Drizzle schema layer doesn't import Zod types from the communication module (avoiding circular deps). Runtime validation happens at the application layer.

2. **schema.drizzle.ts** -- Add the same column to the `conversations` table in the drizzle-kit schema file:

   No `$type` needed (drizzle-kit doesn't use it). Place it in the same position as in schema.ts.
