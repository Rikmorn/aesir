**spawn-agent.ts** -- Create `createSpawnAgentTool(ctx: ToolContext): ToolDefinition` following the pattern in request-human-input.ts.

Input schema (Zod):
```typescript
const SpawnAgentInputSchema = z.object({
  agentType: z.enum(["researcher", "coder", "tester"]).describe("Type of sub-agent to spawn"),
  task: z.string().describe("Task description for the sub-agent to execute"),
  context: z.string().optional().describe("Additional context to prepend to the task"),
});
```

Tool implementation in `execute()`:
1. Parse input with `SpawnAgentInputSchema.parse(input)`
2. Guard: if `ctx.spawnDeps` is undefined, return `{ content: "spawn_agent is not available in this context.", isError: true }`
3. Guard: if `deps.currentDepth >= deps.maxSpawnDepth`, return `{ content: "Maximum spawn depth (${deps.maxSpawnDepth}) exceeded.", isError: true }`
4. Resolve agentType to agent definition ID via `deps.parentDefinition.subAgents?.[parsed.agentType]`. If not found, return error listing available types.
5. Load sub-agent definition via `deps.agentRegistry.get(agentId)`. If not found, return error.
6. Build sub-agent ToolContext: `{ agentId: definition.id, correlationId: ctx.correlationId, logger: ctx.logger.child({ subAgent: definition.id }), containerManager: ctx.containerManager, taskId: ctx.taskId }`. Do NOT include spawnDeps (current sub-agents don't spawn).
   - EXCEPTION: If the sub-agent's definition has `coordination:spawn_agent` in its tools AND `deps.currentDepth + 1 < deps.maxSpawnDepth`, then set spawnDeps with incremented `currentDepth`. This is for future-proofing; current sub-agents don't have spawn_agent.
7. Resolve sub-agent tools via `deps.toolRegistry.resolve(definition.tools, subToolContext)`
8. Build initial message: if `parsed.context`, prepend it to task with `\n\n` separator
9. Generate sub-agent instance ID: `inst_${nanoid(12)}`
10. Record `agent.started` event via `deps.eventLog.append()` with `parentInstanceId: deps.parentInstanceId`, payload: `{ agentType, task: parsed.task.slice(0, 200), spawnDepth: deps.currentDepth + 1 }`
11. Run `await runAgentLoop({ systemPrompt: definition.systemPrompt, tools: resolvedTools, initialMessage, model: definition.model, maxIterations: definition.maxIterations, tokenBudget: deps.tokenBudget, abortSignal: deps.abortSignal, logger: subToolContext.logger })`
12. Calculate `durationMs = Date.now() - startTime`
13. Record `agent.completed` event with payload: `{ status: result.status, tokenCount: result.tokenCount, toolCallCount: result.toolCallCount, outputPreview: result.output.slice(0, 300) }`, plus `tokenCountInput: result.tokenCount.input, tokenCountOutput: result.tokenCount.output, durationMs`
14. Return result:
    - If `result.status === "error" || result.status === "aborted"`: return `{ content: "Sub-agent ${agentType} failed (${status}): ${output}", isError: true }`
    - If `result.status === "max_iterations" || result.status === "max_tokens"`: return `{ content: "Sub-agent ${agentType} stopped (${status}): ${output}", isError: false }` (partial work is useful)
    - Otherwise (completed): return `{ content: result.output, isError: false }`

Use the SAME tool description as the current placeholder in tool-factories.ts:
"Spawn a focused sub-agent to perform a specific task. Available agent types: 'researcher' (explores codebase, reads files, searches code), 'coder' (implements changes, writes files, runs builds), 'tester' (runs tests, diagnoses failures, reads code). Each sub-agent shares the token budget with the orchestrator."
