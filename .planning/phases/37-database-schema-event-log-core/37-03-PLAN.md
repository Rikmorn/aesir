   Actually, let me reconsider. The session status values include "failed" but the event types don't have "agent.failed". The status derivation must handle this:

   - `agent.completed` with `payload.success === false` or `payload.status === "failed"` -> status "failed"

   Use a simple heuristic: `agent.completed` events check `payload.error` -- if present, status is "failed", otherwise "completed".

For `tool.succeeded`:
- Check if the tool name (from `event.payload.toolName` or similar) exists in `artifactConfig`
- If yes, extract the artifact value from the payload using the configured `payloadPath`
- Update the artifacts JSONB column by merging:
  ```typescript
  const toolName = (event.payload as Record<string, unknown>)?.toolName as string | undefined;
  if (!toolName) return;

  const extractor = artifactConfig.get(toolName);
  if (!extractor) return;

  const value = getNestedValue(event.payload as Record<string, unknown>, extractor.payloadPath);
  if (value === undefined || value === null) return;

  // Read current artifacts, merge, write back
  const existing = await db.select({ artifacts: agentSessions.artifacts })
    .from(agentSessions)
    .where(eq(agentSessions.conversation_id, event.conversation_id))
    .limit(1);

  const currentArtifacts = (existing[0]?.artifacts ?? {}) as Record<string, string>;
  const updatedArtifacts = { ...currentArtifacts, [extractor.artifactKey]: String(value) };

  await db.update(agentSessions)
    .set({
      artifacts: updatedArtifacts,
      last_event_type: event.type,
      last_event_at: event.timestamp,
      updated_at: new Date(),
    })
    .where(eq(agentSessions.conversation_id, event.conversation_id));
  ```

**Helper: `getNestedValue(obj, path)`**
- Resolves dot-notation paths like "result.prUrl" into nested object access
- Returns `undefined` if any part of the path is missing
- Example: `getNestedValue({ result: { prUrl: "https://..." } }, "result.prUrl")` -> `"https://..."`
- Keep it simple: `path.split(".").reduce((o, k) => o?.[k], obj)`
