Create `packages/agents/src/framework/event-log.ts` implementing the `EventLog` interface from `types.ts`.

Follow the `createTraceRecorder()` pattern from `packages/agents/src/shared/db/trace-recorder.ts` but with these additions: timer-based flush, subscriber notification, gapless sequence tracking, and query capability.

**Factory signature:**
```typescript
export function createEventLog(options: EventLogOptions): EventLog
```

**Internal state:**
- `buffer: NewAgentEvent[]` -- pending events not yet flushed
- `sequenceCounters: Map<string, number>` -- current sequence per conversation
- `subscribers: Map<string, { filter: EventSubscriptionFilter; handler: EventSubscriptionHandler }>` -- active subscriptions
- `flushTimer: NodeJS.Timeout | null` -- scheduled flush timer
- `closed: boolean` -- prevents append after close

**Method implementations:**

1. **`append(event: AppendEventInput): void`** (synchronous, no async)
   - Throw if `closed === true`
   - Get next sequence number from `sequenceCounters` for `event.conversationId`. If no counter exists for this conversation, throw an error with message: "Sequence not initialized for conversation {id}. Call initSequence() first."
   - Increment counter and assign as `sequence`
   - Build a `NewAgentEvent` record:
     - `id`: Use `createId.agentEvent()`
     - `conversation_id`: from event.conversationId
     - `agent_definition_id`: from event.agentDefinitionId
     - `agent_definition_version`: from event.agentDefinitionVersion
     - `agent_instance_id`: from event.agentInstanceId
     - `parent_instance_id`: from event.parentInstanceId ?? null
     - `sequence`: computed above
     - `type`: from event.type
     - `payload`: truncate via `truncateJsonPayload(event.payload ?? {}, maxPayloadBytes)` -- copy `truncateJsonPayload` from trace-recorder.ts or import if extractable
     - `timestamp`: `new Date()` (assign at append time, not flush time)
     - `token_count_input`: from event.tokenCountInput ?? null
     - `token_count_output`: from event.tokenCountOutput ?? null
     - `duration_ms`: from event.durationMs ?? null
   - Push record to buffer
   - Notify all matching subscribers (see below)
   - If `buffer.length >= maxBufferSize`, trigger eager flush: `void doFlush()`
   - Otherwise, call `scheduleFlush()` to set/reset the timer

2. **`initSequence(conversationId: string): Promise<void>`**
   - Query DB: `SELECT COALESCE(MAX(sequence), 0) as max_seq FROM agents.agent_events WHERE conversation_id = ?`
   - Use Drizzle: `db.select({ maxSeq: sql<number>\`COALESCE(MAX(${agentEvents.sequence}), 0)\` }).from(agentEvents).where(eq(agentEvents.conversation_id, conversationId))`
   - Set `sequenceCounters.set(conversationId, result[0]?.maxSeq ?? 0)`
   - Import `eq` from `drizzle-orm` and `sql` from `drizzle-orm`

3. **`query(conversationId: string, options?: EventQueryOptions): Promise<AgentEvent[]>`**
   - First call `await doFlush()` to ensure pending events are persisted
   - Build Drizzle query with conditions:
     - `WHERE conversation_id = ?`
     - If `options.types` provided: `AND type IN (...)`
     - If `options.afterSequence` provided: `AND sequence > ?`
     - `ORDER BY sequence ASC`
     - If `options.limit` provided: `.limit(options.limit)`
   - Use `drizzle-orm` `and()`, `eq()`, `inArray()`, `gt()`, `asc()` operators
   - Return the rows

4. **`subscribe(filter, handler): Unsubscribe`**
   - Generate a unique subscription ID: `createId.event()` (reuse existing event prefix)
   - Store `{ filter, handler }` in `subscribers` Map with subscription ID as key
   - Return `() => { subscribers.delete(subscriptionId); }`

5. **`flush(): Promise<void>`**
   - Delegate to internal `doFlush()`

6. **`close(): Promise<void>`**
   - Set `closed = true`
   - Clear `flushTimer` if set
   - Call `await doFlush()` to persist remaining events
   - Clear `subscribers`
   - Clear `sequenceCounters`
   - Log "EventLog closed"

**Internal helpers:**

- **`scheduleFlush()`**: If no timer is set, `flushTimer = setTimeout(async () => { flushTimer = null; await doFlush(); }, flushIntervalMs)`. Use `flushTimer.unref()` so the timer doesn't prevent Node.js from exiting.

- **`doFlush(): Promise<void>`**: Same pattern as trace-recorder:
  - If buffer empty, return
  - Clear timer if set
  - Copy buffer, clear buffer
  - Try `await db.insert(agentEvents).values(toInsert)`
  - On error: `logger.error(...)`, do NOT re-throw (best-effort)
  - On success: `logger.debug({ count }, "Flushed events")`

- **`notifySubscribers(record: AgentEvent)`**: For each subscriber, check if record.type matches filter.types (or filter.types is empty/undefined = all types). If match, call `handler(record)` wrapped in try/catch with error logging. Use `void handler(record).catch(err => logger.error(...))` pattern -- fire-and-forget, never block append().

- **`truncateJsonPayload(value, maxBytes)`**: Copy the function from `packages/agents/src/shared/db/trace-recorder.ts` into event-log.ts. This avoids a cross-module dependency for a small utility. Keep the same 10KB default.

**IMPORTANT notes:**
- `append()` must be synchronous (void return). The caller must never await.
- When building the `AgentEvent` record to pass to subscribers, cast the `NewAgentEvent` to `AgentEvent` type since subscribers expect the full type. The record will have all fields set.
- Column names in Drizzle queries use the schema definition property names (e.g., `agentEvents.conversation_id`).
- The `flushIntervalMs` default is 1000. The `maxBufferSize` default is 100. The `maxPayloadBytes` default is 10240.
