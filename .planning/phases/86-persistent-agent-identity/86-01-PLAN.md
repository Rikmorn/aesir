     - `document_type TEXT NOT NULL` (free-text string per user decision -- NOT an enum)
     - `content TEXT NOT NULL` (the document body, markdown/plain text)
     - `version INTEGER NOT NULL` (incrementing per agent_id + document_type pair)
     - `conversation_id TEXT REFERENCES agents.conversations(id) ON DELETE SET NULL` (FK to conversation that produced this version, ON DELETE SET NULL per user decision)
     - `created_at TIMESTAMPTZ NOT NULL DEFAULT NOW()`
   - Add indexes:
     - `idx_identity_agent_type` on (agent_id, document_type) for getCurrentDocuments queries
     - `idx_identity_agent_type_version` on (agent_id, document_type, version DESC) for latest version lookup
   - Add unique constraint: `uq_identity_agent_type_version` on (agent_id, document_type, version) to prevent duplicate versions

2. Add `identityDocuments` table to `schema.ts` following the existing pattern (see knowledgeEntries, scheduleState for reference):
   - Use `agentsSchema.table("identity_documents", ...)`
   - Column types: text for id/agent_id/document_type/content, integer for version, text for conversation_id with `.references(() => conversations.id)`, timestamp for created_at
   - Add index definitions matching migration
   - Export types: `IdentityDocument`, `NewIdentityDocument`

3. Mirror the table definition in `schema.drizzle.ts` (required for drizzle-kit migration tracking -- do NOT remove any existing tables from this file)

4. Create `identity-service.ts` following the `createKnowledgeService` factory pattern:
   - Interface `IdentityServiceOptions`: `{ db, logger }` (no embedding service needed)
   - Interface `IdentityService` with methods:
     - `getCurrentDocuments(agentId: string): Promise<IdentityDocument[]>` -- returns the latest version of each document for this agent. Query: for each distinct document_type where agent_id matches, select the row with max version. Use a subquery or window function. Return ordered by document_type.
     - `getDocumentHistory(agentId: string, documentType: string, options?: { limit?: number; offset?: number }): Promise<IdentityDocumentVersion[]>` -- returns version history for a specific document, newest first. Default limit 20.
     - `updateDocument(params: { agentId: string; documentType: string; content: string; conversationId: string }): Promise<{ version: number; documentType: string; allDocuments: string[] }>` -- validates char limit (12,000), validates document cap (5 per agent), determines next version number (SELECT MAX(version) + 1), inserts new row, returns the new version and a list of all current document types for this agent.
     - `getDocumentCount(agentId: string): Promise<number>` -- returns count of distinct document types for this agent (used by cap check)
     - `health(): Promise<{ healthy: boolean; latencyMs: number }>` -- same pattern as KnowledgeService
     - `close(): Promise<void>`
   - Constants: `IDENTITY_MAX_DOCUMENTS = 5`, `IDENTITY_MAX_CHARS_PER_DOCUMENT = 12_000`
   - `updateDocument` validation:
     - If `content.length > IDENTITY_MAX_CHARS_PER_DOCUMENT`, throw with message: "Document exceeds 12,000 character limit (submitted: {length}). Rewrite more concisely."
     - If this is a NEW document_type (no existing versions) AND current distinct document count >= IDENTITY_MAX_DOCUMENTS, throw with message: "Maximum 5 identity documents reached. Your documents: {list}. Update an existing document or replace one."
     - If this is an existing document_type, always allow the update (not a new document, just a new version)
   - `getCurrentDocuments` implementation: Use raw SQL or Drizzle query that gets the latest version per document_type:
     ```sql
     SELECT DISTINCT ON (document_type) *
     FROM agents.identity_documents
     WHERE agent_id = $1
     ORDER BY document_type, version DESC
     ```
