1. Add `identityDocuments` table definition to `packages/dashboard/src/lib/schema.ts`:
   - Mirror the agents schema table (dashboard uses its own local schema -- does NOT import from @aesir/agents, per MEMORY.md)
   - Use `agentsSchema.table("identity_documents", ...)` matching the schema.ts structure from Plan 01:
     - id: text PK, agent_id: text, document_type: text, content: text, version: integer, conversation_id: text (nullable), created_at: timestamp
   - Export the table reference

2. Add service functions to `packages/dashboard/src/services/agents.ts`:

   **a. `getIdentityDocumentsForAgent(agentId: string): Promise<IdentityDocumentSummary[]>`**
   - Returns the current (latest version) of each document for the given agent
   - Query: `SELECT DISTINCT ON (document_type) * FROM agents.identity_documents WHERE agent_id = $1 ORDER BY document_type, version DESC`
   - Map to `IdentityDocumentSummary`: `{ documentType: string; content: string; version: number; charCount: number; conversationId: string | null; updatedAt: string }`
   - `charCount` is `content.length` (computed, not stored per user decision)
   - `updatedAt` is `created_at.toISOString()`

   **b. `getIdentityDocumentHistory(agentId: string, documentType: string, limit: number = 20, offset: number = 0): Promise<{ versions: IdentityDocumentVersion[]; hasMore: boolean }>`**
   - Returns version history for a specific document type, newest first
   - Query: select from identity_documents WHERE agent_id = $1 AND document_type = $2 ORDER BY version DESC LIMIT $3+1 OFFSET $4
   - Use limit+1 trick: fetch one extra to determine `hasMore`, return only `limit` items
   - Map to `IdentityDocumentVersion`: `{ version: number; content: string; charCount: number; charDelta: number | null; conversationId: string | null; createdAt: string }`
   - `charDelta`: difference from previous version. For the most recent version, compute as `currentCharCount - previousVersionCharCount`. For the first version (version 1), charDelta is null. This can be computed in-app by comparing adjacent rows or via a LAG window function in the query.
   - Simpler approach: compute charDelta client-side. Return versions with charCount, let the component compute deltas between adjacent versions.

   **c. API route for version history pagination (client-side fetch):**
   - Create `packages/dashboard/src/app/api/agents/[id]/identity/[type]/route.ts` with GET handler
   - Accepts query params: `limit` (default 20), `offset` (default 0)
   - Returns JSON: `{ versions: IdentityDocumentVersion[], hasMore: boolean }`
   - This API route is needed because the version list uses client-side pagination (load more button) which requires a fetch call

3. Define TypeScript interfaces for the dashboard-local types:
   ```typescript
   export interface IdentityDocumentSummary {
     documentType: string;
     content: string;
     version: number;
     charCount: number;
     conversationId: string | null;

   }

   export interface IdentityDocumentVersion {
     version: number;
     content: string;
     charCount: number;
     conversationId: string | null;
     createdAt: string; // ISO string
   }
   ```
