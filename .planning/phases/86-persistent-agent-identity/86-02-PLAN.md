1. Create `lifecycle-hooks.ts` -- the shared hook mechanism:
   ```typescript
   export interface LifecycleHookContext {
     conversationId: string;
     agentDefinitionId: string;
     agentDefinitionVersion: string;
     messages: Anthropic.MessageParam[];
     systemPrompt: string;
     tools: ToolDefinition[];
     model: string;
     logger: PinoLogger;
     // Inject a user-role turn and run a short agent loop iteration
     // The hook can pass a prompt and the agent responds with tool calls or text
     injectTurn(userMessage: string): Promise<AgentLoopResult>;
   }

   export type LifecycleHook = (ctx: LifecycleHookContext) => Promise<void>;

   export interface LifecycleHookRegistry {
     register(name: string, hook: LifecycleHook): void;
     runPreCompletion(ctx: LifecycleHookContext): Promise<void>;
   }
   ```
   - `createLifecycleHookRegistry(logger: PinoLogger): LifecycleHookRegistry`
   - Hooks stored as `Map<string, LifecycleHook>` (name for logging/dedup)
   - `runPreCompletion`: iterates hooks sequentially (order matters for Phase 87), wraps each in try/catch so one failing hook doesn't block others. Logs hook name + duration.
   - Export all types and factory from the module

2. Modify `worker-loop.ts` -- add two integration points in `executeConversation`:

   **a. System prompt injection (before step 11 "Run agent loop"):**
   - Add `identityService` as optional field in `WorkerLoopOptions`: `identityService?: IdentityService | undefined`
   - After loading the definition (step 1) and before running the agent loop (step 11), if `identityService` is present AND `conv.parent_conversation_id` is null (not a sub-agent):
     ```typescript
     let systemPrompt = definition.systemPrompt;
     if (options.identityService && !conv.parent_conversation_id) {
       try {
         const identityDocs = await options.identityService.getCurrentDocuments(conv.agent_definition_id);
         if (identityDocs.length > 0) {
           const identityBlock = formatIdentityDocumentsBlock(identityDocs);
           systemPrompt = `${systemPrompt}\n\n${identityBlock}`;
           childLogger.info({ documentCount: identityDocs.length }, "Identity documents injected into system prompt");
         }
       } catch (identityErr) {
         // IDN-09: Graceful degradation -- proceed without identity docs
         childLogger.warn({ err: identityErr }, "Failed to load identity documents (graceful degradation, proceeding without)");
       }
     }
     ```
   - Use this `systemPrompt` variable everywhere `definition.systemPrompt` was previously used in the loopOptions and eventBase payload
   - Add helper function `formatIdentityDocumentsBlock(docs)` that produces:
     ```xml
     <identity_documents>
     <document type="architectural_model" version="7" updated="2026-02-20T14:30:00Z">
     [content]
     </document>
     </identity_documents>
     ```
     Per user decision: include version number and last-updated timestamp in tags.

   **b. Pre-completion hook (in step 14, BEFORE the "Completed successfully" persistence block):**
   - Add `lifecycleHooks` as optional field in `WorkerLoopOptions`: `lifecycleHooks?: LifecycleHookRegistry | undefined`
   - In step 14, when `result.status === "completed"` and `!conv.parent_conversation_id` (not a sub-agent) and `!cancellationCheck[0]?.pending_cancellation` (happy path only per user decision):
     ```typescript
     if (options.lifecycleHooks && !conv.parent_conversation_id) {
       try {
         const hookCtx: LifecycleHookContext = {
           conversationId: conv.id,
           agentDefinitionId: conv.agent_definition_id,
           agentDefinitionVersion: conv.agent_definition_version,
           messages: [...finalMessages] as Anthropic.MessageParam[],
           systemPrompt,
           tools: resolvedTools,
           model: definition.model,
           logger: childLogger,
           injectTurn: async (userMessage: string) => {
             // Run a mini agent loop with the injected message
             const hookMessages = [...finalMessages, { role: "user" as const, content: userMessage }];
             const hookResult = await runAgentLoop({
               systemPrompt,
               tools: resolvedTools,
               initialMessage: userMessage,
               context: hookMessages.slice(0, -1),
               model: definition.model,
               maxIterations: 3,
               onToolCall,
               onToolResult,
               onResponse,
               abortSignal,
               logger: childLogger,
             });
             // Append hook messages to finalMessages
             finalMessages.push(...hookResult.messages.slice(1));
             return hookResult;
           },
         };
         await options.lifecycleHooks.runPreCompletion(hookCtx);
       } catch (hookErr) {
         // Non-fatal: hooks failing should not prevent conversation completion
         childLogger.error({ err: hookErr }, "Pre-completion hooks failed (non-fatal, completing anyway)");
       }
     }
     ```
   - IMPORTANT: The hook runs AFTER step 13c (cancellation check) but BEFORE the `result.status === "completed"` persistence block. The hook can add messages to `finalMessages` via `injectTurn`, and those messages get persisted with the completion update.
   - Note: `finalMessages` needs to be declared with `let` instead of `const` if it isn't already, or use `.push()` to mutate in place.
