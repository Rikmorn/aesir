  <action>
    **Filter module (router/webhook-filter.ts):**

    Create `createWebhookFilter(options)` factory that returns `filterWebhookEvent(event)`:

    ```typescript
    interface WebhookFilterResult {
      action: 'accept' | 'suppress';
      reason?: 'duplicate' | 'agent_echo';
    }

    interface WebhookFilterOptions {
      pool: Pool;
      logger: PinoLogger;
    }
    ```

    **Layer 1 -- Delivery dedup (stateful):**
    - If `event.deduplicationId` exists, namespace it: `${source_prefix}:${deduplicationId}` where source_prefix is the first segment of `event.source` before `:` (e.g., "linear" from "linear:webhook", "github" from "github:webhook"). For pass-through events where source has no colon, use the full source string.
    - Execute: `INSERT INTO agents.processed_webhook_events (event_id) VALUES ($1) ON CONFLICT DO NOTHING`
    - If `result.rowCount === 0`, it's a duplicate -> return `{ action: 'suppress', reason: 'duplicate' }` with debug log
    - If no `deduplicationId`, skip Layer 1 (pass through)

    **Layer 2 -- Echo suppression (stateless):**
    - If `event.actorInfo?.isBot === true`, return `{ action: 'suppress', reason: 'agent_echo' }` with debug log
    - Missing actorInfo -> pass through (fail-open per CONTEXT.md decision)

    **Logging format (per CONTEXT.md):**
    `logger.debug({ eventId, eventType, reason }, 'event suppressed')`
    where `eventId` is the namespaced dedup ID (or deduplicationId for echo), `eventType` is `event.type`.

    Export: `createWebhookFilter`, `WebhookFilterResult`, `WebhookFilterOptions`.

    **Tests (router/webhook-filter.test.ts):**
    Use vitest. Mock pg Pool with a mock `query` function that tracks calls and returns configurable `rowCount`.

    Test cases:
    1. First delivery -> accept (rowCount = 1)
    2. Duplicate delivery -> suppress with reason 'duplicate' (rowCount = 0)
    3. Bot actor -> suppress with reason 'agent_echo' (even if not duplicate)
    4. No deduplicationId -> skip dedup layer, accept
    5. No actorInfo -> skip echo layer, accept (fail-open)
    6. actorInfo.isBot = false -> accept
    7. Both duplicate AND bot actor -> suppress with reason 'duplicate' (dedup checked first)
    8. Source namespacing: "linear:webhook" -> "linear:{id}", "github:webhook" -> "github:{id}"
    9. DB error during dedup check -> throw (let caller handle, do not silently accept)
  </action>
