**Find tests mocking @aesir/common for config:**
```bash
grep -r "vi.mock.*@aesir/common" packages/ --include="*.test.ts"
```

**For tests that were mocking to prevent env validation:**
- Many can now REMOVE the vi.mock entirely (pure library has no side effects)
- Keep vi.mock only if test needs to stub specific behavior (like createLogger)

**Update patterns:**

1. **Platform tests (worker.test.ts, client.test.ts, approval-workflow.test.ts):**
   - If they mocked config from @aesir/common, remove the mock
   - Tests should now work without mocking since common has no env validation
   - If tests need specific config values, pass them as function parameters

   ```typescript
   // Before
   vi.mock("@aesir/common", () => ({
     config: { temporal: { address: "localhost:7233" } },
     createLogger: () => mockLogger,
   }));

   // After - remove config mock, keep logger mock only if needed
   vi.mock("@aesir/common", () => ({
     createLogger: () => mockLogger,
   }));
   // Pass config via function parameters in tests
   const client = createTemporalClient({ address: "localhost:7233", namespace: "test" });
   ```

2. **Integration tests (linear, github, slack):**
   - Mock their own local config.ts instead of @aesir/common
   ```typescript
   // Before
   vi.mock("@aesir/common", () => ({
     config: { linear: { ... } },
   }));

   // After
   vi.mock("../config.js", () => ({
     config: { linear: { webhookSecret: "test-secret" } },
     env: { LOG_LEVEL: "debug" },
   }));
   ```

3. **Common test issues to fix:**
   - "config is not defined" - update import or pass as parameter
   - "createLogger is not a function" - keep that specific mock
   - Type errors from removed exports - update test expectations

**Run tests to find failures:**
```bash
pnpm test:fast 2>&1 | head -100
```
