## Technical Implementation

### Before (Inconsistent Naming)

```yaml
# Integration services used DATABASE_*
linear-integration:
  environment:
    - DATABASE_HOST=postgresql
    - DATABASE_PORT=5432
    - DATABASE_USER=temporal
    - DATABASE_PASSWORD=temporal
    - DATABASE_NAME=temporal

# Agent services used DB_*
dev-agent:
  environment:
    - DB_HOST=postgresql
    - DB_PORT=5432
    - DB_USER=temporal
    - DB_PASSWORD=temporal
    - DB_NAME=temporal
```

### After (Consistent DB_* Naming)

```yaml
# All services now use DB_*
linear-integration:
  environment:
    - DB_HOST=postgresql
    - DB_PORT=5432
    - DB_USER=temporal
    - DB_PASSWORD=temporal
    - DB_NAME=temporal

github-integration:
  environment:
    - DB_HOST=postgresql
    - DB_PORT=5432
    - DB_USER=temporal
    - DB_PASSWORD=temporal
    - DB_NAME=temporal

slack-integration:
  environment:
    - DB_HOST=postgresql
    - DB_PORT=5432
    - DB_USER=temporal
    - DB_PASSWORD=temporal
    - DB_NAME=temporal

dev-agent:
  environment:
    - DB_HOST=postgresql
    - DB_PORT=5432
    - DB_USER=temporal
    - DB_PASSWORD=temporal
    - DB_NAME=temporal
```

**Benefits:**
- Consistent naming across all Docker services
- Matches the DB_* naming convention established in Plan 22.1-02
- Easier to maintain and understand environment configuration
