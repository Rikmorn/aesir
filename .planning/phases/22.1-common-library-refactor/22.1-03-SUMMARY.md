# Phase 22.1 Plan 03: Agents Config Summary

**One-liner:** Agents package owns environment and agent configuration with eager validation at module load

## What Was Built

### Config Infrastructure
- **packages/agents/src/config.ts**: Eager environment validation for all agent requirements (Anthropic, Slack, Linear, GitHub, database, Temporal)
- **packages/agents/src/config/agent-config.ts**: Moved AgentConfigSchema from common to agents (ownership transfer)
- **packages/agents/src/config/index.ts**: Barrel export for agent configuration utilities

### Backward Compatibility Shims (Temporary)
- **packages/common/src/shim-config.ts**: Minimal config object reading from process.env (no validation)
- **packages/common/src/shim-agent-config.ts**: Re-export of AgentConfigSchema for packages not yet migrated

### Public API
- Updated `packages/agents/src/index.ts` to export config and agent-config modules
- Makes `config`, `env`, `AgentConfigSchema`, `devAgentConfig` available via `@aesir/agents`

## Architecture Decisions

### 1. Eager Validation Pattern
**Decision:** Validate environment at module load time, not lazy on first use
**Rationale:** Fail-fast approach surfaces configuration errors immediately at startup rather than during runtime when services are already handling requests
**Impact:** Clear error messages guide developers to fix missing env vars before the service starts

### 2. Agent Config Ownership
**Decision:** Move AgentConfigSchema from `@aesir/common` to `@aesir/agents`
**Rationale:** Agent configuration (iterations, recursion limits, model settings) is specific to the agents layer and not a cross-layer contract. Common should only contain types shared between layers.
**Impact:** Cleaner package boundaries, agents package is self-contained for configuration

### 3. Phased Migration with Shims
**Decision:** Use temporary shim exports in `@aesir/common` during migration
**Rationale:** Allows Plans 22.1-02 through 22.1-05 to proceed independently without breaking builds
**Impact:** Temporary code that will be removed once all packages have their own config

### Validation Schema
The agents env schema validates:
- **Runtime config**: NODE_ENV, LOG_LEVEL

- **Retention**: RETENTION_DAYS for cleanup
