## Notes

The Docker "failures" for GitHub, Slack, and agents are **expected behavior**:
- Services correctly fail fast when required credentials are missing
- Error messages clearly indicate which env vars are needed
- This is the intended outcome of the refactor - predictable, debuggable startup failures

To run all services:
1. Add `GITHUB_CLIENT_ID`, `GITHUB_CLIENT_SECRET`, `GITHUB_WEBHOOK_SECRET` to `.env`
2. Add `SLACK_SIGNING_SECRET`, `SLACK_CLIENT_ID`, `SLACK_CLIENT_SECRET` to `.env`
3. Ensure `CREDENTIAL_ENCRYPTION_KEY` matches key used to encrypt stored credentials (or re-run OAuth flows)
