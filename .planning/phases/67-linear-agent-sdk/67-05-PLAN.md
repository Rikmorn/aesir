<objective>
Add two infrastructure activity emissions to worker-loop.ts to close session lifecycle gaps:
1. **Resume activity**: Emit a thought activity when a conversation resumes from `waiting` state, so Linear transitions the session to `active`.
2. **Completion activity**: Emit a response activity when a conversation completes (`end_turn`), so Linear transitions the session to `complete`.

Purpose: Without these, a resumed session may show stale state (e.g., `awaitingInput`) until the agent emits its first thought, and a completed conversation (especially sub-agents that just work without replying) may never transition to `complete` in Linear.

Output: Two new helper functions in worker-loop.ts following the exact same pattern as `emitErrorActivity`.
</objective>

**1. `emitResumeActivity`:**
```typescript
async function emitResumeActivity(
  replyContext: unknown,
  deps: { logger: PinoLogger; agentId: string; correlationId: string },
): Promise<void> {
  try {
    const ctx = replyContext as Record<string, unknown> | undefined;
    if (!ctx || ctx.channel !== "linear" || !ctx.agentSessionId) return;

    const { callMcpTool } = await import("../shared/mcp/client.js");

    await callMcpTool({
      integration: "linear",
      tool: "create_agent_activity",
      params: {
        agentSessionId: ctx.agentSessionId as string,
        type: "thought",
        body: "Resuming work...",
      },
      agentId: deps.agentId,
      correlationId: deps.correlationId,
    });

    deps.logger.info(
      { sessionId: ctx.agentSessionId },
      "Resume activity emitted to Linear",
    );
  } catch (error) {
    deps.logger.warn(
      { err: error },
      "Failed to emit resume activity to Linear (non-fatal)",
    );
  }
}
```

**2. `emitCompletionActivity`:**
```typescript
async function emitCompletionActivity(
  replyContext: unknown,
  deps: { logger: PinoLogger; agentId: string; correlationId: string },
): Promise<void> {
  try {
    const ctx = replyContext as Record<string, unknown> | undefined;
    if (!ctx || ctx.channel !== "linear" || !ctx.agentSessionId) return;

    const { callMcpTool } = await import("../shared/mcp/client.js");

    await callMcpTool({
      integration: "linear",
      tool: "create_agent_activity",
      params: {
        agentSessionId: ctx.agentSessionId as string,
        type: "response",
        body: "Task completed.",
      },
      agentId: deps.agentId,
      correlationId: deps.correlationId,
    });

    deps.logger.info(
      { sessionId: ctx.agentSessionId },
      "Completion activity emitted to Linear",
    );
  } catch (error) {
    deps.logger.warn(
      { err: error },
      "Failed to emit completion activity to Linear (non-fatal)",
    );
  }
}
```
