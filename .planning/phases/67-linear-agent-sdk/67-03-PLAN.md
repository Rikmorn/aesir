**webhooks.ts (webhook handler) changes -- 10-second acknowledgment thought:**
In the AgentSession event handler, after the payload is validated and BEFORE sending the 200 response, check if the action is `"created"`. If so, fire an async acknowledgment thought:

if (payload.action === "created") {
  // Fire async acknowledgment thought -- do NOT await (5-second webhook deadline)

Add the helper function in the same file (or as a local function):
```typescript
async function emitAcknowledgmentThought(
  sessionId: string,
  deps: WebhookRouterDeps,
): Promise<void> {
  const { logger, db } = deps;
  const childLogger = logger.child({ component: "session-acknowledgment" });

  try {
    const { createLinearClientFromDatabase } = await import("../oauth/flow.js");
    const client = await createLinearClientFromDatabase("ws_default");

    await client.createAgentActivity({
      agentSessionId: sessionId,
      content: {
        type: "thought",
        body: "Looking into this...",
      },
      ephemeral: true,
    });

    childLogger.info({ sessionId }, "Acknowledgment thought emitted");
  } catch (error) {
    childLogger.error({ err: error, sessionId }, "Failed to emit acknowledgment thought");
    // Non-fatal: agent will still process the session
  }
}
```

This uses `ephemeral: true` so the thought disappears when the agent emits its first real activity. The wording "Looking into this..." is per the discretion recommendation in research.

The 200 response is sent BEFORE the thought is emitted (fire-and-forget). This respects the 5-second webhook response deadline (Pitfall 1 from research).
