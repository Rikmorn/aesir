  <action>
    1. Create packages/integrations/slack/src/api/events.ts:
       - Import express, Router from express
       - Import createPinoLogger from @aesir/common
       - Import SlackEventDeliveryStore from ../db/event-delivery-store.js
       - Import createEventHandler from ../events/handler.js
       - Import config from ../types/config.js

       - Define EventsRouterDeps:
         - eventDeliveryStore: SlackEventDeliveryStore
         - logger: PinoLogger
         - onEvent?: (payload: SlackEventPayload) => Promise<void> (optional callback)

       - Create createEventsRouter(deps: EventsRouterDeps): Router
         - Create router with express.Router()
         - Create event handler with deps

         - POST /events endpoint:
           - Handle URL verification challenge first:
             - If body.type === "url_verification", return { challenge: body.challenge }
             - This is Slack's initial webhook setup verification
           - Parse request body (already JSON via express.json())
           - If body.type === "event_callback":
             - Extract event from body.event
             - Merge event_id from body into event if not present
             - Call eventHandler.handleEvent(event)
             - If result is error, log and return 500
             - If result is null (duplicate or filtered), return 200 OK
             - If onEvent callback provided, call it with payload (async, don't await to avoid timeout)
           - Acknowledge immediately (3-second rule)
           - Return 200 OK

         - Handle Slack retries (X-Slack-Retry-Num header):
           - Log at debug level, don't treat as error
           - Deduplication handles actual duplicates

    2. Create packages/integrations/slack/src/api/oauth.ts:
       - Import express, Router from express
       - Import createPinoLogger from @aesir/common
       - Import SlackCredentialStore from ../db/credential-store.js
       - Import createSlackInstallationStore from ../oauth/installation-store.js
       - Import generateOAuthState, getDefaultOAuthScopes from ../oauth/flow.js
       - Import config from ../types/config.js

       - Define OAuthRouterDeps:
         - credentialStore: SlackCredentialStore
         - logger: PinoLogger

       - Create oauthStateStore: Map<string, { createdAt: number }> (in-memory for MVP)

       - Create createOAuthRouter(deps: OAuthRouterDeps): Router
         - Create router

         - GET /oauth/authorize:
           - Generate OAuth state
           - Store state in oauthStateStore with timestamp
           - Construct Slack OAuth URL:
             - Base: https://slack.com/oauth/v2/authorize
             - Params: client_id, scope, state, redirect_uri (optional)
           - Redirect to Slack OAuth URL
           - Log at info: "Initiating OAuth flow"

         - GET /oauth/callback:
           - Extract code and state from query params
           - Validate state exists in oauthStateStore (CSRF protection)
           - Remove state from store (one-time use)
           - Exchange code for tokens via Slack API:
             - POST https://slack.com/api/oauth.v2.access
             - Body: code, client_id, client_secret, redirect_uri
           - Parse response for installation data
           - Create installationStore from credentialStore
           - Call storeInstallation with parsed data
           - Return success HTML or redirect
           - Log at info: "OAuth flow completed" with teamId

         - GET /oauth/success (optional):
           - Simple success page for post-OAuth redirect

       - Clean up expired states (older than 10 minutes) periodically
  </action>
