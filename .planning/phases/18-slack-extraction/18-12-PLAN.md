    ---
    description: Slack integration package patterns and conventions
    globs:
      - packages/integrations/slack/**/*.ts
      - packages/agents/**/slack/**/*.ts
    alwaysApply: false
    ---

    # Slack Integration Guidelines

    ## Package Location

    Slack integration is in `packages/integrations/slack/` as `@aesir/integration-slack`.

    ## Key Patterns

    ### Bolt Framework

    - Use Bolt for event handling, not raw Express
    - Socket Mode for development (requires SLACK_APP_TOKEN)
    - HTTP mode for production (requires SLACK_SIGNING_SECRET)

    ### Event Handling

    - Events deduplicated via event_id (not webhook delivery IDs)
    - Bot messages filtered to prevent loops (subtype: "bot_message")
    - Acknowledge within 3 seconds (Slack's timeout rule)
    - Process async after acknowledgment

    ### Threading

    - Use event.thread_ts || event.ts for reply context
    - Replies go to thread if in thread, new message if not

    ### OAuth

    - Bolt installationStore backed by PostgreSQL (slack.installations)
    - Installation model stores team_id, bot_token, scopes
    - Support for Enterprise Grid via enterprise_id (nullable)

    ## Common Imports

    ```typescript
    import {
      createBoltApp,
      createSlackClientFromDatabase,
      sendMessage,
      sendApprovalRequest,
      buildApprovalBlocks,
      createEventHandler,
    } from "@aesir/integration-slack";
    ```

    ## Database

    - Schema: slack.* namespace
    - Tables: installations, event_deliveries
    - Tokens encrypted with AES-256-CBC

    ## Port

    - Slack service: 3003 (Linear: 3001, GitHub: 3002)
    ```
