  <name>Task 1: Create Bolt installationStore adapter</name>
  <files>

  </files>
  <action>
    Create packages/integrations/slack/src/oauth/installation-store.ts:

    1. Import types from @slack/bolt:
       - Installation, InstallationStore, InstallationQuery

    2. Import from internal modules:
       - SlackCredentialStore from ../db/credential-store.js
       - PinoLogger from @aesir/common

    3. Define SlackInstallationStoreOptions:
       - credentialStore: SlackCredentialStore
       - logger: PinoLogger

    4. Create createSlackInstallationStore(options): InstallationStore
       - Implements Bolt's InstallationStore interface exactly

       - storeInstallation: async (installation: Installation) => Promise<void>
         - Log at info: "Storing Slack installation" with teamId
         - Extract from installation:
           - teamId: installation.team?.id (required)
           - enterpriseId: installation.enterprise?.id (optional)
           - userId: installation.user?.id (optional)
           - isEnterpriseInstall: installation.isEnterpriseInstall ?? false
           - botToken: installation.bot?.token (required)
           - userToken: installation.user?.token (optional)
           - botId: installation.bot?.id (optional)
           - botUserId: installation.bot?.userId (optional)
           - botScopes: installation.bot?.scopes (array)
           - appId: installation.appId (optional)
         - Call credentialStore.storeInstallation with mapped data
         - Unwrap ResultAsync - throw on error with error message
         - Log at debug: "Installation stored successfully"

       - fetchInstallation: async (query: InstallationQuery<boolean>) => Promise<Installation | undefined>
         - Log at debug: "Fetching Slack installation" with query params
         - Extract teamId, enterpriseId, isEnterpriseInstall from query
         - Call credentialStore.fetchInstallation with query
         - If result is error, log and return undefined (Bolt expects undefined for not found)
         - If result is null, return undefined
         - Map stored credential back to Bolt Installation shape:
           - team: { id: teamId }
           - enterprise: enterpriseId ? { id: enterpriseId } : undefined
           - bot: { token, id, userId, scopes }
           - user: userToken ? { token: userToken, id: userId } : undefined
           - isEnterpriseInstall
           - appId
         - Return Installation object

       - deleteInstallation: async (query: InstallationQuery<boolean>) => Promise<void>
         - Log at info: "Deleting Slack installation" with query params
         - Call credentialStore.deleteInstallation with query
         - Unwrap ResultAsync - throw on error
         - Log at debug: "Installation deleted"

    5. Export createSlackInstallationStore
  </action>
  <verify>
    pnpm --filter @aesir/integration-slack typecheck
  </verify>
  <done>Bolt installationStore adapter created with PostgreSQL backend</done>
