       - Import App, InstallationStore, Installation, InstallationQuery from @slack/bolt
       - Import createPinoLogger from @aesir/common
       - Import SlackCredentialStore from ../db/credential-store.js
       - Import BoltAppOptions, BoltAppDependencies from ./types.js
       - Import config from ../types/config.js

       - Create createInstallationStoreAdapter(credentialStore: SlackCredentialStore, logger: PinoLogger): InstallationStore
         - Implements Bolt's InstallationStore interface
         - storeInstallation: async (installation: Installation) => Promise<void>
           - Extract teamId, enterpriseId, isEnterpriseInstall from installation
           - Call credentialStore.storeInstallation with mapped fields
           - Log success at info level
           - Unwrap ResultAsync, throw on error
         - fetchInstallation: async (query: InstallationQuery) => Promise<Installation | undefined>
           - Extract teamId, enterpriseId, isEnterpriseInstall from query
           - Call credentialStore.fetchInstallation
           - Map result back to Bolt's Installation shape
           - Return undefined if not found (Bolt's expected behavior)
           - Unwrap ResultAsync, throw on error
         - deleteInstallation: async (query: InstallationQuery) => Promise<void>
           - Call credentialStore.deleteInstallation
           - Unwrap ResultAsync, throw on error

       - Create createBoltApp(options: BoltAppOptions, deps: BoltAppDependencies): App
         - If mode === "socket":
           - Require appToken in options (throw if missing)
           - Create App with socketMode: true
           - Pass token, appToken from options
         - If mode === "http":
           - Require signingSecret in options
           - Create App with socketMode: false
           - Pass signingSecret from options

         - Create installationStore adapter from credentialStore
         - Configure OAuth if clientId/clientSecret provided:
           - installationStore: adapter
           - scopes: options.scopes or default ['app_mentions:read', 'chat:write', 'channels:history', 'im:history']
           - stateSecret: options.stateSecret or config.slack.stateSecret
           - installerOptions: { directInstall: true }

         - Move from existing packages/integrations/src/slack/bolt-app.ts
         - Call app.stop()
         - Log success
         - Don't re-throw on stop (shutting down anyway)
