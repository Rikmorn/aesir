Create the event handling layer with typed event payloads, Zod-based parsing, and deduplication integration.

Purpose: Slack events need structured types for agent consumption. Deduplication prevents duplicate processing when Slack retries failed deliveries. This module enables the pattern: "package emits typed events, consumer decides how to handle."

Output: Event types, parser, and handler with deduplication ready for Bolt integration.
</objective>

<task type="auto">
  <name>Task 1: Create event type definitions</name>
  <files>
    packages/integrations/slack/src/events/types.ts
  </files>
  <action>
    Create packages/integrations/slack/src/events/types.ts:

    1. Import z from zod

    2. Define base event schema (common fields):
       - event_id: z.string() (unique per event, for deduplication)
       - event_time: z.number() (Unix timestamp)
       - team_id: z.string() (workspace ID)
       - api_app_id: z.string().optional()

    3. Define app_mention event schema (SlackMentionEventSchema):
       - type: z.literal("app_mention")
       - user: z.string() (who mentioned the bot)
       - text: z.string() (full message text including mention)
       - ts: z.string() (message timestamp, used for replies)
       - channel: z.string() (where the mention occurred)
       - thread_ts: z.string().optional() (if in a thread)
       - Extends base event schema

    4. Define message event schema (SlackMessageEventSchema):
       - type: z.literal("message")
       - subtype: z.string().optional() (e.g., "bot_message", "thread_broadcast")
       - user: z.string().optional() (not present for bot messages)
       - text: z.string()
       - ts: z.string()
       - channel: z.string()
       - thread_ts: z.string().optional()
       - channel_type: z.enum(["channel", "group", "im", "mpim"]).optional()
       - Extends base event schema

    5. Define interactive action schema (SlackActionEventSchema):
       - type: z.literal("block_actions")
       - user: z.object({ id: z.string(), name: z.string().optional() })
       - channel: z.object({ id: z.string(), name: z.string().optional() })
       - message: z.object({ ts: z.string(), thread_ts: z.string().optional() }).optional()
       - actions: z.array(z.object({
           type: z.string(),
           action_id: z.string(),
           block_id: z.string().optional(),
           value: z.string().optional(),
         }))
       - response_url: z.string().optional()
       - trigger_id: z.string().optional()

    6. Export union schema SlackEventSchema:
       - z.discriminatedUnion("type", [SlackMentionEventSchema, SlackMessageEventSchema, SlackActionEventSchema])

    7. Export inferred types:
       - type SlackMentionEvent = z.infer<typeof SlackMentionEventSchema>
       - type SlackMessageEvent = z.infer<typeof SlackMessageEventSchema>
       - type SlackActionEvent = z.infer<typeof SlackActionEventSchema>
       - type SlackEvent = z.infer<typeof SlackEventSchema>

    8. Define normalized event payload for consumers (SlackEventPayload):
       - eventId: string
       - eventType: string
       - teamId: string
       - userId?: string
       - channel: string
       - text?: string
       - ts: string
       - threadTs?: string
       - actions?: Array<{ actionId: string; value?: string }>
       - raw: SlackEvent (original event for full access)
  </action>
  <verify>
    pnpm --filter @aesir/integration-slack typecheck
  </verify>
  <done>Event type definitions created with Zod schemas for validation</done>
</task>

  <files>

  <action>
    1. Create packages/integrations/slack/src/events/parser.ts:
       - Import z from zod
       - Import schemas and types from ./types.js

       - Create parseMentionEvent(payload: unknown): SafeParseReturnType
         - Returns SlackMentionEventSchema.safeParse(payload)

       - Create parseMessageEvent(payload: unknown): SafeParseReturnType
         - Returns SlackMessageEventSchema.safeParse(payload)

       - Create parseActionEvent(payload: unknown): SafeParseReturnType
         - Returns SlackActionEventSchema.safeParse(payload)

       - Create parseSlackEvent(payload: unknown): SafeParseReturnType
         - Attempts to parse with SlackEventSchema
         - Returns z.SafeParseReturnType with success/error

       - Create normalizeEvent(event: SlackEvent): SlackEventPayload
         - Converts parsed event to normalized payload format
         - Extracts common fields (eventId, teamId, channel, etc.)
         - Handles different event types appropriately
         - Always includes raw event for full access

    2. Create packages/integrations/slack/src/events/handler.ts:
       - Import SlackEventDeliveryStore from ../db/event-delivery-store.js
       - Import parseSlackEvent, normalizeEvent from ./parser.js
       - Import SlackError from ../types/errors.js
       - Import PinoLogger from @aesir/common
       - Import ResultAsync from neverthrow

       - Define EventHandlerOptions:
         - deliveryStore: SlackEventDeliveryStore
         - logger: PinoLogger

       - Define EventHandler interface:
         - handleEvent(payload: unknown): ResultAsync<SlackEventPayload | null, SlackError>
           - Returns null if duplicate or ignored event type

       - Create createEventHandler(options: EventHandlerOptions): EventHandler
         - Implementation:
           a. Parse incoming payload with parseSlackEvent
           b. If parse fails, return error
           c. Extract event_id from parsed event
           d. Check isDeliveryProcessed(event_id)
           e. If already processed, log at debug and return null (not an error)
           f. recordDelivery before processing (prevents race conditions)
           g. Normalize event to SlackEventPayload
           h. Filter ignored events (bot messages via subtype check)
           i. Return normalized payload for consumer

       - Filter logic (from CONTEXT.md):
         - Ignore: message events with subtype "bot_message" (prevent loops)
         - Ignore: message_changed, message_deleted subtypes
         - Process: app_mention, message (without ignored subtypes), block_actions

    3. Create packages/integrations/slack/src/events/index.ts:
       - export * from "./types.js"
       - export * from "./parser.js"
       - export * from "./handler.js"
