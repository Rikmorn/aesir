       - Create installations table (slack.installations) - matches Bolt's Installation model:
         - id: text primary key with createId.credential()
         - team_id: text (required - Slack workspace ID, e.g., T1234...)
         - enterprise_id: text (nullable - for Enterprise Grid)
         - user_id: text (nullable - user who installed, for user tokens)
         - is_enterprise_install: boolean default false
         - encrypted_bot_token: text (required - xoxb-...)
         - encrypted_user_token: text (nullable - xoxp-... if requested)
         - bot_id: text (nullable)
         - bot_user_id: text (nullable)
         - bot_scopes: text (nullable - comma-separated scopes)
         - app_id: text (nullable)
         - token_type: text default "bot"
         - created_at, updated_at: timestamps with defaults
         - deleted_at: timestamp (soft delete)
         - unique constraint on (team_id, enterprise_id) with where deleted_at IS NULL

       - Create eventDeliveries table (slack.event_deliveries):
         - id: text primary key
         - event_id: text unique (from Slack event payload)
         - event_type: text (e.g., "app_mention", "message")
         - team_id: text (for workspace tracking)
         - processed_at: timestamp (nullable)
         - created_at: timestamp
         - index on (event_id) for fast lookups
         - index on (created_at) for cleanup queries

       - Export type inference: Installation, NewInstallation, EventDelivery, NewEventDelivery
