<task type="auto">
  <name>Task 2: Create TypeScript project reference structure</name>
  <files>tsconfig.json, tsconfig.base.json</files>
  <action>
  1. Create tsconfig.base.json with shared compiler options (these get inherited by all packages):
  ```json
  {
    "compilerOptions": {
      "target": "ES2022",
      "module": "NodeNext",
      "moduleResolution": "NodeNext",
      "lib": ["ES2022"],
      "strict": true,
      "esModuleInterop": true,
      "skipLibCheck": true,
      "forceConsistentCasingInFileNames": true,
      "declaration": true,
      "declarationMap": true,
      "composite": true,
      "incremental": true,
      "sourceMap": true,
      "resolveJsonModule": true,
      "isolatedModules": true,
      "noImplicitReturns": true,
      "noFallthroughCasesInSwitch": true,
      "exactOptionalPropertyTypes": true,
      "noUncheckedIndexedAccess": true
    }
  }
  ```

  Note: `composite: true` is critical - it enables project references and incremental builds.
  Note: `declaration: true` is required for project references to work (packages consume .d.ts files).

  2. Update tsconfig.json to be references-only (no compiler options):
  ```json
  {
    "files": [],
    "references": [
      { "path": "packages/common" },
      { "path": "packages/platform" },
      { "path": "packages/integrations" },
      { "path": "packages/agents" }
    ]
  }
  ```

  Note: `files: []` is required to prevent root tsconfig from compiling anything directly.
  The packages don't exist yet - this is intentional. They'll be created in plan 02.
  </action>
  <verify>
  - tsconfig.base.json exists with `composite: true` and `declaration: true`
  - tsconfig.json has only `files: []` and `references: []`
  - tsconfig.json references all four packages (common, platform, integrations, agents)
  </verify>
  <done>TypeScript project reference structure is ready for packages</done>
</task>

  ```typescript
      // Projects mode for monorepo - each package has its own vitest.config.ts
      projects: ["packages/*"],
    },
  });
  ```

  Note: This expects each package to have its own vitest.config.ts using `defineProject()`.
  Tests won't run until packages are scaffolded, which is expected.
  </action>
