<task type="auto">
  <name>Task 1: Configure workspace-level coverage in vitest.config.ts</name>
  <files>vitest.config.ts</files>
  <action>
Update the root vitest.config.ts to add comprehensive coverage configuration:

1. Add coverage configuration with provider: 'v8'
2. Set enabled: false (enable via CLI flag --coverage)
3. Configure reporters: ['text', 'html', 'lcov']
4. Set reportsDirectory: './coverage'
5. Configure per-package thresholds using glob patterns:
   - Core packages (common, platform, observability): 70% lines, functions, branches, statements
   - Integration packages (integrations/**, agents): 50% thresholds
6. Configure exclusions:
   - **/node_modules/**
   - **/dist/**
   - **/*.test.ts, **/*.integration.test.ts, **/*.e2e.test.ts
   - **/db/migrations/**, **/db/scripts/**
   - **/main.ts (entry points)
   - **/types.ts, **/schemas.ts (type-only files)
   - **/_legacy/**

IMPORTANT: Coverage config MUST be at root level, not in project configs (Vitest ignores project-level coverage settings when running from root).

Update the projects array to include all package locations:
- packages/*
- packages/integrations/*
  </action>
  <verify>
Run `cat vitest.config.ts` to confirm coverage configuration is present.
Run `pnpm vitest --help` to confirm coverage flag is available.
  </verify>
  <done>vitest.config.ts has coverage configuration with thresholds and exclusions</done>
</task>

<task type="auto">
  <name>Task 2: Update package.json scripts for coverage commands</name>
  <files>package.json</files>
  <action>
Update root package.json scripts:

1. Keep existing `test` script: "vitest run"
2. Keep existing `test:watch` script: "vitest"
3. Update `test:coverage` script: "vitest run --coverage"
4. Add `test:coverage:open` script: "vitest run --coverage && open coverage/index.html"

Note: The --coverage flag enables coverage collection at runtime. The coverage.enabled: false in config means coverage is off by default (faster tests), but --coverage overrides this.
  </action>
  <verify>
Run `pnpm test:coverage` and verify it runs tests with coverage output.
If tests pass, check that coverage/ directory is created with reports.
  </verify>
  <done>test:coverage script runs and generates coverage report in coverage/ directory</done>
</task>
