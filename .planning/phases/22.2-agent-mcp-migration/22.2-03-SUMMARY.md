## Key Changes

### Interface Simplification

**Before:**
```typescript
export interface ProductAgentGraphOptions {
  llm?: ChatAnthropic;
  linearClient: LinearClient;  // Direct SDK dependency
  teamId: string;
  checkpointer?: PostgresSaver;
}
```

**After:**
```typescript
export interface ProductAgentGraphOptions {
  llm?: ChatAnthropic;
  teamId: string;  // Only need team ID for MCP calls
  checkpointer?: PostgresSaver;
}
```

### MCP Tool Usage

**List Labels:**
```typescript
const labels = await callMcpTool<Array<{ id: string; name: string }>>({
  integration: "linear",
  tool: "list_labels",
  params: { teamId },
  agentId: "product-agent",
  correlationId,
});
```

**Create Issue:**
```typescript
const result = await callMcpTool<{ id: string; identifier: string; title: string }>({
  integration: "linear",
  tool: "create_issue",
  params: {
    teamId,
    title: task.title,
    description: buildTaskDescription(task, taskList.projectContext),
    priority: mapPriorityToLinear(task.priority),
    labelIds: labelIds.length > 0 ? labelIds : undefined,
  },
  agentId: "product-agent",
  correlationId,
});
```

### Correlation ID Flow

- Product agent node generates correlation ID: `generateCorrelationId("agent")`
- Propagated to all MCP tool calls
- Logged with all operations for end-to-end traceability
