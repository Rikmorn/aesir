**Why agent-side MCP types exist separately from @aesir/common:**
- @aesir/common/mcp contains SERVER-SIDE types (MCPToolContext, MCPToolResult, MCPToolMeta) for building MCP tool handlers
- Agent-side types (McpCallOptions, McpErrorResponse) are CLIENT-SIDE types for consuming MCP HTTP responses
- These are intentionally separate: servers produce MCPToolResult, clients consume the wire format
- Do NOT import from @aesir/common for agent MCP types - they serve different purposes
</context>

       switch (integration) {
         case 'linear':

         case 'github':
           return process.env.GITHUB_MCP_URL || 'http://github-integration:3002';
