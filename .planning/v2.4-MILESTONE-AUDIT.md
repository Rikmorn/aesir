## Known Limitations (by design)

These were explicitly scoped out of v2.4 per REQUIREMENTS.md:

| Limitation | Reason |
|------------|--------|
| Authentication not enforced | Auth-ready middleware exists; multi-user is future milestone |
| No agent definition editing | Write paths require API design; YAML files work for single-dev workflow |
| No conversation actions (cancel, retry) | Management endpoints exist but not exposed as UI actions |
| No historical analytics/trends | Raw data and recent aggregates sufficient for v2.4 |
| No alerting/notifications | Dashboard is pull-based; push is future |
| No mobile responsiveness | Desktop developer tool |
